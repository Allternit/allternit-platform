## What is Allternit?

Allternit implements agency as a system. Models do not own the agent. Allternit owns state, work, tools, policy, verification, memory, routing and execution. Models are interchangeable cognitive components used only where cognition is required.

You give Allternit a goal. It compiles the goal into typed work, runs it durably, checks every action against policy, verifies the result, and records receipts you can audit and replay.

<Note>
The only public API is the Cloud API at `https://api.allternit.com`. Allternit API (`:8013`) is the private data-plane runtime. See [API Overview](/api/overview).
</Note>

An agent in Allternit is a profile: identity, instructions, capabilities, policies and a default model preference the router may use. The model is not the agent's brain. The earlier product line, "One Brain, Multiple Faces, One Nervous System", described one runtime behind many surfaces; the systems architecture is the [Agency Kernel](/architecture).

## Installation

Install Gizzi Code, the Allternit CLI, globally:

<CodeGroup>
```bash npm
npm install -g @allternit/gizzi-code
```

```bash yarn
yarn global add @allternit/gizzi-code
```

```bash pnpm
pnpm add -g @allternit/gizzi-code
```
</CodeGroup>

Then run `gizzi` from your terminal to start the interactive TUI.

Or use the one-line installer for the BYOC runtime:

```bash
curl -fsSL https://install.allternit.com | bash
```
