## Overview

<Note>2026-10-09 (D0 cleanup): the per-backend canonical providers, the `/observe`, `/roots`, `/transactions`, `/approvals`, `/streams/negotiate` and `/shadow/observe` routes, environments, leases, history, and the canonical MCP server were removed. Computers are driven through the [computer toolset](/tools/computer-toolset) (`/v1/execute` on the gateway, `/v1/computers/:id/toolset` for hosted computers via `@allternit/computer-driver`).</Note>

The canonical router at `/v1/computer-use/canonical` (`domains/computer-use/core/gateway/canonical_router.py`) is now the **ledger layer** of the Computer Use Engine. It keeps:

- **Session events** — an append-only event ledger. The computer-use runs router and browser skills write to it in the same gateway process.
- **Trajectories** — an ordered, hashed export of a session's events, plus an MP4 replay built from stored observations.
- **Receipts** — integrity-hashed records that can be fetched and verified.
- **Evaluation and routing** — benchmark suites, recorded results, release gates and routing-cell stages.
- **Migrations** — import of legacy recordings and receipts into the ledgers.

`/providers` and `/health` still answer, so older clients get an empty catalog instead of a 404.

## Base URL

Local gateway:

```text
http://127.0.0.1:8760/v1/computer-use/canonical
```

## Endpoints

### Catalog and host capabilities

| Method | Path | Description |
|---|---|---|
| `GET` | `/providers` | Always `{"providers": [], "diagnostics": {}}` since the D0 cleanup. |
| `GET` | `/health` | Ledger subsystem status (`degraded`, zero providers) and contract version. |
| `GET` | `/native-capabilities` | Host-native capability payload. |
| `POST` | `/native-permissions/request-plan` | Permission request plan for a native capability. |

### Sessions, receipts and replay

| Method | Path | Description |
|---|---|---|
| `GET` | `/sessions/{session_id}/events` | List session events (`after_sequence`, `limit`). |
| `GET` | `/sessions/{session_id}/trajectory` | Export the session trajectory. |
| `POST` | `/sessions/{session_id}/replay/mp4` | Build a time-aligned MP4 replay from stored observations. |
| `GET` | `/sessions/{session_id}/resources` | List bound resources. |
| `GET` | `/receipts/{receipt_id}` | Retrieve and verify a receipt. |

### Evaluation and routing

| Method | Path | Description |
|---|---|---|
| `GET` | `/evaluation/suites` | List benchmark suites and adapter statuses. |
| `POST` | `/evaluation/results` | Record a measured evaluation result. |
| `GET` | `/evaluation/gates/{provider_id}/{capability_cell}` | Check a release gate. |
| `GET` | `/routing/cells` | List routing cells. |
| `POST` | `/routing/cells` | Configure a routing cell. |
| `POST` | `/routing/cells/{capability_cell}/transition` | Advance a routing stage. |

### Shadow and migration

| Method | Path | Description |
|---|---|---|
| `POST` | `/shadow/results` | Compare a stored receipt with a legacy result. |
| `POST` | `/migrations/legacy-recording` | Import a legacy recording. |
| `POST` | `/migrations/legacy-receipts` | Import legacy receipts. |

## SDK

`@allternit/sdk/computer-use` keeps `getCanonicalProviderCatalog()` / `listCanonicalProviders()` (empty catalog), `getCanonicalEvents()` and `getCanonicalTrajectory()`. The observe, roots, transaction, approval, environment, lease, history, file, clipboard and mobile methods were removed with their routes. New code should use `@allternit/computer-driver`.

## Configuration

| Variable | Default | Description |
|---|---|---|
| `ALLTERNIT_COMPUTER_STATE_DIR` | `~/.allternit/computer-use` | SQLite ledgers, artifacts and replay output directory. |
| `ALLTERNIT_LEGACY_RECORDING_ROOTS` | `~/.allternit/recordings:/tmp/allternit-recordings` | Roots the legacy migration service may read. |

## Error codes

| HTTP | Code | Meaning |
|---|---|---|
| `409` | `stale_resource_state` | Resource epoch changed since the base observation. |
| `422` | `canonical_validation_failed` | Invalid input (bad receipt ID, routing stage, migration path). |
| `500` | `canonical_internal_error` | Unexpected runtime error. |
