# Skills

Skills are reusable packages of prompts, tools, and configuration that extend what an agent can do. They live in `~/.allternit/skills/` and can be shared through a marketplace or version control.

## Skill format

A skill is a directory with a `SKILL.md` manifest and optional tool definitions:

```text
my-skill/
├── SKILL.md
└── tools/
    └── my-tool.json
```

## Loading skills

Skills load automatically from these folders. A skill is any folder in them that holds a `SKILL.md`.

| Folder | Where | Notes |
| --- | --- | --- |
| `~/.allternit/skills/` | Your computer | Skills the Allternit app installs or you add in Customize → Skills. |
| `~/.claude/skills/`, `~/.agents/skills/`, `~/.openclaw/skills/` | Your computer | Skills you already use with other agents load as they are. |
| `.allternit/skills/`, `.claude/skills/`, `.agents/skills/`, `.openclaw/skills/` | Your project, from the session folder up to the repository root | The Skill Builder and skill import write to `.allternit/skills/`. |
| `.gizzi/skill/` or `.gizzi/skills/` | `~/.gizzi/` or your project | Gizzi's own skill folders. |
| Any folder listed in `skills.paths` | Your Gizzi config | `~/` paths and project-relative paths both work. |

Set `GIZZI_DISABLE_EXTERNAL_SKILLS=1` to load only Allternit's built-in skills and the Gizzi folders.

Bots see built-in skills, skills in `~/.allternit/skills/`, and skills from your Gizzi config. They don't see your personal `~/.claude`, `~/.agents`, `~/.openclaw` or `~/.codex` skills, or project-folder skills.

Activate a skill for a session with:

```bash
gizzi --skill my-skill "do the thing"
```

## Built-in skills

Allternit ships with skills such as `allternit/powerpoint` for presentation creation. See [Build a tool](/tools/build-a-tool) to add custom tools to a skill.
