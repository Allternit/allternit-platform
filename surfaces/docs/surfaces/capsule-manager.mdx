## Overview

The **Capsule Manager** is the platform surface for managing MCP Interactive Capsules. Capsules are small, scoped UI surfaces attached to agent tools. They let tools expose interactive HTML/CSS/JS views, exchange events with the platform, and invoke platform tools on behalf of the agent.

## Base URL / usage

Capsule Manager runs inside the platform shell:

```text
https://app.allternit.com/shell?view=capsules
```

Open programmatically:

```typescript
open('capsules');
```

## Capsule lifecycle

| State | Description |
|---|---|
| `active` | Capsule is running and visible |
| `paused` | Capsule is suspended but retains state |
| `closed` | Capsule has been dismissed |

## Capsule surface

| Field | Type | Description |
|---|---|---|
| `html` | string | Capsule markup |
| `css` | string | Capsule styles |
| `js` | string | Capsule client script |
| `permissions` | string[] | Required permissions |

## Commands

The `capsule.create`, `capsule.render`, `capsule.event`, `capsule.invoke` and `capsule.close` commands and the standalone capsule REST examples that earlier versions of this page showed could not be found in the platform UI or the API on main, so they have been removed. There is no public capsule HTTP API. Capsules are created and rendered in-process by the platform shell and the capsule registry, and the Capsule Manager view lists and manages them.
