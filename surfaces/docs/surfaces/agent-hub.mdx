---
title: Agent Hub navigation
description: Where to find bot and project work after removal of the standalone workspace hub.
---

The standalone Agent Hub / Bot Hub was removed from the agent workspace. The `agent-hub` navigation id now aliases the Bots launch surface.

Use [Bots](/surfaces/bots) to create or open a worker. Manage Duplicate and Delete from bot home's menu. Use [Project home](/guides/project-coordination) for coordinated team work, and [threads](/guides/bot-threads) for the individual work records.

For reusable setups, browse [bot and team templates](/guides/bot-templates). For agent configuration concepts and API integration, see [Agent Studio](/surfaces/agent-studio) and the [Agents API](/api/agents).
