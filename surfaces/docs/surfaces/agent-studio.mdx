## Overview

**Agent Studio** is the visual agent builder in the Allternit platform. It lets you prototype an agent, choose its brain and parameters, bind tools, and run a test conversation before saving the configuration to the platform.

## Base URL / usage

Agent Studio runs inside the platform shell:

```text
https://app.allternit.com/shell?view=agent-studio
```

Open programmatically from shell code:

```typescript
open('agent-studio');
```

## Configuration tabs

| Tab | Purpose |
|---|---|
| **Agent** | Set name, description, system prompt, model, temperature, and max tokens |
| **Tools** | Toggle tools the prototype may call |
| **Run** | Send a test message and inspect the raw response |

## Prototype configuration

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | string | `My Agent` | Agent display name |
| `description` | string | `""` | What the agent does |
| `system_prompt` | string | `You are a helpful Allternit agent.` | System instructions |
| `model` | string | `allternit-large` | Brain model identifier |
| `temperature` | number | `0.7` | Sampling temperature |
| `max_tokens` | integer | `4096` | Token limit |
| `tools` | string[] | `[]` | Enabled tool IDs |

### Built-in prototype tools

| Tool ID | Name | Description |
|---|---|---|
| `web_search` | Web Search | Search the web for current information |
| `bash` | Bash | Run shell commands in a sandbox |
| `text_editor` | Text Editor | Read and edit files |
| `computer_use` | Computer Use | Control a desktop environment |
| `mcp_registry` | MCP Registry | Use registered MCP tools |

## Endpoints

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/v1/agents/prototype` | Save (or update, keyed by user and `name`) a draft agent with status `prototype` |
| `POST` | `/api/v1/agents` | Create a regular agent |

`POST /api/v1/agents/prototype` **persists a draft; it never executes the agent**. Drafts are stored as real agent rows with status `prototype` so they do not appear in the main agent list. To run a saved agent, call `POST /api/v1/agents/{agent_id}/runs` with `{ "input": "..." }`; the prototype response includes a copyable `curl` and `sdk` snippet for that call.

Validation: `name` must be at least 2 characters, `model` is required, and `max_tokens` must be at least 1. The body also accepts `messages`, reserved for the Run tab; a prototype save ignores it.

## Save a prototype

```bash
curl -X POST https://api.allternit.com/api/v1/agents/prototype \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Research Agent",
    "description": "Performs deep technical research.",
    "system_prompt": "You are a research assistant. Cite sources.",
    "model": "allternit-reasoning",
    "temperature": 0.5,
    "max_tokens": 4096,
    "tools": ["web_search", "mcp_registry"]
  }'
```

## Error codes

| HTTP | Code | Meaning |
|---|---|---|
| 200 | — | Prototype completed |
| 400 | `invalid_request` | Missing required fields or invalid tool IDs |
| 401 | `unauthorized` | Missing or invalid bearer token |
| 500 | `prototype_failed` | Brain or runtime error during the prototype run |
