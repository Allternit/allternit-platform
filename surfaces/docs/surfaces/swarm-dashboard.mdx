## Overview

The **Swarm Dashboard** is the operational view for multi-agent swarm health. It displays circuit breaker status, quarantined agents, and message statistics so operators can see when agents are failing, isolated, or under load.

## Base URL / usage

Swarm Dashboard runs inside the platform shell:

```text
https://app.allternit.com/shell?view=swarm
```

There is also a preview page:

```text
https://app.allternit.com/swarm-preview
```

Open from shell code:

```typescript
open('swarm');
```

API base:

```text
https://api.allternit.com/api/v1/swarm
```

## Dashboard tabs

| Tab | Purpose |
|---|---|
| **Circuit Breakers** | View per-agent breaker state and reset open breakers |
| **Quarantine** | View isolated agents and release them |
| **Statistics** | Inspect sent, received, failed, latency, and active streams |

## Circuit breaker states

| State | Meaning |
|---|---|
| `closed` | Healthy, requests flow normally |
| `open` | Failure threshold exceeded, requests blocked |
| `half_open` | Testing whether the agent has recovered |

## Endpoints

Status: the dashboard view is a UI; its data endpoints are not all backed.

The API routes that exist on `cmd/allternit-api` today (see `swarm_routes.rs`):

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/v1/swarms` | List swarms |
| `POST` | `/api/v1/swarms` | Create a swarm |
| `POST` | `/api/v1/swarms/:id/execute` | Execute a swarm |
| `GET` | `/api/v1/swarm/threads` | List swarm threads |
| `GET` | `/api/v1/swarm/health` | Swarm health |
| `GET` | `/api/v1/swarm/executions/:id` | Get an execution |

The dashboard UI calls `/api/v1/swarm/circuit-breakers`, `/quarantine` and `/messages/stats` (plus the reset and release actions). **These routes do not exist in the API on main**, so the Circuit Breakers, Quarantine and Statistics tabs have no live backend (DESIGN, not implemented). Earlier versions of this page showed request and response examples for them; those were not real contracts and have been removed.
