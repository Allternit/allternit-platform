title: Context window panel
description: What fills a session's context window, measured by the brain that runs it, plus the plan usage limits for its model.

The composer's usage meter (HUD blocks with a percent, beside the model pill) opens the **Context window** panel. It is the same panel in Allternit Desktop, the ai.allternit.com phone layout and the m.allternit.com PWA.

## What the panel shows

| Part | What it shows |
| --- | --- |
| Header | Tokens in context / the model's window, and the share used. |
| Bar | One segment per category, in the legend's colors. Deferred tools have no segment. |
| Categories | Messages, System tools, Memory files, Skills, System prompt, Repo map (the ranked file map Code turns get, see [Context Usage](/cli/context#repo-map)), MCP tools, MCP server instructions, Autocompact buffer and Free space, each with tokens and its share of the window. |
| Deferred tools | **System tools (deferred)** and **MCP tools (deferred)**: tools the brain loads only when it searches for them. They are listed with their size, but they are not in the window, so their share reads **—**. |
| MCP tools | Expands to each tool by server. The header shows the total tokens and the number of tools. |
| Memory files | Expands to each instruction file (AGENTS.md, CLAUDE.md, auto-memory) with its size and count. |
| System tools, Skills | Expand to each tool or skill with its size and count. |
| Footnote | Who measured the numbers (see below) and whether auto-compact is on. |
| Plan usage limits | The windows of the model's plan (5-hour, Weekly, per-model weekly) with reset times. The plan name shows beside the title when the provider says it, for example **Max (5x)** for Claude or **Plus** for Codex. |

Every row shows for every brain. A category the brain does not fill reads 0 (a model gizzi runs itself has no deferred tools, for example).

## Who measures it

The numbers come from whatever runs the session's loop, so they match what that brain actually holds:

| Brain | Source | Footnote |
| --- | --- | --- |
| API and local models (gizzi's own loop) | gizzi measures every request it sends: system blocks, tool schemas and messages. The provider's reported input then corrects Messages. | Estimated, or Measured by the provider |
| Claude Code (`claude-cli`) | After each turn gizzi runs Claude Code's own `/context` on the session. This is a local command, so it makes no model call and spends no tokens. It does not write to the transcript. The result includes deferred tools, MCP tools, memory files and skills. | Reported by Claude Code |
| Codex (`codex-cli`) | After each turn gizzi reads the thread's own record (`~/.codex/sessions/…/rollout-*.jsonl`). That record holds the base instructions, the developer blocks, skills, AGENTS.md and every item. The app server's `mcpServerStatus/list` gives each MCP server's tools. System tools is what the first request measured beyond the prompt blocks. When the MCP schemas are bigger than that, Codex is searching for them, so they show as deferred. | Reported by Codex |
| Kimi Code (`kimi-cli`) | After each turn gizzi reads Kimi's own session record (`~/.kimi-code/sessions/…/agents/main/wire.jsonl`). It holds the system prompt, the AGENTS.md files it read, the exact tool snapshot sent to the model (MCP tools by server) and the conversation. | Reported by Kimi |
| Qwen Code (`qwen-cli`) | After each turn gizzi runs Qwen Code's own `/context` on the session. This is a local command with no model call. | Reported by Qwen |
| CodeBuddy | Its own `/context`, the same way as Claude Code. | Reported by CodeBuddy |
| OpenCode | Its provider calls pass through a local relay in gizzi (127.0.0.1, with a per-process secret). The relay forwards each request unchanged and measures the exact system prompt, tool schemas and messages that OpenCode sent. | Reported by OpenCode |
| Signed-in apps (ChatGPT, Claude on their websites) | After each turn the gateway reads the vendor's own endpoints inside your signed-in page. It reads the conversation (messages, tool turns, attachments), memory and custom instructions, project instructions and files, skills, and the tools used or switched on. Claude's 5-hour and weekly usage feeds the plan limits. The vendor's own system prompt and tools are not shown, so those rows are estimates marked **~**. For Claude, the system prompt is Anthropic's published claude.ai prompt for the model, and the tools row is about 10.6k tokens (a measured full claude.ai prompt minus its published core). For ChatGPT, the prompt and each tool come from the measured sizes in the leaked ChatGPT prompts, with separate tables for Thinking and Instant models. Connector tool schemas that no source covers read **hidden**. | Reported by *name*'s page |
| Kimi web, Gemini web | The turns the open thread shows (Messages). The system prompt and built-in tools are estimates (**~**) measured from their leaked prompts. | Reported by *name*'s page |
| Cursor, Grok, Antigravity, Hermes CLIs | gizzi's measure of what it sends them, plus their own prompt and built-in tools estimated (**~**) from their leaked prompts. | Rows: what gizzi sends *name* |
| Other CLI brains (Kiro, Trae, Qoder…) | gizzi's measure of what it sends them. Messages comes from the brain's reported total, or from the conversation. | Rows: what gizzi sends *name* |

Between turns, a newer total from the same brain moves only Messages, so the panel keeps the brain's last full split.

The latest breakdown is saved with the session, so it survives a gizzi restart.

## API

`GET /api/v1/agent-sessions/:id/context` (gizzi `GET /session/:id/context`) returns `{ breakdown, limits }`. The breakdown fields added for this panel are all optional, so older clients ignore them:

| Field | Meaning |
| --- | --- |
| `source` | `"gizzi"` or `"brain"`. |
| `brain`, `brainName` | The brain's provider id and display name, when `source` is `"brain"`. |
| `hidden` | Rows the brain does not show (a signed-in app's own system prompt and tool schemas). The panel shows **hidden** for them. |
| `estimatedRows` | Rows filled from a published or leaked measure of the brain's hidden prompt. The panel shows them with **~**. |
| `split` | `"brain"` when the rows are the brain's own report, `"sent"` when they are gizzi's measure of what it sends the brain. |
| `categories[].deferred` | `true` for `system_tools_deferred` and `mcp_tools_deferred`: listed, not counted in `usedTokens`. |
| `skills` | `[{ name, tokens }]`, one entry per skill listed to the model. |

`GET /api/v1/providers/:id/quota` gains `quota.plan`, the subscription's name when known.
