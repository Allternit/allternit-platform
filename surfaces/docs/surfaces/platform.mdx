## Two things called "platform"

| Surface | What it is | Where it lives |
|---|---|---|
| Workspace UI | Chat, code, cowork, design and agent views. Packaged into [Desktop](/surfaces/desktop) and served as the web app. Vite + React SPA. | Separate `allternit-ai` repository (Desktop builds it via `ALLTERNIT_AI_PATH`) |
| Cloud console | `@allternit/platform-console`: organization management, compute, billing, API keys, docs, and the runtime pairing approval page (`/pair`) | `surfaces/platform.allternit.com` |

Earlier versions of this page described a Next.js 15 app in `surfaces/allternit-platform` on port 3013 with Prisma and Drizzle. That directory no longer exists on main.

## Cloud console: local development

```bash
cd surfaces/platform.allternit.com
cp .env.local.example .env.local   # add your Clerk publishable key
pnpm install
pnpm dev                           # vite --port 3016 --strictPort
```

The dev server runs on `http://localhost:3016`. `pnpm build` runs a Vite build and `scripts/postbuild.mjs`.

## Workspace UI: what it does

- Streaming agent chat with tool calls
- Code sessions, cowork teams, design view
- Agent creation and management ([Agents API](/api/agents))
- MCP server management ([MCP](/tools/mcp))

## How this relates to the Agency Kernel

Neither surface is part of the [Agency Kernel](/architecture). Both call the Cloud API and Allternit API documented under [API](/api/overview).
