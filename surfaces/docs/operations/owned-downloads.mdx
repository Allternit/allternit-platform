**Status: AVAILABLE (internal).** `runtime.allternit.com` is the public domain of the R2 bucket `allternit-runtime`. Downloads are free, and CORS is set for `ai.allternit.com` and `m.allternit.com`. Two things are mirrored there so users don't depend on GitHub or Hugging Face being reachable.

## Voice packs

The voice service (`services/voice/src/models.rs`) downloads packs from `https://runtime.allternit.com/voice-packs/v1/<file name>`. Files are flat, with the same names and the same pinned sha256 as the upstream files. If the mirror returns 404, fails, or serves a file that fails the hash check, the service falls back to the upstream URL and logs the fallback once. Setting `ALLTERNIT_VOICE_MODEL_BASE` skips both and uses `<base>/<asset path>` alone.

To (re)populate the mirror after adding or changing a pinned file, keep the manifest in `scripts/mirror-voice-packs.sh` in sync with `PACKS`, then run:

```bash
R2_ENDPOINT=https://<account>.r2.cloudflarestorage.com R2_ACCESS_KEY=... R2_SECRET=... \
  scripts/mirror-voice-packs.sh
```

Without those variables the script downloads and verifies every file, then prints the upload commands (curl SigV4) without running them.

## Desktop installers

`scripts/mirror-desktop-release.sh <version>` copies the published `Gizziio/desktop` release `v<version>` installers (dmg, exe, AppImage, deb; about 1.9 GB a version) to `desktop/v<version>/`, writes `desktop/latest.json`, and deletes every other `desktop/v*`, so only the current version is kept. Auto-update zips, blockmaps and `latest*.yml` stay on GitHub only. This keeps R2 inside the 10 GB monthly allowance. By default it prints a plan; `--apply` uploads. Credentials come from `R2_ENDPOINT`, `R2_ACCESS_KEY` and `R2_SECRET`, and it needs an authenticated `gh`.

`latest.json` looks like `{"version": "1.1.3", "assets": {"mac_arm64": "<url>", "mac_x64": "<url>", "win_x64": "<url>", ...}}`. The installer script (`install.allternit.com`) reads it first and falls back to the GitHub API and GitHub release URLs.

### Release runbook step

After publishing a Desktop release on GitHub, run `scripts/mirror-desktop-release.sh <version> --apply`. Until it runs, the installer keeps resolving to the previous mirrored version or the GitHub release.
