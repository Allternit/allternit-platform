| Topic | Page |

The receipt chain and effect receipts are internal. Nothing here is reachable through api.allternit.com.

## Current implementation

The work runtime runs inside CommRails. The drive runner, which walks a graph and spawns executors under spawn caps, is an operator command you run on purpose. It is not a daemon.
