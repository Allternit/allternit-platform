A://Labs is Allternit's set of free courses. You do not need an account. Every
lesson has a video. The courses are grouped into 7 tracks, and learning paths
list the courses in a suggested order.

The courses live at [labs.allternit.com](https://labs.allternit.com).

## Where to open it

| Where | How |
| --- | --- |
| Desktop and web app | Apps and Extensions, then the **A://Labs** card, then **Courses**. It opens in ACI, the built-in browser. |
| Phone layout | Open the drawer and tap **A://Labs**. |
| iPhone app | Settings, then **Courses**. It opens in an in-app browser sheet. |
| Terminal | Run `gizzi labs`. It prints the address, and opens it in your browser when run in an interactive terminal. |
| Any browser | Go to labs.allternit.com. |

## Your progress

Progress is saved in the browser you use. If you open the courses in a different
browser or on a different device, you start from a clean list there.
