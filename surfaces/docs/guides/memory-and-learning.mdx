**Memory and Learning** is the page behind a bot's **Memory** tile. It shows a map first, then how much is stored, then the list of memories with every action you already had.

## The map

Every box is something real: a skill the bot ran, a memory, a thread, a routine, a Soul or a person, place or topic the memory mentions. A line means one depends on the other, for example a thread that used a skill. Allternit only draws lines it can prove from your data.

- **Could change** (top): things two or more steps away that would be affected.
- **Used by**: things that rely on the focused item.
- **This item**: the focus card, with its kind, name and counts.
- **Uses**: what the focused item relies on.

On a wide screen the groups sit in columns and hovering traces the lines. **Find** searches the map. On a phone and on iOS the same groups are stacked top to bottom, with long groups cut to "+N more".

Tap a box to move focus to it. The focus card has **Open**, and either **Forget** (a memory) or **Turn off** (a skill). Before either, a confirm lists the items that could change.

The map starts on the most recently used item. An empty account shows a short explanation instead of a blank box. If the map cannot load you get a retry and the memory list below still works.

**Settings, Memory** shows the same map for your whole account, above what was already there.

## What the map cannot see yet

Skill use is recorded from chat turns. Skills that ran in other ways, such as inside a terminal session you started yourself, are not counted. A routine is linked to a skill only through the thread it runs in.

## Where the links come from

Every line on the map comes from a real record:

- A thread uses its bot's Soul, because chat reads `SOUL.md` on every message.
- A thread uses a fact when the memory recall log shows it recalled that fact.
- A fact was learned from a thread when the note it was extracted from ran in that thread.
- A fact names a person, product or place when two or more facts share that name.
- A routine uses the thread it runs in.
- A thread uses a skill once the bot runs that skill in agent chat. Skills that never ran are not on the map.

An item with no links says so. The map opens on the most recent item that has links.

Turning a skill off on a bot's Skills page hides it from that bot's skill tool. A Claude CLI brain can still reach its own personal Claude skills, because those load inside the CLI.
