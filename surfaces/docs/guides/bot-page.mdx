Open a bot and you see four tiles above its settings rows, then a **Model** row.

| Tile | Shows | Opens |
| --- | --- | --- |
| **Soul** | When the Soul was last edited | The [Soul page](/guides/bot-soul) |
| **Memory** | How many memories this bot owns | [Memory and Learning](/guides/memory-and-learning) |
| **Skills** | How many skills are on | The bot's skills, each with an on/off switch |
| **Usage** | Spend, when a real figure exists, otherwise the number of sessions in the last 30 days | The usage numbers |

A tile only shows a value that is real. While the numbers load the tile shows a quiet placeholder, and if they cannot be loaded the tile stays with no value. Spend is not recorded today, so Usage shows sessions.

The existing rows under the tiles are unchanged. On iOS the Usage page has no purchase button.
