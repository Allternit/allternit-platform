title: Make an image or GIF
description: Describe a picture or an animated GIF in Image mode
---

<Note>This device-local image flow is in development. Its app changes must pass the build train and real device checks before release.</Note>

## Ask for it

Choose Image mode and describe the picture. Your send is the request. There is no second confirm step.

The app picks how to make it, in this order:

1. Your computer's image tool, if one is set up.
2. The ChatGPT browser on this Desktop or phone.
3. A drawing in code. The app tells you when a picture is drawn in code.

If you ask for a change afterwards, the app uses your earlier briefs from the same chat as context, so you can say what to change instead of starting over.

## Sign in to ChatGPT

If the result shows **Sign in to ChatGPT**, the computer's image tool or the device's ChatGPT browser has no ChatGPT session. Sign in there, then send the request again. The app does not copy your Safari login or use an API key. A verification prompt from ChatGPT needs your attention; generation waits until you handle it.

Desktop and iPhone keep the private browser session in memory. After restarting the app you may need to sign in again. Saved images and local image history stay on the device.

## Make a GIF

Ask for a GIF in Image mode. GIFs are animated in code, so they work with any model and cost nothing extra. A GIF can also animate an earlier picture from the chat: pan, zoom or add an overlay. GIFs play in chat and in Outputs.

Limits: 640 px on a side, 15 frames per second, 8 seconds, 120 frames in all and 8 MB. The default is 480 px, 12 fps and 3 seconds. The loop is built to close, so the last frame leads back to the first.

## If a request may have been sent

A request that may already have been sent is never retried automatically. If a result says it is uncertain, check the earlier result or your ChatGPT conversation before you try again. One picture request runs for each message you send.

When the phone is locked or the app is suspended, the app does not promise to keep working. On return it checks the existing conversation before it continues.

## Gizzi terminal

Type `/image <brief>` in Gizzi. It saves a PNG in the current folder. GIFs are not available in the terminal.

## Where it is not available

A plain web page or PWA with no connected computer shows "Image mode needs a connected computer or the Desktop or phone app." It never sends the request to another computer on its own.

For the request, progress and result contract, see [Image mode engine resolver](/dev/aci-image-jobs).
