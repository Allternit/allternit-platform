---
title: "Choose how agents run"
description: "Agents need a computer. Link your own, subscribe, or run a hosted computer on credits."
---

Agents need a computer. Pick where your agents run. Chat with Allternit Cloud models stays open: it works without a computer, and your $2 of free monthly model usage still applies.

A signed-in account with no computer sees this choice the first time it opens an agent. Free accounts do not get a free hosted computer.

## The three options

| Option | Cost | What you get |
| --- | --- | --- |
| Use your own computer | Free | Link the Allternit Desktop app on a Mac, Windows or Linux computer you own. Agents run there. See [Link your computer](/guides/link-your-computer). |
| Subscribe | Plus $20, Max $100 or Ultra $200 a month | A plan with one hosted computer included. See [Computer pricing](/guides/computer-pricing). |
| Buy credits | A hosted computer billed per minute while it runs, from $0.10 an hour | A hosted computer paid from your credit balance. See [Computer on credits](/guides/credits-computer). |

Current prices are shown in the app. The numbers above are the current prices and can change.

## Chat only

Choose **Just chat for now** to skip the choice. Chat works without a computer. Agents will not run until you add one. You can pick a computer later from the banner, from Settings, or with `gizzi computers status`.

## Where hosted computers run

Hosted computers run on a third-party cloud provider, managed by Allternit. They sleep when idle.

## Check your status

- Gizzi Code: `gizzi computers status` shows your state and the three options.
- API: `GET /api/v1/account/compute-status`. See [Account compute status](/api/account-compute-status).
