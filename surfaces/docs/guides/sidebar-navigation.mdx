---
title: Sidebar navigation
description: Find recent work and adjust the familiar Allternit sidebar on desktop and phone.
---

The sidebar keeps New, Projects, Artifacts, Automation Tasks, Customize, Teammates and Recents in their existing sections.

## Recent conversations

Conversation titles can occupy two lines. Their latest message appears underneath when available. Working and unread indicators remain beside each conversation.

Use **+** beside Recents to start a session. Open **Recents actions** (the three-dot button) for **Open all recents**, **Filters**, or **Continue CLI session**. Select the Recents heading to collapse or expand the list. The same section controls apply in Code and Browser modes, with their existing mode-specific actions.

When the longer Recents list is open, **Search recents** narrows it by conversation title. Escape clears the search and returns to the shorter list.

## Sidebar width and account

On desktop, drag the sidebar edge to adjust its width. New layouts start at 286 pixels; saved widths remain unchanged. The account name and plan occupy separate lines to leave room for Inbox, Phones and Apps & Extensions. The usage meter continues to show your allowance.

## Phone and installed PWA

On ai.allternit.com at phone sizes and in the m.allternit.com PWA, navigation stays in the existing menu drawer. Recent conversation and Code session titles can occupy two lines. Rows retain their touch targets and existing actions, including swipe and reorder for conversations.

For implementation details, see [Sidebar layout](/architecture/sidebar-layout).
