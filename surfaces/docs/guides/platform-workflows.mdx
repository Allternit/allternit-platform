The agent workspace at `ai.allternit.com` and Allternit Desktop bring conversations, durable bot work, and deliverables together. The cloud console at `platform.allternit.com` manages cloud infrastructure. Desktop packages the workspace UI and a local runtime; a web workspace needs a connected runtime for host-side work.

## The work model

A **bot** is a durable worker. A **thread** is an isolated unit of work owned by a bot. A **subagent** is a delegated worker inside that work. A **project** supplies shared context and team membership. Its coordinator, **Al**, assigns and tracks threads; the bots execute them.

Artifacts are the resulting files, documents, previews, and other deliverables. A thread's history and checkpoint survive a change of model context; the context window itself is not the work record.
