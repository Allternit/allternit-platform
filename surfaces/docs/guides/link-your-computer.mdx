---

Linking your own computer is free. Agents run on that computer, using its files and tools.

## Steps

1. **Download the Desktop app** from [allternit.com/download](https://www.allternit.com/download). Install it on the computer you want agents to use.
2. **Open Allternit** on that computer. It opens a page in your browser. Sign in with your Allternit account and approve the link.
3. **Done.** The computer shows as linked. `gizzi computers status` and the app both show it as paired.

You can run the same steps from Gizzi Code with `gizzi computers link`, which prints them.

## If the browser did not open

The app shows a code. Open [platform.allternit.com/pair](https://platform.allternit.com/pair), sign in, and type the code shown in the app.

## Troubleshooting

- **The page says the code expired.** Codes are short-lived. Close the page, restart the Desktop app, and approve the new link it opens.
- **You approved but the app still waits.** Check that the computer is online, then press the retry action in the app.
- **Status shows paired but offline.** The app has not reported in recently. Open Allternit on that computer. The state stays paired.
- **Wrong account.** Sign out of the browser page, sign in with the account you use in Allternit, and approve again.
- **A paired device was removed.** Removing a device from your account returns the account to no computer. Link it again with the steps above.
