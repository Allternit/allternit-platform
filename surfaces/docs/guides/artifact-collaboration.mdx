## Comments

Open **Comments** in the artifact window header. On a phone it covers the
screen.

- Select text, cells, a slide or an element first and the comment attaches to
  it; the thread shows **On …** with what it points at.
- Replies stay in the thread. **Resolve** folds a thread away (**Resolved (n)**
  shows them again; **Reopen** brings one back). You can delete your own
  comments; the owner can delete any.
- Comments refresh every 20 seconds while the window is open.

### Ask Allternit in a comment

Write `@gizzi` or `@allternit` in a comment (or press **Ask Allternit** on a
thread that mentions it). Allternit receives the comment and what it points at
and either changes just that part, saving a new version, or answers. Its
answer appears in the thread as **Allternit**. While it works the thread says
**Waiting for Allternit…**. If it answers in the chat instead of changing the
artifact, the reply stays in the chat.

Only people who can edit can send a mention to Allternit. For everyone else
the text is saved as an ordinary comment, and an editor can press **Ask
Allternit** on it.

## What each sharing level can do

| Level | Open | Comment | Edit |
|---|---|---|---|
| Viewer | yes | no | no |
| Commenter | yes | yes | no |
| Editor | yes | yes | yes |

Docs are shared as **Viewer** or **Editor** only, so a Doc has no Commenter.
Viewers can read the comments but not add any; the Comments panel tells them
to ask the owner for more access.

## Presence

The avatars next to **Share** show who else has the artifact open right now. A
dark ring means they're editing. Presence is live only: Allternit doesn't store
who viewed what. Organization admins can turn presence off for everyone in the
org; the avatars then don't appear.

## Versions

Every autosave is a version, with who made it (**You**, **A collaborator**, or
**By Gizzi**). Editors open any version from the clock menu. Owners can pin the
version viewers see in the Share window.
