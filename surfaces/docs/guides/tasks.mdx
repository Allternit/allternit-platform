---
title: Tasks
description: Filter real work by status on Desktop, web and phone, and open scheduled work.
---

Tasks collects work from Allternit's task board. The same status filters appear in the Desktop board and table, the web phone layout, and the m.allternit.com PWA.

## Filter work

Choose **All**, **In review**, **In progress**, **To do**, **Backlog**, or **Done**.
Each count reflects the loaded tasks in the current workspace. Selecting a status changes the visible cards or rows; it does not change any task's status.
On a phone, swipe the filter row to reach additional statuses.
The Decisions section keeps requests that need your input available above the task list.

A failed Factory task can appear in Done because its execution ended. Its **Failed** label remains visible; Done does not mean success.

## Scheduled work

Choose **Scheduled ↗** to open Automation Tasks. Schedules use a separate scheduler and are not a task-board execution status.
See [Bot routines](/guides/bot-routines) for next runs, pause and resume, failures and history.

## Loading and connection errors

The board shows its loading state while fetching work. If the request fails, use **Retry** after checking your connection.
An empty filtered list means no loaded tasks have that status.
