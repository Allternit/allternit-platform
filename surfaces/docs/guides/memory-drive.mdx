---
title: Memory Drive
description: "Where your agents' memory lives: a private folder of plain notes with full history, cleaned up each night, that you can browse, edit, undo and take to other agents."
---

Everything your agents remember about you is kept in your **Memory Drive**: a private
folder of short markdown notes with a full history of every change. Chat, bots and
Gizzi all read and write the same drive, so they remember the same things.

- **One line per memory**, with the conversation it came from and the date.
- **A short index**, `MEMORY.md`, that every session reads first.
- **Every change is saved as a version.** You can see what changed, when, and by whom.
- **It uses an open format** ([Agent Memory Repo](https://github.com/AgentMemoryRepo/agentmemoryrepo)),
  so other agents such as Claude Code or Codex can read it too.

## Open it

- **Desktop:** **Settings → Memory → Memory Drive**.
- **ai.allternit.com on a phone and the m.allternit.com app:** **Settings → Memory → Memory Drive**.

All of these show the same drive.

## What's in it

| File | What it holds |
| --- | --- |
| `MEMORY.md` | The index. A few pinned lines and a link to each topic file. |
| `facts.md`, `preferences.md`, `events.md`, `procedures.md`, `people-and-things.md`, `relationships.md`, `tasks.md` | Memories, sorted by type. |
| `lessons.md` | Lessons the nightly Dream learned from your recent conversations. |
| `notes.md` | Things you saved by hand. |
| `imports/` | Memories saved before the drive existed, if you imported them. |
| `twin/` | A read-only copy of [your twin](/guides/your-twin)'s memory. Change it in **Your twin**. |

A memory looks like this:

```
- Prefers short answers. [source: /?session=s_123; added: 2026-10-06]
```

Select the source to open the conversation it came from. If that conversation was
deleted you'll see "That session is no longer available."

## Browse, edit and see history

- Pick a file to read it.
- **History** lists every change to that file. Select one to see exactly what changed.
- **Edit** opens the file. If something else changed it since you opened it, you'll be
  asked to reload before saving, so nothing is overwritten.
- **Remember something** saves a line to `notes.md` with today's date.

Deleting a memory removes it from what your agents know. The old line stays in the
drive's history, so you can see and restore it.

To remove a memory for good, open its file and select **Delete forever…**, choose the
memories, and type `delete forever` to confirm. They are removed from the drive and from
every earlier version of it, and they can't be added back. Copies someone already cloned
with a token are not affected.

The drive shows how much space it uses. A drive holds up to 2 MB and 256 files; you'll
see a warning at 80%.

## Nightly Dream

Once a night your drive is tidied in a single change called **Dream** with the date:

- Memories that say the same thing are merged.
- When two memories disagree and a recent conversation shows which is right, the wrong one is removed.
- Lessons that came up across your conversations are added to `lessons.md`.
- Memories nobody has used in 30 days or more may be removed.
- Facts about you that belong in your twin are **only suggested**. You approve them in **Your twin**.

The Dream runs between 2 and 6 a.m. in your time zone, which Allternit saves the first
time you open the Dreams section. Every change cites the conversation it is based on. Suggestions without evidence are
skipped. Open **Dreams** to read each night's report. **Undo** reverses that night's
changes and keeps anything you or your agents wrote since. If you edited a line the
Dream also changed, undo tells you which files to fix by hand. You can turn Dreaming
off in the same place.

When you select **Run now**, each step shows as it happens: reading your memories and recent
messages, asking the model what to merge, learn and prune, checking that plan against your
memories, and saving. Select **Steps** on any past Dream to see the same list.

## Shared drives

Next to your own drive you can open drives for a **team** (workspace), a **project**,
a **bot** or a **swarm** you own or belong to. Each is separate: nothing is copied
between drives. Team members can write; members with the viewer role can read.
Removing someone from the workspace removes their access right away.

Team, project and swarm drives have a **Questions** board. Agents and people can ask a
question, answer it and mark it resolved, in Settings → Memory, with
`gizzi memory ask` / `answer`, or through the `memory_ask`, `memory_answer` and
`memory_questions` tools available to bots.

A bot's drive holds what that bot remembers, and a project's drive holds the project's
memory, in `memory.md`. Saving, forgetting or moving a bot's memory changes its drive, and
editing the file changes what the bot knows.

## Move memories you already had

When you have memories from before the Memory Drive, your **Needs you** inbox shows
"You have N saved memories from before the Memory Drive." Select **Review** to open the
import.

If you used Allternit before the Memory Drive, open **Import existing memory**. You'll
see what would move and anything that would be skipped (for example, text that looks
like a password) before anything changes. **Import** saves it all as one change.
Running it again does nothing. Your old memories stay visible for 30 days after the
import and are then hidden. They are not deleted.

## Bring your memory from your logins in one tap

If you've connected ChatGPT, Claude, Kimi, Gemini or Copilot in **Settings → Connections**, the quickest way to
bring your memory over is **Bring your memory from your logins**. It lists each connected login.

1. Select **Bring my memory from ChatGPT** (or Claude, Kimi, Gemini or Copilot).
2. Allternit opens a new, regular chat in that account on your Sessions computer and asks it to
   list everything it knows about you. Your saved memories and custom instructions there apply,
   because it's your own account. It usually takes under a minute.
3. The answer opens in the preview. Untick anything you don't want, then select **Import**.

The chat stays in that account's history like any other chat. A login that's signed out or
needs a check can't be tapped until you fix it in **Settings → Connections**; if the
assistant asks for a check mid-way, open it on your Sessions computer, finish the check, and tap
again. Gemini and Copilot logins are best effort: their connections aren't verified against the live
services yet, so if one doesn't answer, use the prompt below instead.

### Keep it current by itself

With **Keep memories from your assistant logins** on (under **Where your memories come from**,
on by default), Allternit reads your signed-in logins every few hours without asking the assistant
anything:

- **Saved memories and custom instructions**, copied word for word from the assistant's own
  settings. They land in `imports/<assistant>.md` with the source `<assistant>:memory`.
- **New chats** since the last read, up to 20 each time. Only your own messages are read, by the
  same model as a chat-history import, and what's worth keeping lands in
  `imports/<assistant>-chats.md`, citing the chat it came from.

It only reads: it never types, clicks or sends a message, and it waits when that login is busy with
a chat. Only logins whose notice you accepted in **Settings → Connections** are read. A memory you
removed is never brought back. **Read my logins now** runs it right away, and the list under the
switch shows what each login's last read found, or why it couldn't read (for example, a
verification check to clear on your Sessions computer). Each read is also a row in **Activity**.
Today ChatGPT and Claude can be read this way. Kimi, Gemini and Copilot show "can't read yet" until
they can.

## Bring memories from another assistant

Open **Bring memories from another assistant** in Settings → Memory and pick where they're
coming from: **ChatGPT**, **Claude**, **Gemini**, **Grok**, **Copilot**, **Perplexity**,
**Meta AI**, **Kimi**, **Le Chat**, **Mem0** or **Something else**.

1. Select **Copy prompt** and send the prompt in a new chat with that assistant. It asks the
   assistant to list everything it knows about you, one fact per line.
2. Paste its answer into the box, or upload a `.txt`, `.md` or `.json` file.
3. Select **Preview**. Untick anything you don't want, then select **Import**.

For **Mem0**, export your memories as JSON from Mem0 and upload the file.

You can also paste a saved-memory list directly:

- **ChatGPT:** Settings → Personalization → Memory → Manage. Copy the list.
- **Claude:** Settings → Memory. Copy what it remembers.

Preview shows what will be added and what is skipped (duplicates, things already remembered,
anything that looks like a password). **Import** saves the memories you ticked as one change in
`imports/`, one file per assistant (for example `imports/gemini.md`).

Some assistants, such as OpenAI's Dots, Grok Bot and Meta's Muse agent, don't let you see or
export their memory. Asking them with the prompt is the only way, and only works where the
assistant answers it.

## Bring memories from your chat history

If you've used ChatGPT, Claude, Gemini or Grok for a while, your chats say a lot about you. Get the
chat export from that assistant, then upload it in **Bring memories from your chat history**:

- **ChatGPT:** Settings → Data controls → Export data. ChatGPT emails you a ZIP.
- **Claude:** Settings → Privacy → Export data. Claude emails you a ZIP.
- **Gemini:** takeout.google.com → My Activity → Gemini Apps. Google emails you a ZIP.
- **Grok:** accounts.x.ai → Data → Download your data.

Upload the ZIP as it came, or the conversations file inside it. The file is opened on the device
you're using, and only your side of each chat is sent to the computer that holds your drive. The
assistant's replies and any images stay out.

Choose how many conversations to read (the newest 50, the newest 200, or all of them), then select
**Find memories**. The memory model on that computer reads them a few at a time and suggests
memories, and the page shows its progress. Keep the page open until it finishes, or select
**Stop** to keep what it found so far. Bigger histories take longer and use more of that model.

Select **Review**, untick anything you don't want, and select **Import**. Each memory cites the
conversation it came from, and they're saved in one change to a file such as
`imports/chatgpt-chats.md`. Nothing is saved before you choose Import.

Large exports work best on a computer; a phone may not have the memory to open them.

## Bring memories from agents on your computer

If you use **Claude Code**, **Codex**, **Hermes** or **OpenClaw** on the computer that holds your
drive, **Bring memories from agents on your computer** lists the ones it found and how many
memories each has. Select **Preview** next to one, untick anything you don't want, and select
**Import**. Allternit reads only those agents' memory and instruction files:

- **Claude Code:** your `CLAUDE.md` and each project's saved memories.
- **Codex:** your `AGENTS.md` and Codex memories.
- **Hermes:** `USER.md` and `MEMORY.md`, for every profile.
- **OpenClaw:** `USER.md` and `MEMORY.md` in its workspace.

Each memory keeps the file it came from as its source. One import takes up to 500; if there are
more, preview again after importing to bring in the rest. Cursor no longer keeps memories, so
there is nothing to import from it.

## Where your memories come from

Besides your chats in Allternit, **Where your memories come from** in Settings → Memory lists the
other places that add to your drive. Each has its own switch:

- **Your messages to your bots** (on by default). What you send your bots on Telegram, WhatsApp,
  Discord, Slack, Teams, text messages and email. Only messages from you count. Allternit knows
  they're yours because you verified that account or phone number, or because it's your
  account's email address. It works whether or not a bot answers in that chat. What other people
  send your bots never becomes your memory. Each
  memory cites the chat it came from, such as `telegram:chat/…`.

  To verify an account, open **Settings → Notifications → Factory approvals on your channels**,
  pick the account, choose **Use this account for approvals**, and send `verify <code>` from it
  within 15 minutes. Until one is verified, the switch says so and nothing from that channel is
  captured.
- **Gizzi in the terminal** (on by default). What you type in Gizzi, so the nightly Dream can
  learn from it. Gizzi saves memories itself as well.
- **Keep importing from agents on your computer** (on by default). A few minutes after Allternit
  starts, and then every few hours, it imports new memories from Claude Code, Codex, Hermes and
  OpenClaw on the computer that holds your drive. Anything already in your drive is skipped. To
  stop, turn the switch off; to prune what it added, use **Forget** below.

Below the switches, **Memories by source** shows how many memories each source added: an
assistant you imported from, an agent on your computer, or a channel. To take a source back out,
select **Forget** next to it and confirm. Its memories are removed in one change and stay in the
drive's history, like any delete.

Incognito chats are never remembered, from any surface.

## See what touched your memory

In a chat, the turn shows what Memory Drive did, the same way it shows searches and commands:

- **Searched Memory Drive** lists the memories the reply used.
- **Saved to Memory Drive** lists what was remembered from the turn, with where it came from.
  Saving finishes a few seconds after the reply, so this row can appear just after it.
- When Gizzi or an agent uses its own memory tools, those calls read the same way.

Under **Activity**, Memory Drive lists everything that touched your memory, newest first:
saves, uses in chats, removals, imports, reads from your assistant logins, and Dream steps. Use
the buttons above the list to show one kind. Select a row to see the memories in it. Activity
keeps 90 days of rows and never includes incognito chats.

## Your ledger

Your memories are one part of what you build in Allternit. **Your ledger**, also in Settings →
Memory, keeps the rest as plain files with history, next to your memories:

| Folder | What's in it |
| --- | --- |
| `bots/` | Each bot's settings, plus its workspace files (`SOUL.md` and the rest) |
| `agents/` | Agents that aren't bots |
| `bot-templates/` | Bot and team templates you made |
| `routines/` | Routines and scheduled messages |
| `workflows/` | Workflows, with their steps |
| `tasks/` | Open tasks |
| `skills/` | Installed skills (`SKILL.md` folders) and skill recipes |
| `projects/` | Projects and their instructions |
| `schedules/` | Scheduled tasks, loops and scheduled runs |
| `connected-apps.json` | Which apps and accounts are connected. Only the account, never its sign-in |

Allternit saves the ledger every hour, and only when something changed. Select **Save now** to
save it right away, **Browse files** to read any file, or **Download (.zip)** to keep a copy.
**Changes** lists each save and which files it changed.

Passwords, keys and sign-in tokens are never written to the ledger. Values stored under names like
`api_key` or `password` are replaced, links to private git repositories lose their password, and
a file that still looks like it holds a key is left out and listed in the ledger's `README.md`.

### Edit through the ledger

The ledger's files are the real thing, not just a copy. Open a file under **Browse files** and
select **Edit**:

- **A bot, agent, routine, workflow, template, task, project or schedule** (`….json`): saving changes
  it in Allternit. For example, set a routine's `"status"` to `"active"` to turn it back on after a
  restore, or rewrite a bot's instructions.
- **A bot's workspace file** (such as `SOUL.md`) or **a file in an installed skill**: saving writes it
  where the bot or skill reads it.

A few things stay as they are. A record's `id` can't change. Values shown as `[left out: …]` keep what's
stored. Allternit refuses keys and passwords typed into the ledger, so set those in Allternit's
settings. Runtime details such as the next run time are worked out by Allternit, not read from
the file. Each save is recorded in **Changes**.

To **make something new**, open one like it and select **Duplicate**. Change the copy and select **Save**:
it's created with a new id, and routines and schedules start paused. To **remove something**,
select **Delete** and confirm. Bots and agents are archived, other things are deleted, and either way
the earlier file stays in the ledger's history. A skill's `SKILL.md` can't be deleted here; uninstall
skills in Customize → Skills.
Changes made in a folder or repository copy come back too (see **Keep a copy where you want**).

### Restore from a ledger

To bring a ledger into this account, for example on a new computer or in a new account, select
**Choose a ledger (.zip)** under **Your ledger** and pick the `allternit-ledger.zip` you downloaded.
A zip of a folder copy works too. Allternit shows what it will do before anything changes:

- what it will add, and what's **already here**;
- what can't be restored, and why (for example, another account on this computer already has it);
- settings to fill in again: values the ledger left out, such as an API key, are never written back;
- apps to reconnect: sign-ins are never in a ledger.

Select **Restore** to add everything listed. Routines, scheduled messages and schedules come back
**paused**, so nothing starts running on its own; turn them back on when you're ready. Bot
workspace files and skills are only added: an existing file is never replaced. Restoring the
same ledger again adds nothing new.

## Keep a copy where you want

Your Memory Drive and ledger live on the computer that holds your drive (Allternit Desktop, or your
cloud computer). **Keep a copy where you want** in Settings → Memory adds a copy somewhere you
choose, updated every hour:

- **A folder on that computer.** Type its full path, such as `/Users/you/Dropbox` or your iCloud
  Drive folder, and select **Copy here**. Allternit writes an `Allternit` folder inside it, with
  `memory/` and `ledger/`, and keeps it in step. It only changes or removes files it wrote itself.
- **Your own git repository.** Create an empty private repository (GitHub, GitLab, or any host that
  takes HTTPS), paste its HTTPS address and an access token that can push to it, then select
  **Copy to this repository**. Your memories go to the branch `allternit-memory` and your ledger
  to `allternit-ledger`. The token is stored sealed on that computer and never shown again. Paste
  a new one to replace it.

**Changes you make in a copy come back.** Edit, add or delete a file in the folder, or commit to the
`allternit-memory` or `allternit-ledger` branch, and the next copy brings the change into Allternit.
It goes through the same rules as editing in Allternit: memory lines are checked, ledger files change
the real bot or routine, new files create things (paused for routines and schedules), and deleted
files delete them.

If a file changed **in both places** since the last copy, Allternit keeps its version and saves yours
beside it: as `….conflict-<time>` in the folder, or on a branch named `allternit-conflicts/…` in your
repository. Nothing is lost.

Select **Copy now** to copy right away. Each copy shows when it last worked, how many changes it
brought in, any conflicts, and anything it couldn't bring in and why. Select **Stop copying** to
stop; copies already made stay where they are.

**Delete forever** removes memories from your drive and its history, but not from copies you
keep elsewhere. Delete them there yourself, or stop the copy first.

## Use it from other agents

Select **Clone this drive** to get the drive's address and create a token:

- A **read** token lets an agent load your memory.
- A **write** token also lets it save new memories.

The token is shown once. Copy it then. The address never contains the token. Revoke a
token any time from the same list; it stops working immediately.

For Claude Code, install the Allternit Memory Drive plugin. For other agents, give them
the token through a git credential helper, never in the address:

```sh
export ALLTERNIT_MEMORY_TOKEN=allternit_git_…
git -c credential.helper= \
  -c 'credential.helper=!f() { echo username=x-access-token; echo "password=$ALLTERNIT_MEMORY_TOKEN"; }; f' \
  clone <drive address> memory
```

Every change pushed to your drive is checked first. It's refused if it isn't in the
memory format, looks like it contains a password or key, rewrites history, or edits
`twin/`.

## In Gizzi

Gizzi keeps a copy of your drive on your computer and reads `MEMORY.md` at the start of
every session. What it remembers is saved to the drive and synced. If you're offline or
signed out, it saves locally and syncs when you sign in. Run `/memory` to see the
drive, recent changes and sync status. See [gizzi memory](/cli/memory) for the commands.

## Where it lives

Your Memory Drive is stored on your computer: Allternit Desktop, or your cloud computer.
On ai.allternit.com and the phone app it is reached through that computer. If none is
online, Settings → Memory says so; open Allternit Desktop or start your cloud computer.

## Keep in mind

- Agents never save anything that looks like a password, key or card number.
- Incognito conversations are never used as a source.
- Memory you delete stays in the drive's history. Anyone you give a read token to can
  see that history.
