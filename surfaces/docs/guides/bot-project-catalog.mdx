---
title: "Bot project catalog"
description: "Explore bot projects and distinguish discovery from connection support."
---

Open Gateway settings or **Create bot → Bring a vendor’s bot** to explore the bot project catalog. Search by project or developer and filter by availability. The same catalog appears on Desktop, web and phone.

Existing vendor connection cards appear separately above the catalog. Their connection state comes from your runtime and account. The project catalog contains 33 discovery entries; it does not add adapters for those entries.

- **Planned:** the project identity has been checked; its adapter is not available.
- **Researching:** the project identity or connection method is still being checked.
- **View project:** opens a verified upstream project in a new tab.

Catalog entries do not request credentials or create bots. Official marks identify projects where assets have been sourced; other entries use initials. Similar names from different developers are kept separate.

Use **Brains** to choose a model. Connecting another agent system is a separate operation with its own permissions, runtime and account. A listing in this catalog does not establish affiliation or full feature support.
