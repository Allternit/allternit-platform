title: Connections
description: "Settings → Connections: one page to connect your AI, your computers, your phone, your coding tools, your voice keys, your apps and your messaging channels, with four status words and a fallback for anything that is not available."
---

**Settings → Connections** is one page for everything Allternit can work through. Each thing is one row. You tap a row, a sheet shows the few steps for that row, and the row comes back by itself when you are done. It replaces **Settings → Subscriptions**, **Settings → API Keys** and the separate connect screens. Anything you set up before is still there.

Connections is the same on Allternit Desktop, ai.allternit.com, the phone layout, the m.allternit.com app and the iPhone app (Settings › Connections, no new tab). In the terminal, `gizzi connect` lists the same rows with the same words. A few steps need Allternit Desktop, because they talk to a phone or a computer near you; those are marked below.

## The four status words

Every row shows one of four states. There are no others.

| State | The row says | What it means |
| --- | --- | --- |
| Off | **Not connected** · what it is for | Nothing is set up yet. Tap to connect. |
| Connecting | **Connecting…** | A sign-in is waiting for you or for the vendor. The row finishes by itself. |
| On | **Connected** · what was found | It works. The row says what it found, for example the plan name or "Key works". |
| Needs you | **Needs you** · the reason | It worked before and needs one thing from you. The reason is in plain words, for example "Sign-in expired" or "The key was rejected". |

A row that your account cannot use right now shows why, in one line, and up to two buttons for another way to get the same thing. It never shows a **Connect** button that would fail. There are no "I entered it" or "I'm signed in" buttons anywhere: the row checks for itself.

## The groups

| Group | What it holds |
| --- | --- |
| **Your AI** | Allternit Cloud, your AI plans (ChatGPT, Claude, Grok, Kimi, GitHub Copilot), Gemini, API keys, and a local brain. |
| **Computers** | Your Allternit Cloud computer, your Mac or PC, and your own server. |
| **Phones** | Your phone, and letting Allternit use your phone. |
| **Coding tools** | Gizzi Code, Claude Code, Codex, Gemini CLI, Cursor Agent and the other command-line tools on a computer. |
| **Voice** | Your own OpenAI and ElevenLabs keys for voice. |
| **Apps** | Gmail, Google Drive, Slack, GitHub, Notion and other apps your bots use. |
| **Channels** | Telegram, WhatsApp, Discord and the other places your bots answer. |

Inside **Your AI**, rows are split three ways so you can see what works for you:

- **Works on any device.** Allternit Cloud, API keys, Gemini, and your Claude, ChatGPT, Grok and Kimi plans. A plan runs in a private box on an Allternit server ("Runs on Allternit · no computer needed"), so it works on your phone, the web and Desktop with no computer.
- **Needs your computer.** The coding tools and the local brain.
- **Coming soon.** GitHub Copilot, until it is turned on for your account. Then you sign in with GitHub and it works with no computer.

## What works with no computer

| Works on any device, no computer | Needs your computer |
| --- | --- |
| Allternit Cloud (included) | Coding tools: Claude Code, Codex, Grok CLI, Kimi CLI, Gemini CLI, Cursor Agent |
| Your Claude, ChatGPT, Grok and Kimi plans (on an Allternit server, chat only) | Local brain (Ollama) |
| API keys: OpenAI, Anthropic, Google, xAI, OpenRouter and more | Letting Allternit use the apps on your computer |
| Gemini through a free Google AI Studio key | |
| Apps and channels (Gmail, Slack, Telegram and the rest) | |
| Voice keys saved to your account | |
| Your phone | |

Each plan runs in a private box on an Allternit server. The box runs the vendor's own command-line program. You sign in to the vendor yourself and manage your own account with the vendor. Your plan answers only messages you send yourself, in chat, with tools off. Bots, routines, schedules and agents never use it; use an API key for those.

Before the first connect, the sheet shows the risk and asks you to accept it: the vendor's terms may not allow using a plan this way, and the vendor could limit or close your account. Allternit cannot control or undo that. The full text is in [Use the AI plan you already pay for](/guides/use-your-plan#the-risk).

A plan row is turned on one vendor at a time. A row that is not on yet says "Not available yet. Use a key for now." and offers the key row. An older app says "Update the app to connect this plan." The GitHub Copilot row says "Coming soon." and offers GitHub. Chats with a plan model are saved to your account in the cloud, so they show on your other devices.

## Connect something

Tap a row. The sheet shows the steps for that row. The steps are the fewest the vendor allows, and the row finishes by itself when you are done.

| What | Steps | How it finishes |
| --- | --- | --- |
| An app (Gmail, Slack, GitHub, Notion) | Continue to the app › Authorize › Done | You come back by yourself after the vendor's page |
| A plan on an Allternit server (Claude, ChatGPT, Grok, Kimi) | Read the risk and tap **I understand, connect** › the sign-in step below › Done | The row checks and finishes. Claude: open the link, approve, paste the code the vendor shows. ChatGPT and Grok: open the link and confirm the code. Kimi: one of these two |
| ChatGPT on Desktop, the iPhone app or Gizzi Code | Read the risk › sign in on OpenAI's page › Done | The page returns to the app and the row finishes. Your sign-in stays on the device |
| Grok on a computer | Open Grok (the code is already in the link) › Confirm › Done | The row checks and finishes |
| ChatGPT on a computer | Open ChatGPT (the code is copied when you tap) › Paste the code › Done | The row checks and finishes |
| Claude Code on a computer | Open Claude › Approve › Copy the code › Done | Allternit Desktop reads the code from your clipboard when you come back. On the web you tap one **Paste** button |
| An API key | Open the key page › Paste › Done | The key is checked with the vendor before it is saved |
| Your phone | Scan the QR code, or tap **Text me the link** | The row checks and finishes |

Allternit checks an API key with the vendor before it saves it, saves it encrypted, and never shows it again. You see only the last few characters. If the vendor rejects it, the row says **Needs you · The key was rejected**.

Allternit never sees your password for a plan or an app. Plan sign-ins happen on the vendor's own page. For a plan on an Allternit server, the sign-in is kept in your private box and Allternit does not copy it anywhere else. For ChatGPT on your own device, it stays on the device. See [Use the AI plan you already pay for](/guides/use-your-plan).

### When a row needs you

| The reason says | What to do |
| --- | --- |
| Sign-in expired | Tap the row and sign in again. |
| The key was rejected | Open the key page, copy a new key and paste it. |
| The vendor limited this plan | The vendor has limited your plan for now. Use a key, or try again later. |
| Needs your own computer for now | Connect a computer, or use the key shown as the fallback. |
| Not available yet | Use the fallback button on the row. |
| Update the app to connect this plan | Update the app, or use the key shown as the fallback. |
| Busy. Try again | Allternit's plan boxes are all in use. Wait a moment and tap the row again. |
| Your computer is offline | Turn the computer on and connect it to the internet. The row updates by itself. |
| Could not start. Try again | Tap the row and try again. |

### Setting up on the first day

The first-run setup has four steps: your AI, your phone, your main bot, and connected. There is no computer step. If you need a computer later, **Add a computer** is offered as "Later, if you need it". See [Use the AI plan you already pay for](/guides/use-your-plan) for which plans work where.

## Remove a connection

Open a row and choose **Remove**. A row from your account is removed from your account. Removing a plan signs you out of the vendor and deletes your sign-in from your private box; removing your last plan deletes the box. A row on a computer is removed from that computer only.

## Ways a bot reaches an app

A bot can reach the same app in up to four ways. Each app row lists the ways that exist for it, most reliable first:

1. **Connector.** The app's own API through an MCP connector. See [Connectors](/guides/connectors).
2. **Phone app.** The app on a phone you linked, already signed in. See [Phone Link](/guides/phone-link).
3. **Desktop app.** The app installed on your computer.
4. **Browser sign-in.** A sign-in in a separate browser profile on this computer or on your Sessions computer.

The order is fixed. When a task starts, Allternit uses the first way that is connected and working, and marks it **Used first**. If it stops working, the next task moves to the next working way. A task that is already running does not switch partway through.

To always use one way for an app, open the app and choose **Pin** on that way. A pinned way is used first while it works. Choose **Unpin** to go back to the fixed order. A way that is not working can't be pinned.

## What the drawer shows

Click an app row to open its drawer. For each way it shows:

- **Health:** working, needs you (for example, sign in again or unlock your phone), or offline.
- **Last worked:** when a task or check last succeeded through it.
- **Plan left:** what the vendor reports about your plan's remaining use, when it reports it.
- **Last 7 days:** how many tasks went through it, how many finished, and the typical reply time.
- **Recent tasks:** the latest tasks that used it, with their result.

A number that has no data behind it is shown as a dash, not as zero. A new connection shows dashes until it has been used.

## Checks for every app on a phone

Every app on a linked phone gets a check, not only the AI chat apps (Allternit Desktop runs it). A phone way shows:

- **Signed in or not:** **Not signed in** when the app opens on its sign-in screen. Choose **Open on phone**, sign in there yourself, then **Check**.
- **Account:** the email, @handle or name the app shows for your own account.
- **Plan and usage:** for apps that show them, the plan name (such as Free, Plus, Pro or Max) and each usage window, such as **5-hour**, **Current** or **Weekly**, with the percent left and when it resets.

Allternit opens the app, reads its first screen, then opens the app's own profile, settings or usage screen, reads it, and goes back to the Home screen. It scrolls a long settings list to find a row further down. It only taps entries such as **Settings**, **Account**, **Profile** or **Usage**, and Back or Close. It never types, never changes a setting, and never taps anything that signs out, deletes, upgrades, buys, subscribes or cancels.

Each check opens the app on your phone, so Allternit keeps them rare. It checks each app once when it first sees it on a linked phone, and right after the wizard's **Check** finds an app signed in. After that, only signed-in AI chat apps (Claude, ChatGPT, Gemini and the like) are checked again on their own, about every 6 hours, because their usage changes. Other apps are checked again only when you choose **Check**. A background check waits until the phone has sat on its Home screen for a few minutes, so it doesn't open apps while you're using the phone. It also waits while the phone is locked or offline, while a bot is using it, and while you're watching its live screen, and it checks one app at a time. A check that can't read the account keeps the last one it read. A fact the app doesn't show, or that Allternit can't read for certain, is shown as a dash. Allternit doesn't guess it.

A phone way says **Verified reader** when the app's path was checked on a real phone of that kind. These were checked in October 2026 on an iPhone and an Android phone, with every settings page scrolled:

| App | Account | Plan | Usage | Checked on |
|-----|---------|------|-------|------------|
| Claude | Email | Yes | 5-hour, Weekly, and Weekly per model (for example Weekly (Fable)) | iPhone |
| ChatGPT | Email | Yes | Weekly (Settings › Usage and limits) | iPhone |
| Gemini | Email | The free tier names no plan | Current and Weekly (Settings › Usage limits) | iPhone |
| Discord | Email | – | – | iPhone, Android |
| Instagram | Username | – | – | iPhone, Android |

Every other app, and an app on a kind of phone it wasn't checked on, gets the sign-in check: signed in, or **Not signed in**. Kimi and Perplexity try the usual ways through their menus until a signed-in phone is checked. If a phone way still shows dashes after a check, open the app on the phone once to make sure it is signed in and has finished loading. The next check picks the facts up.

## More than one account

You can connect more than one account to the same app, for example a personal and a work Gmail, or two Claude Code sign-ins. Open the app (or the coding tool) and look at its **Accounts** block:

- Each row shows who it is signed in as, a **Default** chip on the account bots use when nothing else is said, a status dot, and the way it is connected (**Connector**, **Browser sign-in**, **Phone app** with the phone's name, or the coding tool).
- **Add another account** signs in a second account. If the app can add through more than one way, you first choose which (**Connector** or **Browser sign-in**). Phone apps are listed one per phone and are changed on the phone.
- **Make default** moves the Default chip to that account. **Rename** gives an account a name you recognize. **Remove** asks first, then signs that one account out and leaves the others. If you remove the default, the most recently used one becomes the default.

When a bot needs an app, it uses the account in this order:

1. **The account you name in the request.** "Send it from my work Gmail" or "use the account ending in @acme.com" picks the account whose email or name matches. If no account matches, the bot says so and lists the accounts it has; it does not fall back to another one.
2. **The bot's own account for that app.** In a bot's **Connected Apps**, an app with more than one account gets an account menu. Leave it on **Default account** to follow your default.
3. **Your default account.**

**A bot's brain.** The same order applies to the account a bot's brain runs on. A bot whose brain is a coding tool (Claude Code, Codex) or a subscription model (ChatGPT, Claude, Kimi and the like) gets an **Account** menu in its brain settings when you have more than one sign-in for it; leave it on **Default account** to follow your default. If the chosen account can't be used right now (signed out, or out of its plan's limit), the bot's reply says so and asks you to pick another account in the bot's settings. It never switches to another account on its own. See [Bots](/surfaces/bots).

**Coding tools.** Under Settings › Connections › Coding tools, a tool that can hold several sign-ins (Claude Code, Codex and Gemini CLI where the installed version supports it) shows **Add another account** under its row. Give the account a name such as Work, then sign in with the same link or code as the first time. The first account keeps the tool's own sign-in; added accounts keep their sign-in in their own folder under `~/.allternit/cli-homes`, so they never overwrite each other. Tools that can hold only one sign-in don't show the button.

An Allternit server older than this feature shows each connector's one account without **Add another account**, **Make default** or **Rename**.

## Coding tools

The Coding tools group is only for CLI brains: Claude Code, Codex, Grok and the other command-line tools Allternit can install and sign in on a computer. See [Coding tools on any computer](/guides/subscriptions#coding-tools-on-any-computer) for the steps.

- **On this computer** lists the tools that are installed, ready ones first, with **Sign in** or **Sign in again**.
- **Add a coding tool** at the bottom shows every other tool Allternit supports: Gemini CLI, GitHub Copilot CLI, Aider, Amp, Goose, Crush, Cline, Kilo Code, Factory Droid, Augment Auggie, OpenHands, Continue and more. **Install** runs a pinned installer, then the same sign-in.
- **Add your own** registers a CLI that isn't listed. Give its command and how it takes a prompt (for example `-p {prompt}`), and optionally a model flag, a sign-in check and an install command. It then installs, signs in and works as a brain like the others, and you can remove it any time. Custom tools are only available on your own computer, not on a shared hosted runtime.

Two kinds of brains live elsewhere:

- **Local models** on your own computer are under **Settings → Models**.
- **API providers** (an API key from a model provider) are under **Settings → API Keys**.
