Every project opens as a dashboard of what is going on in it. New projects start on **Pulse**, in the **Quiet orange** colors: white and gray, with one color for what needs you.

## Customize

**Customize**, at the top right of a project, is the one place for a project's look and settings. Each pick applies at once, so the dashboard behind it is your preview. Press **Done** to close it.

| Tab | What it does |
|---|---|
| Layout | Pick a layout from live previews, or make your own |
| Colors | Quiet orange, Quiet blue, Quiet green, Black and white, Bright, or Sunset |
| Background | Pick the moving background. It fills the page behind every layout |
| Tiles | Turn the parts of the current layout on or off |
| Details | Icon and color, plus the settings for this kind of project |
| Manage | Edit details, archive, save as template, and delete |

Each project keeps its own choices.

## The layouts

| Layout | What it shows |
|---|---|
| Pulse | An activity chart, a month calendar of deadlines, and a stream of changes |
| Bento | Blocks of different sizes with everything at a glance |
| Mission control | A dark panel with progress, crew, next events and a live log |
| Scoreboard | Four tall columns with large numbers |
| Cover story | The status page as a story, with the full page to edit below it |
| Runway | Work as bars on the way to your deadlines |
| Board | Work in Queued, Working, Needs you and Done columns |
| Crew | A large card for each bot on the project |
| Orbit | The project in the center, with bots and their work around it |
| Gallery | What the project made, as large tiles |

## Make your own

Under **Layout**, describe what you want in **Make one** and press **Build it**. For example, type "just decisions and dates". Allternit picks the matching tiles and saves the result as **Yours**. Change it later under **Tiles**.

**Make one** matches your words to the tiles that exist. It does not design new tiles.

## Where the numbers come from

The dashboards show real data and nothing else:

- Countdown and calendar come from dated lines in the **Deadlines** section of the [status page](/guides/project-status). Write one per line, such as `Nov 14: launch`. A line without a date still lists, but it does not count down.
- Progress counts the project's threads, tasks or sessions.
- Activity counts changes per day over the last 14 days.
- Decisions come from threads waiting on you and the status page's next action.

A project with no deadlines shows no countdown. A tile with nothing to show says so.

## Your chats and sections

Under the dashboard you find the project's chats, tasks or sessions. Bot projects also show their threads there, and the updates from the coordinator. **Memory, files and more** opens the remaining sections with their controls. The composer stays at the bottom of the page.

Chat, Code and Design projects open on the dashboard on a first visit. **Dashboard** in the project header brings it back after you open another pane.

## Phones

Desktop, ai.allternit.com and the m.allternit.com app use the same layouts. Below a width of 620 pixels, tiles stack in one column, and a docked pane has the same effect.
