Open **Settings, Memory** on Desktop, ai.allternit.com (including the phone layout) and the m.allternit.com app. On iPhone it is **Settings, Memory**. **Customize, Skills** also has a **Memory** card that opens it.

## About you

Your twin profile, plus **What Allternit knows about you**: a short summary built from your twin context. See [Your twin](/guides/your-twin).

## Memories

One list holds everything remembered about you:

- Items from your twin, marked **Twin**.
- Facts learned from your chats, marked **Learned**.

You can search the list, edit an item and delete it. Editing a learned fact replaces it with a new one, so its id changes.

## Search and reference chats

**Search and reference chats** controls whether Gizzi looks through your past conversations. Allternit stores every turn you and your agents have (your messages, the replies and tool calls) for everyone, whether or not Sleep is on. On each chat turn, with the switch on, Gizzi adds a short, dated **From past chats** block to what the assistant reads, so it can use what was said before. Turn the switch off and the block is not added. Incognito chats are never stored or searched.

Under a reply, memory chips group what was used: saved memories, and **From past chats** with the date of each turn (web, Desktop, m.allternit.com, iPhone and Android).

## Knowledge

**Knowledge** lists what your agents want to learn and the curator has proposed. You approve or reject each one. See [Knowledge factory](/guides/knowledge-factory).

## Drive

The **Drive** section is unchanged. See [Memory Drive](/guides/memory-drive).

## From the terminal

```bash
gizzi memory list [--source twin|facts] [--json]
gizzi memory edit <id> "<text>"
gizzi memory forget <id>
```

See [gizzi memory](/cli/memory).
