## Prerequisites

Before you begin, ensure you have the following:

- Node.js 18+
- Git
- An API key from [platform.allternit.com](https://platform.allternit.com)

## Install Gizzi Code

Gizzi Code is the unified Allternit CLI. Install it globally:

<CodeGroup>
```bash npm
npm install -g @allternit/gizzi-code
```

```bash yarn
yarn global add @allternit/gizzi-code
```

```bash pnpm
pnpm add -g @allternit/gizzi-code
```

```bash bun
bun add -g @allternit/gizzi-code
```
</CodeGroup>

Or use the one-line installer for the full BYOC runtime:

```bash
curl -fsSL https://install.allternit.com | bash
```

## Talk to the public API

Production clients use the Cloud API only:

```
https://api.allternit.com
```

Allternit API on `:8013` is the private data plane (desktop / your VPS / a provisioned instance). See [API Overview](/api/overview).

## Authenticate

Set your API key so Gizzi Code can talk to the Allternit platform:

```bash
export ALLTERNIT_API_KEY="your_api_key_here"
```

For persistent configuration, run:

```bash
gizzi auth login
```

`gizzi auth status` shows which credentials are active.

## Start the interactive TUI

Launch the terminal user interface and start an agent session:

```bash
gizzi
```

From the TUI you can:

- Chat with agents
- Run tools and browse the web
- Edit files and review diffs
- Switch profiles and models

## Run a headless command

You can also run a single prompt and exit:

```bash
gizzi exec "Explain the latest changes in this git diff"
```

## Open a web or desktop interface (optional)

Start the Gizzi server and open its web interface:

```bash
gizzi web
```

Or open the current folder in Allternit Desktop (the command downloads and installs Desktop if it is missing):

```bash
gizzi allternit .
```
