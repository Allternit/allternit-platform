## Architecture contract

### 2026-09-30

- Kernel ABI 1.0.0 frozen: 21 schema files, 65 contracts, 191-ID primitive registry.
- Agency API v0.3 contract published as a preview.
- Architecture, work runtime and cognitive runtime pages added, with status labels.
- Per-contract reference pages, registries, enums and error codes generated from the schemas.

### On main at this date

Node lifecycle library, primitive registry and graph validator library; signed receipt chain and effect receipts (internal); per-node execution environment and shared egress guard; a gate in front of every executor; verifier-owned completion for agency-origin work; decision runtime with S1 shadow only.

### Not on main

Replay and cassettes, router and ModelPool, the context and tool call compilers, the conformance suite and the alpha gate.
