The rail on the left has five top items and several groups. Only the group you are in stays open. The breadcrumb shows Group > Page.

## Top items

- Dashboard
- Playground ([guide](/console/playground))
- API keys
- Models ([guide](/console/models-and-pricing))
- Gizzi Code: requests, tokens and spend from Gizzi Code signed in to Allternit Cloud, with a CSV download

## Groups

| Group | Pages |
|---|---|
| Platform API | Projects, Agents, Conversations, Decisions, Approvals, Computers, Phones, Usage, Billing, Webhooks |
| Managed Agents | Overview, Builder, Sessions, Deployments, Computers, Vaults, Memory, Skills, Files, Batches |
| Analytics | Usage, Logs, Cost, Rate limits, Caching |
| Organization | Credits and billing, Plans, Members, Audit log, Spend limits, Service accounts, Security, Organization webhooks, Tags, Settings |
| Cloud | Compute, Devices, Fabric, Runs, Schedules, Cloud accounts, Organizations |
| Gateway | Routing policy, Route credentials. Self-hosted only. |

Some pages are hidden on the hosted Cloud console. Fabric shows only when Fabric is enabled.

## Bottom of the rail

One account row shows your organization and user. Click it to switch organizations and open account controls. Below it is one line of links: Docs, Support, Status and Changelog.

Every old URL still works.

## Managed Agents need a device

Managed Agents run on a computer you connect. If no device is paired, the Managed Agents pages and Cloud accounts show a "Managed Agents run on a computer you connect" card instead of an error. Use Connect a device to pair one, or open the docs. See [Managed Agents](/byoc/managed-agents).
