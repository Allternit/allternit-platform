## Overview

`end_conversation` ends one of Gizzi's own chats. It is for sustained abuse after a warning, or when you ask for it. You can always start a new chat.

This tool turns on with its feature PR. Until then it is registered as a stub and does not show in any tool list, so the model never sees a tool that does nothing.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `reason` | `sustained_abuse` or `user_requested` | Why the chat ends |
| `warned` | boolean | True when the assistant warned you in an earlier reply |
| `summary` | string, optional | One neutral line for the record, up to 500 characters |

## Result

The reason and `ended: true`. The session moves to an ended state and the composer offers a new chat.

## Permission

It is on for Gizzi's own chats and off for bots on customer channels. It is allowed in every mode.

## Surfaces

Desktop, web, phone layout, PWA, iOS and the terminal show the ended state. Android follows the PWA. Delivered by the phone PR (PR11g). Family: `session`.
