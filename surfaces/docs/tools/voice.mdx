## Overview

The **Allternit Voice Service** (`services/voice`, crate `voice-service`) is a Rust HTTP sidecar used by Gizzi Code and Allternit Desktop. Both directions are real and run on [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) inside the single binary — no cloud voice APIs, no Python, no whisper.cpp:

- **STT:** Silero VAD finds speech segments; **Moonshine tiny** (English, default) or **Parakeet TDT 0.6B v3** (accurate) transcribes them. Any sample rate is accepted (resampled to 16 kHz); 8 kHz phone audio including G.711 μ-law WAV works.
- **TTS:** **Kokoro-82M int8** (English v0.19, Apache-2.0), 11 voices, 24 kHz.

Voice cloning is not part of this service. The remaining product surfaces (Desktop speak button, voice picker UI, Gizzi `/speak`) are specified in `docs/specs/tts-product.md`.

Status: Implementation IMPLEMENTED (STT + TTS) / Exposure INTERNAL.

## Models

Model packs download on first use (sha256-verified, resumable) into
`~/.allternit/models/voice/<pack>/`; nothing model-related ships in the
installer. Poll `GET /v1/models` for state (`missing`, `downloading` with
`pct`, `ready`, `error`).

| Pack | Contents | Size |
|------|----------|------|
| `small` (default) | Silero VAD + Moonshine tiny EN + Kokoro-82M int8 | ~134 MB |
| `accurate` | Parakeet TDT 0.6B v3 int8 (CC-BY-4.0) | ~487 MB |

- `ALLTERNIT_VOICE_MODEL_BASE` overrides the download base URL.
- `ALLTERNIT_VOICE_THREADS` sets inference threads (default **2**), CPU provider — sized for a ~5-year-old 8 GB laptop.
- Licences and attributions: `services/voice/THIRD_PARTY_NOTICES.md` (Parakeet is CC-BY-4.0 and requires attribution).

## Base URL

The service binds to `127.0.0.1` on `PORT` (default `8001`).

```text
http://127.0.0.1:8001
```

```bash
cargo run -p voice-service
# or
./services/voice/start.sh
```

The sherpa-onnx and onnxruntime native libraries link **statically** into the
binary (crate `sherpa-onnx` default `static` feature), so the packaged sidecar
has no accompanying dylib/DLL.

## REST endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health`, `/v1/health` | Health: engine, threads, readiness, pack states |
| GET | `/v1/models` | Pack download states |
| GET | `/v1/voices` | List the 11 installed Kokoro voices |
| GET | `/v1/voices/:id` | Get one voice (404 if unknown) |
| GET | `/v1/stt/models` | List STT models (moonshine, parakeet) |
| POST | `/v1/tts` | Synthesise → `audio/wav` bytes (or `format: "pcm16"`) |
| POST | `/v1/tts/stream` | Sentence-streaming TTS (NDJSON per-sentence pcm16) |
| POST | `/v1/stt` | Transcribe uploaded audio (multipart; WAV any rate, or raw 16 kHz pcm16) |
| POST | `/v1/stt/stream` | Streaming STT: chunked 16 kHz pcm16 in, NDJSON partial/final out |
| GET, POST | `/v1/sessions` | List or create sessions |
| GET, DELETE | `/v1/sessions/:id` | Get or delete a session |
| GET | `/v1/stats` | Service metrics |

## Transcribe audio

Send the audio as a multipart form upload (`audio` field; optional
`language`, `model=moonshine|parakeet`). WAV containers of any sample rate
are decoded and resampled to 16 kHz; raw s16le 16 kHz PCM is also accepted.

```bash
curl -X POST http://127.0.0.1:8001/v1/stt -F "audio=@meeting.wav"
```

```json
{
  "text": "hello world",
  "confidence": 0.9,
  "language": "en",
  "segments": [
    { "start_time": 0.0, "end_time": 1.4, "text": "hello world", "confidence": 0.9 }
  ]
}
```

## Speak text

```bash
curl -X POST http://127.0.0.1:8001/v1/tts \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from Allternit", "voice": "af"}' \
  --output hello.wav
```

The first TTS/STT request downloads the `small` pack; poll `GET /v1/models`
for progress.
