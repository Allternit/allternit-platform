## Overview

The **Allternit Voice Service** (`services/voice`, crate `voice-service`) is a Rust HTTP sidecar used by Gizzi Code and Allternit Desktop. Speech-to-text is real: it runs [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (`whisper-cli` with the `ggml-tiny.en.bin` model) on the host, with no cloud STT.

<Warning>
Text-to-speech is **DESIGN, not implemented**. `POST /v1/tts` and `POST /v1/tts/stream` return metadata only (an `audio_url`, an estimated duration and a format); no audio is synthesized and nothing is served at that URL. Voice cloning and the Chatterbox, XTTS and Piper engines are not part of this service. The full TTS product is specified in `docs/specs/tts-product.md`.
</Warning>

Status: Implementation IMPLEMENTED (STT only) / Exposure INTERNAL.

## Base URL

The service binds to `127.0.0.1` on `PORT` (default `8001`).

```text
http://127.0.0.1:8001
```

```bash
cargo run -p voice-service
# or
./services/voice/start.sh
```

Build `whisper-cli` with `services/voice/build-whisper.sh`. The ggml model downloads on the first `POST /v1/stt` into `~/.allternit/models/whisper/` unless `WHISPER_MODEL` is set. `WHISPER_CLI` points at a specific `whisper-cli` binary.

## REST endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health`, `/v1/health` | Health, including `engine`, `cli_ok` and `model_ok` |
| GET | `/v1/voices` | List TTS voice metadata |
| GET | `/v1/voices/:id` | Get one voice (404 if unknown) |
| GET | `/v1/stt/models` | List STT models |
| POST | `/v1/tts` | Metadata-only TTS response (no audio) |
| POST | `/v1/tts/stream` | Metadata-only streaming response (no audio) |
| POST | `/v1/stt` | Transcribe uploaded audio (multipart) with whisper.cpp |
| POST | `/v1/stt/stream` | Returns a WebSocket URL descriptor |
| GET, POST | `/v1/sessions` | List or create sessions |
| GET, DELETE | `/v1/sessions/:id` | Get or delete a session |
| GET | `/v1/stats` | Service metrics |

## Health check

```bash
curl http://127.0.0.1:8001/v1/health
```

```json
{
  "service": "voice",
  "status": "healthy",
  "version": "0.1.0",
  "timestamp": 1712345678901,
  "features": ["tts", "stt", "streaming"],
  "engine": "whisper.cpp",
  "cli_ok": true,
  "model_ok": true
}
```

## Transcribe audio

Send the audio as a multipart form upload. Audio is converted to 16 kHz 16-bit mono WAV before it is passed to `whisper-cli`.

```bash
curl -X POST http://127.0.0.1:8001/v1/stt -F "audio=@meeting.wav"
```

If `whisper-cli` or the model is missing the request fails; check `cli_ok` and `model_ok` on `/v1/health`.
