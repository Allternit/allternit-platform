## Overview

The Voice API provides text-to-speech (TTS), speech-to-text (STT), voice session management, and service introspection. The Rust voice service (`services/voice`) listens on port `8001` (override with the `PORT` environment variable). Both STT and TTS are real and run on [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) inside the binary:

- **STT:** Silero VAD segments the audio, then Moonshine tiny (default) or Parakeet TDT 0.6B v3 (accurate) transcribes each segment. Any sample rate is accepted and resampled to 16 kHz; 8 kHz phone audio (including G.711 μ-law WAV) works.
- **TTS:** Kokoro-82M int8 (English v0.19), 11 voices, 24 kHz output.
- **Models download on first use** into `~/.allternit/models/voice/<pack>/` (sha256-verified). The `small` pack (~134 MB: VAD + Moonshine + Kokoro) is the default; the `accurate` pack (~487 MB, Parakeet, CC-BY-4.0) downloads on first accurate-STT request. Poll `GET /v1/models` for `missing | downloading | ready | error` state. Override the download base with `ALLTERNIT_VOICE_MODEL_BASE`.
- Inference uses `ALLTERNIT_VOICE_THREADS` threads (default **2**), CPU provider.

Licences and attributions: `services/voice/THIRD_PARTY_NOTICES.md` (sherpa-onnx Apache-2.0; Moonshine MIT; Kokoro Apache-2.0; Silero VAD MIT; Parakeet CC-BY-4.0, attribution required; onnxruntime MIT).

## Base URL

```
http://localhost:8001
```

The voice service binds to `127.0.0.1:8001` by default. When deployed behind the Allternit gateway, it may be exposed under a platform path; consult your deployment's routing table.

## Authentication

The standalone voice service does not require authentication in local development. When exposed through the platform API, standard bearer-token auth applies. See [Authentication](/api/authentication).

## Resources

### VoiceModel

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Kokoro voice id (`af`, `af_bella`, `am_michael`, `bm_george`, …). |
| `name` | string | Human-readable name. |
| `language` | string | Language code (`en-US`, `en-GB`). |
| `gender` | string | Gender tag. |
| `sample_rate` | integer | Output sample rate in Hz (24000). |

### SttModel

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | `moonshine-tiny-en` or `parakeet-tdt-0.6b-v3-int8`. |
| `name` | string | Human-readable name. |
| `language` | string | Supported language. |
| `supports_streaming` | boolean | Whether streaming is supported. |

### PackStatus

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | `small` or `accurate`. |
| `state` | string | `missing`, `downloading`, `ready`, or `error`. |
| `pct` | number | Download progress 0–1 while downloading. |
| `error` | string | Error message when `state` is `error`. |

### VoiceSession

| Field | Type | Description |
|-------|------|-------------|
| `session_id` | string | UUIDv4 session identifier. |
| `created_at` | ISO8601 | Creation timestamp. |
| `last_activity` | ISO8601 | Last activity timestamp. |
| `mode` | string | `tts`, `stt`, or `both`. |
| `language` | string | Session language. |

## Text-to-speech

```http
POST /v1/tts
```

Synthesises speech and returns audio bytes (`audio/wav` by default; pass
`format: "pcm16"` for raw s16le mono 24 kHz). The first request downloads
the `small` pack if it is not on disk yet.

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `text` | string | Yes | Text to synthesize. |
| `voice` | string | No | Kokoro voice id; default `af`. Alias `voice_id` accepted. |
| `language` | string | No | Language hint (reserved). |
| `speed` | number | No | Speech speed multiplier (default 1.0). |
| `format` | string | No | `wav` (default) or `pcm16`. |

### Example request

```bash
curl -X POST http://localhost:8001/v1/tts \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from Allternit", "voice": "af"}' \
  --output hello.wav
```

### Response

`200 OK` — `audio/wav` bytes with `X-Duration-Seconds`, `X-Sample-Rate`,
and `X-Format` headers.

## Streaming text-to-speech

```http
POST /v1/tts/stream
```

Sentence-streaming TTS: the text is split into sentences and each sentence's
audio is emitted as soon as it is synthesised, so playback can start before
the whole text is done.

### Response

`200 OK` — `application/x-ndjson` stream:

```jsonl
{"type":"audio","index":0,"sample_rate":24000,"format":"pcm16","audio_b64":"<s16le base64>"}
{"type":"done","duration_secs":4.32}
```

Decode each `audio_b64` to raw s16le mono PCM at `sample_rate`; concatenating
all chunks yields the full utterance.

## Speech-to-text

```http
POST /v1/stt
```

Transcribes uploaded audio passed as multipart form data. Accepts WAV
(PCM 8/16/24/32-bit, float32, G.711 μ-law/A-law; any sample rate; mono or
stereo) or raw 16 kHz s16le PCM. Audio is resampled to 16 kHz and segmented
by Silero VAD; each segment is transcribed with the selected model.

### Request body (multipart)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `audio` | bytes | Yes | Audio bytes (`.wav` or raw pcm16). |
| `language` | string | No | Language hint (echoed back). |
| `model` | string | No | `moonshine` (default) or `parakeet` (accurate pack). |

### Example request

```bash
curl -X POST http://localhost:8001/v1/stt \
  -F "audio=@recording.wav" \
  -F "language=en"
```

### Example response

```json
{
  "text": "hello world",
  "confidence": 0.9,
  "language": "en",
  "segments": [
    {
      "start_time": 0.0,
      "end_time": 1.4,
      "text": "hello world",
      "confidence": 0.9
    }
  ]
}
```

`segments` carry VAD-derived timestamps. `confidence` is a heuristic —
the offline recognisers do not emit per-word confidence.

## Streaming speech-to-text

```http
POST /v1/stt/stream
```

Streaming STT: send raw chunked s16le mono **16 kHz** PCM
(`Content-Type: application/octet-stream`; `?model=moonshine|parakeet`);
receive `application/x-ndjson` events as speech is segmented:

```jsonl
{"type":"partial","text":"hello wor"}
{"type":"final","text":"hello world","start":0.0,"end":1.4}
{"type":"done","duration_secs":6.1}
```

One streaming STT session at a time; a concurrent request gets
`409 Conflict`. Finish the request body (or close the connection) to flush
trailing speech.

## Error codes

| Status | Meaning |
|--------|---------|
| `200 OK` | Success. |
| `204 No Content` | Session deleted successfully. |
| `400 Bad Request` | Missing audio, empty text, or unknown model/voice. |
| `404 Not Found` | Voice or session not found. |
| `409 Conflict` | A streaming STT session is already active. |
| `415 Unsupported Media Type` | Unsupported audio container (e.g. WebM/Opus — decode to WAV client-side). |
| `503 Service Unavailable` | Engine failed to initialise (e.g. model download/verify failure). |
