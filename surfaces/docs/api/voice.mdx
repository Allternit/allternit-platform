## Overview

The Voice API provides text-to-speech (TTS), speech-to-text (STT), voice session management, and service introspection. The Rust voice service (`services/voice`) listens on port `8001` (override with the `PORT` environment variable). Speech-to-text runs on a local whisper.cpp CLI and ggml model. Text-to-speech does not synthesize audio in this build: `POST /v1/tts` returns a `/v1/audio/<id>.wav` URL, but no `/v1/audio/*` route is registered. `POST /v1/stt/stream` returns a `websocket_url` (`/v1/stt/ws/<id>`) for which no route is registered. There is no Python voice wrapper in the repository. Implementation IMPLEMENTED for STT and sessions, DESIGN - NOT YET IMPLEMENTED for TTS audio and streaming; Exposure INTERNAL.

## Base URL

```
http://localhost:8001
```

The voice service binds to `0.0.0.0:8001` by default. When deployed behind the Allternit gateway, it may be exposed under a platform path; consult your deployment's routing table.

## Authentication

The standalone voice service does not require authentication in local development. When exposed through the platform API, standard bearer-token auth applies. See [Authentication](/api/authentication).

## Text-to-speech

```http
POST /v1/tts
```

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `text` | string | Yes | Text to synthesize. |
| `voice_id` | string | No | Voice preset; defaults to `default`. |
| `language` | string | No | Language hint. |
| `speed` | number | No | Speech speed multiplier. |

### Example request

```bash
curl -X POST http://localhost:8001/v1/tts \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello from Allternit",
    "voice_id": "en-us-female"
  }'
```

### Example response

```json
{
  "audio_url": "/v1/audio/550e8400.wav",
  "duration_secs": 1.6,
  "sample_rate": 24000,
  "format": "wav"
}
```

## Speech-to-text

```http
POST /v1/stt
```

Transcribes uploaded audio passed as multipart form data.

### Request body (multipart)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `audio` | bytes | Yes | Raw audio bytes. |
| `language` | string | No | Language hint. |

### Example request

```bash
curl -X POST http://localhost:8001/v1/stt \
  -F "audio=@recording.wav" \
  -F "language=en"
```

### Example response

```json
{
  "text": "This is a simulated transcription result from the voice service.",
  "confidence": 0.95,
  "language": "en",
  "segments": [
    {
      "start_time": 0.0,
      "end_time": 2.1,
      "text": "Simulated transcription",
      "confidence": 0.95
    }
  ]
}
```

## Voice Session (realtime)

`GET /v1/voice/session` is a WebSocket for live voice conversations. It carries mic audio in, live transcripts and end-of-turn events out, and speaks reply text as it streams in. Barge-in stops the speech when the user talks over it. Implementation IMPLEMENTED (engine traits, state machine, WebSocket route, Smart Turn), with the speech engine wired once the sherpa-onnx engine lands; Exposure INTERNAL (Desktop sidecar). The canonical protocol is [`services/voice/spec/VOICE_SESSION.md`](https://github.com/Gizziio/allternit/blob/main/services/voice/spec/VOICE_SESSION.md).

Voice is input and output only. The app sends each final user turn to the agent as a normal chat message, then streams the agent's reply text back to be spoken.

### Connect

| Where | URL |
|-------|-----|
| Desktop sidecar | `ws://127.0.0.1:<port>/v1/voice/session?token=<sidecar token>` |
| Allternit Cloud | `wss://…/v1/voice/session?ticket=<short-lived ticket>` |

`token` must match the service's `ALLTERNIT_VOICE_TOKEN`. If that variable is unset, only loopback connections are accepted. Cloud tickets are refused until a ticket verifier is configured. A failed check returns `401` before the upgrade.

### Frames

- **Text frames** are JSON with a `type`.
- **Binary frames** are audio. Client → server is PCM16 LE mono mic audio at `inputSampleRate` (default 16000, 20 ms frames). Server → client is PCM16 LE mono speech at `outputSampleRate` from `session.ready`.

| Client → server | Fields | Meaning |
|-----------------|--------|---------|
| `session.start` | `voice?`, `sttModel?` (`light`/`accurate`), `language?`, `inputSampleRate?`, `bargeIn?` (default `true`), `turn?` {`mode`: `smart`/`vad`, `silenceMs?`} | First frame. The answer is `session.ready` or `error`. |
| `session.update` | any `session.start` field | Change settings mid-session. |
| `speak.delta` | `id`, `text` | Append reply text. It's spoken sentence by sentence. |
| `speak.done` | `id` | No more text for `id`. |
| `speak.cancel` | `id?` | Stop speaking `id` (or the current one). The answer is `speak.ended`. |
| `mic.mute` / `mic.unmute` | | Ignore mic audio while muted. |
| `session.end` | | Close. |

| Server → client | Fields | Meaning |
|-----------------|--------|---------|
| `session.ready` | `protocol` (1), `sessionId`, `engine` (`device`/`cloud`), `outputSampleRate`, `models` {stt, tts, vad, turn}, `voices` | Ready. |
| `speech.started` / `speech.stopped` | `atMs` | VAD start and stop, in ms of mic audio. |
| `transcript.delta` | `segmentId`, `text`, `final: false` | Live caption. |
| `transcript.final` | `segmentId`, `text` | Final text for a segment. |
| `turn.ended` | `text`, `confidence` | The user's turn is over. Send `text` to the agent now. |
| `speak.started` / `speak.ended` | `id` | Brackets the speech audio for `id`. |
| `speak.interrupted` | `id`, `sentMs` | Barge-in. Flush playback now and abort the agent's turn. |
| `error` | `code`, `message`, `fatal` | `fatal: true` closes the socket. |

### Turn detection

- `smart` (default) runs Smart Turn v3.2 at each pause. A score of 0.5 or more ends the turn at once. Below that, the turn ends after `silenceMs` of silence (default 1500).
- `vad` ends the turn after `silenceMs` of silence (default 700).

### Example

```json
→ {"type":"session.start","inputSampleRate":48000,"turn":{"mode":"smart"}}
← {"type":"session.ready","protocol":1,"sessionId":"…","engine":"device","outputSampleRate":24000,"models":{"stt":"moonshine-tiny-en","tts":"kokoro-en-v0_19","vad":"silero-vad","turn":"smart-turn-v3.2"},"voices":["af","…"]}
→ (binary mic frames)
← {"type":"speech.started","atMs":1180}
← {"type":"transcript.delta","segmentId":"seg-1","text":"what time","final":false}
← {"type":"turn.ended","text":"What time is it?","confidence":0.93}
→ {"type":"speak.delta","id":"r1","text":"It's noon. "}
→ {"type":"speak.done","id":"r1"}
← {"type":"speak.started","id":"r1"}
← (binary speech frames)
← {"type":"speak.ended","id":"r1"}
```

To try it from a terminal, run `cargo run -p voice-service --example voice_session_client -- --wav question.wav --say "It is noon." --out reply.wav`.
