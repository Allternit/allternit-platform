## Overview

**Status:** Implementation IMPLEMENTED for store and file records (stored in the gateway database; a store or attached file is `completed` immediately, with no indexing step), and DESIGN - NOT YET IMPLEMENTED for search. `POST /v1/vector_stores/:id/search` validates the request and always returns an empty result list, because no embedding or similarity search is wired in yet. Exposure INTERNAL.


The Vector Store API lets you create collections of files for retrieval-augmented generation (RAG). Files uploaded via `/v1/files` can be attached to a vector store, and the store can be searched semantically to retrieve relevant passages.

## Base URL

```
https://api.allternit.com/v1
```

For local development:

```
http://127.0.0.1:8013/v1
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/vector_stores` | Create a vector store |
| `GET`  | `/v1/vector_stores` | List vector stores |
| `GET`  | `/v1/vector_stores/:id` | Retrieve a vector store |
| `DELETE` | `/v1/vector_stores/:id` | Delete a vector store |
| `POST` | `/v1/vector_stores/:id/files` | Attach a file to a store |
| `GET`  | `/v1/vector_stores/:id/files` | List files in a store |
| `DELETE` | `/v1/vector_stores/:id/files/:file_id` | Detach a file |
| `POST` | `/v1/vector_stores/:id/search` | Search a vector store |

## Authentication

All requests require a virtual key in the `Authorization` header. See [Authentication](/api/authentication).

## Create a vector store

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | yes | Human-readable name for the store. |
| `metadata` | object | no | Arbitrary metadata attached to the store. |
| `expires_after` | object | no | Expiration policy: `{ "anchor": "last_active_at", "days": 7 }`. |

### Example request

```bash
curl -X POST https://api.allternit.com/v1/vector_stores \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "platform-documentation",
    "metadata": {"team": "developer-relations"},
    "expires_after": {"anchor": "last_active_at", "days": 30}
  }'
```

### Example response

```json
{
  "id": "vs_abc123",
  "object": "vector_store",
  "name": "platform-documentation",
  "status": "completed",
  "created_at": 1723500000,
  "file_counts": {
    "in_progress": 0,
    "completed": 0,
    "failed": 0,
    "cancelled": 0,
    "total": 0
  },
  "metadata": {"team": "developer-relations"}
}
```

## Attach a file

```bash
curl -X POST https://api.allternit.com/v1/vector_stores/vs_abc123/files \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"file_id": "file_abc123"}'
```

### Example response

```json
{
  "id": "vsf_abc123",
  "object": "vector_store.file",
  "vector_store_id": "vs_abc123",
  "file_id": "file_abc123",
  "status": "completed",
  "created_at": 1723500000
}
```

## Search a vector store

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `query` | string | yes | Search query. |
| `max_results` | integer | no | Maximum results. `1`–`100`. Defaults to `10`. |
| `filter` | object | no | Metadata filter. |

### Example request

```bash
curl -X POST https://api.allternit.com/v1/vector_stores/vs_abc123/search \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "How do I configure BYOC?",
    "max_results": 5
  }'
```

### Response

The response is always an empty list today:

```json
{
  "object": "list",
  "data": [],
  "has_more": false
}
```

## Delete a vector store

```bash
curl -X DELETE https://api.allternit.com/v1/vector_stores/vs_abc123 \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

```json
{
  "id": "vs_abc123",
  "object": "vector_store.deleted",
  "deleted": true
}
```

## Error codes

| HTTP status | Code | Meaning |
|-------------|------|---------|
| 400 | `allternit.invalid_request` | Empty `name`, empty `query`, or `max_results > 100`. |
| 401 | `allternit.authentication_failed` | Missing or invalid API key. |
| 404 | `allternit.invalid_request` | Store or file not found. |
| 429 | `allternit.rate_limited` | Per-key rate limit exceeded. |
| 429 | `allternit.budget_exceeded` | Monthly key or tenant budget exhausted. |
| 500 | `allternit.internal_error` | Internal gateway error. |
| 502 | `allternit.upstream_error` | Database failure while reading or writing store records. |
