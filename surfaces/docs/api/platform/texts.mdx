<Note>
On 2026-11-12 SMS moved from `/v1/messages` to `/v1/texts`; the object is now `text` (ids keep their `msg_` prefix). `POST /v1/messages` is now the [Messages](/api/platform/messages) model call. The webhook events `message.received` and `message.status` keep their names, so stored subscriptions are unaffected.
</Note>

| Method | Path | |
|---|---|---|
| `POST` | `/v1/texts` | Send: `{ "number_id", "to", "body" }` |
| `GET` | `/v1/texts` | List (cursor pagination; filters `number_id`, `account_id`, `direction`) |
| `GET` | `/v1/texts/{id}` | Retrieve |

```json
{ "id": "msg_9f2…", "object": "text", "account_id": "acct_7Hq…", "number_id": "6f1c…", "direction": "outbound",
  "from": "+16125550142", "to": "+14155550123", "body": "Yes, 2 pm works.", "segments": 1, "status": "sent",
  "error_code": null, "media": [], "created_at": "2026-10-04T18:20:44Z" }
```

`status` is `sent`, `simulated` (sandbox), `received` (inbound) or `failed`.

## When a send is refused

| `403` code | Why |
|---|---|
| `sms_not_active` | The number's carrier registration isn't approved yet. |
| `recipient_opted_out` | The person replied STOP. Only their START lifts it. |
| `no_consent` | The person never texted this number and has no [consent](/api/platform/numbers#consent) recorded. |

`429 daily_limit` means the number reached its daily sending cap. `402 spend_cap_reached` means the project reached its monthly [spend cap](/api/platform/billing); simulated (sandbox) texts are free and never refused for it.

## Retrying a send safely

Send an `Idempotency-Key` header (any unique string up to 200 characters) with `POST /v1/texts`. If the request is retried with the same key on the same number, the original text comes back and no second text goes out. A retry that arrives while the first is still in flight returns `409` with `send_in_progress`; try again shortly. If the carrier rejects the first attempt, the key is released and a retry sends normally.

## Receiving texts

Texts that arrive on your numbers are kept and sent to your [webhooks](/api/platform/webhooks) as `message.received`. `STOP`, `START` and `HELP` are answered for you and never reach you as messages; a STOP also means future sends to that person are refused.

## Billing

Each text counts as one or more `sms_segment` (160 characters, or 70 with emoji and other non-GSM characters; longer texts split into 153 / 67 character parts), sent and received alike. Simulated texts are free.
