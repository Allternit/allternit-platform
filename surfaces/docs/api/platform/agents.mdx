title: 'Agents'
description: 'Hosted agents: instructions, voice, model, tools and autonomy for one of your accounts.'
---

An agent is a hosted bot that runs in Allternit's cloud for one of your [accounts](/api/platform/accounts). You set what it says and does; Allternit runs it. Scope `agents`.

| Method | Path | |
|---|---|---|
| `POST` | `/v1/agents` | Create |
| `GET` | `/v1/agents` | List (cursor pagination; `?account_id=` filters) |
| `GET` | `/v1/agents/{id}` | Retrieve |
| `PATCH` | `/v1/agents/{id}` | Update (absent fields stay; arrays and `metadata` replace) |
| `DELETE` | `/v1/agents/{id}` | Delete |

```bash
curl https://api.allternit.com/v1/agents \
  -H "Authorization: Bearer $ALLTERNIT_KEY" -H "Content-Type: application/json" \
  -d '{ "account_id": "acct_7Hq…", "name": "Front desk",
        "instructions": "Answer questions about Lakeside Dental and book cleanings.",
        "tools": ["send_text", "call", "ask_human"], "autonomy": "ask" }'
```

```json
{ "id": "agent_3f9…", "object": "agent", "account_id": "acct_7Hq…", "name": "Front desk",
  "instructions": "Answer questions about Lakeside Dental and book cleanings.",
  "greeting": "Hi, this is Front desk, an AI assistant. How can I help?",
  "model": "allternit", "voice": "af_heart", "tools": ["send_text", "call", "ask_human"],
  "autonomy": "ask", "transfer_targets": [], "business_hours": null, "metadata": {},
  "status": "pending", "created_at": "2026-10-06T19:40:02Z", "updated_at": "2026-10-06T19:40:02Z" }
```

| Field | |
|---|---|
| `account_id` | Required, unless the key is bound to an account (then it's that account). Can't change later. |
| `name` | 1–100 characters. |
| `instructions` | What the agent does and how, up to 32,000 characters. |
| `greeting` | The first thing it says. **It must say it's an AI** (for example "I'm an AI assistant"); you can reword it but not remove it (`greeting_missing_ai_disclosure`). Default: "Hi, this is {name}, an AI assistant. How can I help?" |
| `model` | `allternit` (default: Allternit's routed model), or `anthropic/…`, `openai/…` or `xai/…` (for example `anthropic/claude-sonnet-5-5`), which runs on your project's own key (see [Model keys](#model-keys)). |
| `voice` | A stock voice: `af_heart` (default), `af_alloy`, `af_aoede`, `af_bella`, `af_jessica`, `af_kore`, `af_nicole`, `af_nova`, `af_river`, `af_sarah`, `af_sky`, `am_adam`, `am_echo`, `am_eric`, `am_fenrir`, `am_liam`, `am_michael`, `am_onyx`, `am_puck`, `am_santa`, `bf_alice`, `bf_emma`, `bf_isabella`, `bf_lily`, `bm_daniel`, `bm_fable`, `bm_george`, `bm_lewis`. Custom and cloned voices aren't available. |
| `tools` | Any of `send_text`, `call`, `email`, `web_fetch`, `web_search`, `ask_human`. The agent can use only these (plus looking people up and noting facts about them); everything else is blocked in its conversations. `channel_post`, `calendar`, `knowledge_search` and `transfer` are coming and answer `tool_not_available` for now. |
| `autonomy` | How far it goes on its own: `draft` (writes, never sends), `ask` (default: a person approves each send), `tell` (sends, then reports), `limits` (sends within daily limits, then asks). Payments always wait for a person. |
| `transfer_targets` | Up to 20 E.164 numbers a call may be transferred to. |
| `business_hours` | A JSON object (up to 8 KB), for example `{ "tz": "America/Chicago", "mon": ["09:00", "17:00"] }`. `null` clears it. |
| `metadata` | Your own JSON object, up to 8 KB. |
| `status` | `pending` until the project's hosted runtime holds the agent (it gets it with the first [conversation](/api/platform/conversations) message), then `ready`. |

**Limits.** Sandbox projects can have 3 agents (`agent_limit_reached`; deleting one frees its slot). Live projects have no cap; agents after the first 3 are billed per agent per month (see [Usage](/api/platform/usage)).

**Isolation.** A key bound to an account creates agents in that account and can only see that account's agents; another account's agent answers `404 agent_not_found`, as if it didn't exist.

## Model keys

To run an agent on your own Anthropic, OpenAI or xAI account, store the project's key once and set the agent's `model` to `provider/model`. Scope `agents`; not for account-bound keys.

| Method | Path | |
|---|---|---|
| `PUT` | `/v1/model_keys/{provider}` | `{ "api_key" }` (`anthropic`, `openai` or `xai`) |
| `GET` | `/v1/model_keys` | The project's keys, masked (`…7890`); the key itself is never returned |
| `DELETE` | `/v1/model_keys/{provider}` | Remove it |

Keys are encrypted at rest. The project's hosted runtime gets the key before the agent's next message. To rotate a key, `PUT` the new one: the next message uses it. An agent on a provider model with no key for it answers `model_key_missing` when you send it a message.

Errors use the [standard format](/api/platform/errors): `invalid_name`, `invalid_instructions`, `invalid_greeting`, `greeting_missing_ai_disclosure`, `invalid_model`, `invalid_voice`, `invalid_tool`, `tool_not_available`, `invalid_autonomy`, `invalid_transfer_target`, `invalid_business_hours`, `invalid_metadata`, `missing_account_id`, `account_not_found`, `agent_not_found`, `agent_limit_reached`, `insufficient_scope`; model keys: `invalid_provider`, `invalid_api_key`, `model_key_not_found`, `model_keys_unavailable`.
