---
title: "Account compute status API"
description: "The compute gate: what computer an account has, which paths it can take, and the error agents get without one."
---

These routes live in `allternit-cloud-api` and are served at `https://api.allternit.com`. They take a Clerk session or an `allternit_*` API token.

A signed-in account with no computer does not reach agent work until it links its own Desktop app, subscribes, or buys credits for a hosted computer. Chat with Allternit Cloud models stays open. Hosted computers run on a third-party cloud provider, managed by Allternit. They sleep when idle.

## Get compute status

`GET /api/v1/account/compute-status`

```json
{
  "state": "none",
  "online": false,
  "gate": true,
  "acknowledged_at": null,
  "computer": null,
  "paths": {
    "own": { "download_url": "https://www.allternit.com/download", "pairing_supported": true },
    "plan": { "plans": [
      { "id": "plus", "billing_plan_id": "plus", "name": "Plus", "price_usd_month": 20,
        "computer": { "cpu": 2, "memory_gb": 8, "disk_gb": 50 }, "included_hours": 200 },
      { "id": "max", "billing_plan_id": "super", "name": "Max", "price_usd_month": 100,
        "computer": { "cpu": 4, "memory_gb": 16, "disk_gb": 100 }, "included_hours": null }
    ] },
    "credits": {
      "price_per_hour_usd": 0.10, "stopped_price_per_hour_usd": 0.005,
      "balance_usd": 0.0, "min_start_usd": 5,
      "sizes": [ { "id": "medium", "cpu": 2, "memory_gb": 8, "disk_gb": 50,
                   "price_per_hour_usd": 0.10, "stopped_price_per_hour_usd": 0.005 } ]
    }
  },
  "docs_url": "https://docs.allternit.com/api/account-compute-status"
}
```

Prices, sizes and included hours shown here are not final. Read them from `paths`, do not hard-code them. Plan sizes come from the server's plan table, so they can differ from this example.

| Field | Meaning |
| --- | --- |
| `state` | `none`, `paired`, `provisioning`, `hosted` or `suspended`. |
| `online` | The computer is reachable now. |
| `gate` | True when `state` is `none` or `suspended`. Agent entry is refused while true. |
| `acknowledged_at` | When the user confirmed chat-only. Does not lift the gate. |
| `computer` | `{id, kind, provider, status, sleeps_when_idle, runway_hours, retention_until}` or null. `kind` is `own`, `plan` or `credits`. `provider` is `incus`, `orgo` or null (your own machine). `status` is `running`, `sleeping`, `starting`, `stopped` or `error`. |
| `computer.runway_hours` | Credit computers: hours of running time the balance buys. Show the low-runway notice at 24 and 2. Null otherwise. |
| `computer.retention_until` | Suspended computers: when the stopped computer is deleted (RFC 3339). Null otherwise. |
| `paths.plan.plans[].billing_plan_id` | The id to pass to `POST /api/v1/billing/subscribe` (Max is `super`). |
| `paths.credits` | Null when credit computers are not enabled. |

When both your own Desktop and a hosted computer exist, `state` reports your default computer. A failed hosted create shows as `none` with `computer.status` of `error` for a day, so clients can offer a retry. Free hosted computers do not count.

## Acknowledge chat-only

`POST /api/v1/account/compute-status/acknowledge` with `{"choice":"chat_only"}` returns `{"acknowledged_at":"2026-11-13T15:04:05Z"}`. It is safe to repeat. Any other choice returns `400` with `error.code` of `invalid_choice`.

## The compute_required error

Relay and agent-entry routes answer `409 Conflict` when the account has no computer:

```json
{
  "error": {
    "code": "compute_required",
    "message": "Agents need a computer. Link your own, subscribe, or buy credits.",
    "docs_url": "https://docs.allternit.com/api/account-compute-status",
    "paths": {}
  }
}
```

`paths` is the same object as in compute status. Switch on `error.code`, not on the status alone.

## Link your own computer

Create a code with `POST /api/v1/runtime-pairings`, open the download page with `?pair=CODE`, and the Desktop app handles the existing link `allternit://pair?code=CODE`. Poll `GET /api/v1/runtime-pairings/code/{code}` until it is approved.

## Credit computers

| Method | Path | Notes |
| --- | --- | --- |
| POST | `/api/v1/provisioned-instances/credit` | Body `{"size":"medium"}` (optional). Create or start a hosted computer billed from the credit wallet. `202 {"id","status":"starting","pollUrl","instance"}`, or `200` with `"status":"running"` when it already runs. Poll `pollUrl` until `instance.runtimeOnline` is true. |
| POST | `/api/v1/provisioned-instances/credit/stop` | Stop it. The stopped rate applies. `200 {"instance"}`; `404` when the account has none. |
| POST | `/api/v1/provisioned-instances/free` | `410` with `error.code` of `free_computers_retired`. |

Both credit routes answer `404` while credit computers are not enabled.

Billing is per minute: the running price while it runs, the stopped price while it is stopped or asleep, both debited from the credit wallet. Starting (also restarting a stopped-at-$0 computer) needs at least `min_start_usd`, otherwise the API answers:

```json
{ "error": { "code": "insufficient_credits", "message": "Starting needs at least $5 in credits.",
             "min_start_usd": 5, "balance_usd": 1.2 } }
```

with status `402`. Warnings come at 24 hours and 2 hours of runway. The computer stops at $0 and the state becomes `suspended`; its disk is kept until `computer.retention_until`, then it is deleted. A suspended computer is not billed.

## Flags

| Flag | Values | Effect |
| --- | --- | --- |
| `ALLTERNIT_COMPUTE_GATE` | `off`, `on` | Turns enforcement on. Default off. |
| `ALLTERNIT_CREDIT_COMPUTERS` | `0`, `1` | Turns the credits path on. Default off. |

Prices, the minimum start, retention and the warning emails are set by environment variables listed in [Compute providers](/operations/compute-providers#compute-gate-and-credit-computers).
