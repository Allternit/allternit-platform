## Overview

The A://Labs API exposes the learning-platform catalog and learner state. It surfaces published courses, lessons, enrollments, certifications, articles, and capability records. Lesson generation is implemented through the Gizzi runtime so that A://Labs uses the same brain/provider configuration as the rest of the platform.

<Note>
This namespace is served by the Allternit API data-plane node (`http://127.0.0.1:8013` on the same machine, or your paired or provisioned node). The hosted Cloud API at `https://api.allternit.com` does not route it; it relays only agent sessions, canvases, office and beta research/sessions. See [Cloud API](/api/cloud-api).
</Note>

## Base URL

```
http://127.0.0.1:8013/api/v1
```

## Authentication

- Course and lesson list routes are public.
- Write routes (create lesson, create certification, create article, create capability, upsert enrollment) require a valid bearer token.

See [Authentication](/api/authentication).

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/courses` | List published courses. |
| `GET` | `/api/v1/courses/:id` | Get a course. |
| `GET` | `/api/v1/lessons` | List lessons. |
| `POST` | `/api/v1/lessons` | Create a lesson. |
| `DELETE` | `/api/v1/lessons/:id` | Archive a lesson. |
| `POST` | `/api/v1/lessons/generate` | Generate a lesson via the Gizzi runtime. |
| `GET` | `/api/v1/enrollments` | List caller enrollments. |
| `POST` | `/api/v1/enrollments` | Upsert an enrollment. |
| `GET` | `/api/v1/certifications` | List caller certifications. |
| `POST` | `/api/v1/certifications` | Create a certification record. |
| `GET` | `/api/v1/articles` | List articles. |
| `POST` | `/api/v1/articles` | Create an article. |
| `GET` | `/api/v1/articles/:slug` | Get an article. |
| `GET` | `/api/v1/capabilities` | List capabilities. |
| `POST` | `/api/v1/capabilities` | Create or update a capability. |

## Courses

### List courses

```http
GET /api/v1/courses
```

Returns all published courses ordered by `sort_order`.

### Example response

```json

  {
    "id": "course_550e8400",
    "code": "ALABS-CORE-COPILOT",
    "title": "Build AI-Assisted Software",
    "description": "...",
    "tier": "CORE",

    "modules": 7,
    "capstone": "...",
    "cover_image": "...",
    "demos_url": "...",
    "sort_order": 1,
    "published": true,
    "created_at": "2026-08-13T10:00:00Z",
    "updated_at": "2026-08-13T10:00:00Z"
```

## Lessons

### List lessons

```http
GET /api/v1/lessons?course_id=:course_id&status=published
```

### Query parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `course_id` | string | Filter by course. |
| `status` | string | Filter by status; defaults to `published`. |

### Generate a lesson

```http
POST /api/v1/lessons/generate
```

Generates a lesson for a course using the Gizzi runtime and persists it.

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `course_id` | string | Yes | Course to attach the lesson to. |
| `topic` | string | Yes | Lesson topic. |
| `tier` | string | No | Override tier. |
| `module_number` | integer | No | Defaults to `1`. |
| `lesson_number` | integer | No | Defaults to `1`. |

### Example request

```bash
curl -X POST http://127.0.0.1:8013/api/v1/lessons/generate \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "course_id": "course_550e8400",
    "topic": "Prompt engineering fundamentals",
    "tier": "CORE"
  }'
```

### Example response

```json
{
  "id": "lesson_550e8400",
  "course_id": "course_550e8400",
  "title": "Prompt Engineering Fundamentals",
  "description": "An introduction to prompt engineering...",
  "scene_json": "{\"version\":\"1.0\",\"scenes\":[...]}",
  "content_markdown": "## Prompt Engineering Fundamentals\n\n...",
  "duration_minutes": 15
}
```

## Enrollments

### Upsert an enrollment

```http
POST /api/v1/enrollments
```

Creates or updates the caller's enrollment in a course or lesson.

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `course_id` | string | Yes | Course id. |
| `lesson_id` | string | No | Lesson id. |
| `progress` | integer | No | Progress percentage. |
| `status` | string | No | `in_progress` or `completed`. |

### Example response

```json
{
  "id": "enr_550e8400"
}
```

## Certifications

### Create a certification

```http
POST /api/v1/certifications
```

Records a completed certification for the caller.

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `course_code` | string | Yes | Course code. |
| `course_title` | string | Yes | Course title. |
| `tier` | string | Yes | Course tier. |
| `capstone_url` | string | No | URL to the capstone submission. |
| `score` | integer | No | Assessment score. |

### Example response

```json
{
  "id": "cert_550e8400"
}
```

## Articles

### Create an article

```http
POST /api/v1/articles
```

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `slug` | string | Yes | Unique URL slug. |
| `type` | string | No | Defaults to `blog`. |
| `content_type` | string | No | Defaults to `feature`. |
| `status` | string | No | Defaults to `draft`. |
| `title` | string | Yes | Article title. |
| `subtitle` | string | No | Article subtitle. |
| `abstract` | string | No | Article abstract. |
| `content_markdown` | string | No | Markdown content. |
| `content_html` | string | No | HTML content. |
| `reading_time` | integer | No | Estimated reading time. |
| `featured` | boolean | No | Featured flag. |
| `series` | string | No | Series name. |
| `issue_number` | string | No | Issue number. |
| `license` | string | No | Defaults to `CC BY 4.0`. |
| `access_level` | string | No | Defaults to `public`. |
| `published_at` | string | No | ISO 8601 publish timestamp. |

### Example response

```json
{
  "id": "art_550e8400"
}
```

## Capabilities

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Capability name. |
| `description` | string | No | Description. |

## Error codes

| Status | Meaning |
|--------|---------|
| `200 OK` | Success. |
| `201 Created` | Resource created. |
| `401 Unauthorized` | Missing or invalid bearer token. |
| `404 Not Found` | Course, lesson, article, or other resource not found. |
| `500 Internal Server Error` | Database or runtime error. |
