## Overview

The Analytics API aggregates LLM usage and product activity events into organization-scoped reports. It is gated to organization owners and admins and supports hourly, daily, weekly, and monthly granularity.

<Note>
This namespace is served by the Allternit API data-plane node (`http://127.0.0.1:8013` on the same machine, or your paired or provisioned node). The hosted Cloud API at `https://api.allternit.com` does not route it; it relays only agent sessions, canvases, office and beta research/sessions. See [Cloud API](/api/cloud-api).
</Note>

## Base URL

```
http://127.0.0.1:8013/api
```

All endpoints require a valid Bearer token in the `Authorization` header. See [Authentication](/api/authentication) for details.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/analytics/csp-violation` | Ingest a CSP violation report (stub). |
| POST | `/analytics/gizzi-code/events` | Ingest Gizzi Code CLI usage events. |
| GET | `/admin/analytics/cost-over-time` | Cost over time by granularity. |
| GET | `/admin/analytics/token-usage` | Token usage over time. |
| GET | `/admin/analytics/request-volume` | Request volume with status breakdown. |
| GET | `/admin/analytics/per-user-cost` | Cost per user. |
| GET | `/admin/analytics/active-users` | Daily active users and unique totals. |
| GET | `/admin/analytics/artifact-activity` | Artifact, revision, and section creation. |
| GET | `/admin/analytics/chat-project-usage` | Chat project and session creation. |
| GET | `/admin/analytics/connector-usage` | Connector connection activity. |
| GET | `/admin/analytics/plugin-usage` | Plugin invocations over time. |
| GET | `/admin/analytics/skill-usage` | Team skill installs and invocations. |
| GET | `/admin/analytics/gizzi-code/usage` | Gizzi Code CLI aggregated usage. |

## Query parameters

Most analytics endpoints accept:

| Parameter | Type | Description |
|-----------|------|-------------|
| `organization_id` | string | Organization to query. |
| `start` | string | ISO 8601 start timestamp. |
| `end` | string | ISO 8601 end timestamp. |
| `granularity` | string | `hour`, `day`, `week`, or `month`. Default `day`. |

## Cost over time

```bash
GET /api/admin/analytics/cost-over-time?organization_id=org_abc123&start=2026-08-01T00:00:00Z&end=2026-08-03T00:00:00Z&granularity=day
```

Response:

```json
{
  "items": [
    {
      "bucket": "2026-08-01",
      "cost_microdollars": 300000,
      "requests": 10
    },
    {
      "bucket": "2026-08-02",
      "cost_microdollars": 200000,
      "requests": 8
    }
  ]
}
```

## Ingest Gizzi Code events

```bash
POST /api/analytics/gizzi-code/events
```

Request body:

```json
{
  "events": [
    {
      "session_id": "sess_2f8a9c4e5d3b",
      "event_type": "turn",
      "model": "gizzi-pro",
      "provider": "allternit",
      "prompt_tokens": 100,
      "completion_tokens": 50,
      "cost_microdollars": 1000,
      "tool_calls_accepted": 2,
      "tool_calls_rejected": 0,
      "metadata": { "surface": "vscode" },
      "created_at": "2026-08-13T10:00:00Z"
    }
  ]
}
```

Response:

```json
{ "status": "ok" }
```

## Error codes

| Status | Code | Description |
|--------|------|-------------|
| 200 | — | Success. |
| 400 | `invalid_range` | `start` must be before `end`. |
| 401 | `unauthorized` | Missing or invalid authentication. |
| 403 | `organization_required` / `insufficient_role` | Active organization and admin role required. |
| 403 | `organization_mismatch` | Requested organization does not match the active organization. |
| 500 | `internal_error` | Unexpected server error. |
