## Base URL

```text
https://api.allternit.com
```

This page used to list `/v1/agents`, `/v1/agents/{id}/run`, `/v1/sessions/{id}`, and `/v1/sessions/{id}/messages`. Those routes do not exist. The public API is the Cloud API; it serves `/v1/*` for the LLM gateway and `/api/v1/*` for control-plane and relayed namespaces.

## Status codes

| Code | Meaning |
|------|---------|
| 200 | Success |
| 400 | Bad request |
| 401 | Unauthorized |
| 428 | No healthy node paired to the account |
| 429 | Rate limited, see `Retry-After` |
| 500 | Server error |
