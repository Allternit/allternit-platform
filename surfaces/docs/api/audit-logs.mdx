## Overview

The Task Audit Logs API records actions taken on tasks. Each log entry identifies the task, the action, the actor type and ID, an optional JSON payload, and a timestamp. Access is scoped to tasks owned by the caller or tasks in workspaces where the caller is a member.

<Note>
This namespace is served by the Allternit API data-plane node (`http://127.0.0.1:8013` on the same machine, or your paired or provisioned node). The hosted Cloud API at `https://api.allternit.com` does not route it; it relays only agent sessions, canvases, office and beta research/sessions. See [Cloud API](/api/cloud-api).
</Note>

## Base URL

```text
http://127.0.0.1:8013/api
```

## Authentication

All routes require a valid bearer token in the `Authorization` header. See [Authentication](/api/authentication) for details.

## Audit log object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique log entry identifier. |
| `taskId` | string | Task the action relates to. |
| `action` | string | Action name, e.g. `created`, `updated`, `agent_run`. |
| `actorType` | string | `user`, `agent`, `system`, etc. |
| `actorId` | string | Identifier of the actor. |
| `payload` | string \| null | JSON-serialized action payload. |
| `createdAt` | string | ISO 8601 timestamp. |

Responses use camelCase. The create request accepts `taskId` or `task_id`, and `actor_type` / `actor_id` in snake_case.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/audit-log` | Service status. |
| `GET` | `/audit-logs` | List audit logs with pagination. |
| `POST` | `/audit-logs` | Create a new audit log entry. |

## List audit logs

```bash
curl "http://127.0.0.1:8013/api/audit-logs?taskId=task_abc123&page=1&limit=50" \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

### Query parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `taskId` | string | Filter to a single task. |
| `page` | integer | Page number (default 1, minimum 1). |
| `limit` | integer | Page size (default 50, maximum 100). |

### Response

```json
{
  "logs": [
    {
      "id": "log_abc123",
      "taskId": "task_abc123",
      "action": "agent_run",
      "actorType": "agent",
      "actorId": "agent_01J8X...",
      "payload": "{\"status\":\"completed\"}",
      "createdAt": "2026-08-13T12:00:00Z"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 120,
    "pages": 3
  }
}
```

When `taskId` is omitted, the endpoint returns audit logs for all tasks the caller can access.

## Create an audit log entry

```bash
curl -X POST http://127.0.0.1:8013/api/audit-logs \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "taskId": "task_abc123",
    "action": "reviewed",
    "actor_type": "user",
    "actor_id": "user_123",
    "payload": {"outcome": "approved"}
  }'
```

### Response

`201 Created`

```json
{
  "id": "log_def456"
}
```

## Error codes

Errors are returned as `{"error": "<message>"}`.

| HTTP status | Body | Meaning |
|-------------|------|---------|
| 401 | (auth layer) | Missing or invalid bearer token. |
| 403 | `{"error": "Access denied"}` | Caller cannot access the requested task. |
| 500 | `{"error": "internal error"}` | Database or runtime internal error. |
