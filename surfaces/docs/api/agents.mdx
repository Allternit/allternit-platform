## Overview

The Agents API is the central surface for creating, configuring, running, and managing agents on the Allternit platform. Agents are persistent, user-owned identities. Each one has a profile (name, instructions, system prompt), capabilities, policies (tool policy, harness configuration, enabled surfaces) and a default model preference that the router may use. The model is not the agent's brain: it is one interchangeable component the system calls where cognition is needed. Once created, an agent can be run on demand, instantiated from a template, published to the marketplace, or wired as a subagent under an orchestrator.

<Note>
The `brain`, `model` and `provider` fields below keep their names for compatibility. They set the agent's default model preference, not its identity.
</Note>

## Agents API vs Agency API

**An Agent is configuration and identity. Agency is execution of work.**

| API | What it is for |
|-----|----------------|
| [Agents API](/api/agents) | Configure persistent agent identities and profiles: instructions, capabilities, policies, a default model preference. |
| [Agency API](/api/agency/overview) | Submit durable autonomous work: a goal becomes one verified Run. **PREVIEW.** |
| [Runs](/api/agency/runs) | Observe and control execution: stream, steer, pause, cancel, audit. **PREVIEW.** |
| [Decisions](/api/agency/decisions) | Make a bounded, typed decision with no side effects. **PREVIEW.** |

## Agent creation checklist

Every creation flow enforces the same validation rules:

- `name` must be at least 3 characters.
- `description` must be at least 10 characters.
- `type` is required.
- `model` and `provider` are required.
- `harness_config.mode` must be one of `byok`, `cloud`, `local`, or `subprocess`.
- `enabled_modes` must contain at least one surface.
- `trust_tier` is required.

### Create an agent

```http
POST /api/agents
```

Creates a new agent. The request body is validated against the agent creation checklist.

#### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Agent name (≥ 3 chars). |
| `description` | string | Yes | Agent description (≥ 10 chars). |
| `type` | string | Yes | Agent type. |
| `model` | string | Yes | Model identifier. |
| `provider` | string | Yes | Provider identifier. |
| `mode` | string | No | `primary`, `subagent`, `orchestrator`, or `council`. Defaults to `primary`. |
| `parent_agent_id` | string | No | Parent orchestrator ID. |
| `capabilities` | object | No | Capability flags. |
| `system_prompt` | string | No | System prompt. |
| `tools` | array \| object | No | Tool declarations. |
| `max_iterations` | integer | No | Defaults to `10`. |
| `temperature` | number | No | Defaults to `0.7`. |
| `config` | object | No | Opaque config. |
| `status` | string | No | Defaults to `idle`. |
| `workspace_id` | string | No | Workspace ID. |
| `avatar` | string | No | Avatar reference. |
| `identity_key` | string | No | Public identity key. |
| `trust_tier` | string | No | Defaults to `standard`. |
| `harness_config` | object | Yes | Must include `mode`. |
| `enabled_modes` | array | Yes | At least one surface. |
| `character_json` | object | No | Character metadata. |
| `allowed_skills` | array | No | Skill allow-list. |
| `allowed_tools` | array | No | Tool allow-list. |
| `category` | string | No | Category label. |
| `tags` | array | No | Tags. |
| `data_classification` | string | No | Data classification. |
| `write_scope` | string | No | Write scope. |

#### Example request

```bash
curl -X POST https://api.allternit.com/api/agents \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Code Reviewer",
    "description": "Reviews pull requests for security and style issues.",
    "type": "worker",
    "model": "<specific-model>",
    "provider": "<provider>",
    "harness_config": { "mode": "local" },
    "enabled_modes": ["chat", "code"],
    "trust_tier": "standard",
    "system_prompt": "You are a senior code reviewer. Be concise.",
    "capabilities": { "execute_code": true, "file_search": true }
  }'
```

#### Example response

```json
{
  "agent": {
    "id": "agent_018f3a7c..."
  }
}
```

```http

```

Partial update using `COALESCE` semantics: omitted fields keep their current values. The same harness-mode and enabled-modes validations apply.

#### Example request

```bash
curl -X PUT https://api.allternit.com/api/agents/agent_018f3a7c... \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "system_prompt": "You are a senior security-focused code reviewer.",
    "temperature": 0.3
  }'
```

#### Example response

```json
{
  "success": true
}
```

### Delete an agent

```http

```

#### Example response

```json

  "success": true
}
```

## Subagents

Subagents are agents whose `mode` is `subagent` and whose `parent_agent_id` points to an orchestrator or the primary Companion. They are created through the same checklist as any other agent.

### List subagents

```http

```

Returns a compact view of all subagents under the parent agent.

```json

  "subagents": [
    {

      "type": "worker",

      "status": "idle",
      "created_at": "2026-08-10T09:15:00Z"

```

### Create a subagent

```http
POST /api/agents/:id/subagents
```

Creates a subagent under the parent. The route forces `parent_agent_id` to `:id` and `mode` to `subagent`. The parent must exist and belong to the caller.

#### Example request

```bash

  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
```

### List templates

```http

```

Returns all agent templates, built-ins first.

#### Example response

```json
{
  "templates": [
    {
      "id": "tmpl_a1b2...",
      "name": "Code Review Crew",
      "description": "An orchestrator plus two specialist subagents.",
      "category": "engineering",
      "spec": { "pattern": "crew", "agent": { ... }, "subagents": [ ... ] },
      "is_builtin": true,
      "created_at": "2026-07-01T12:00:00Z"
    }
  ]

```

### Instantiate a template

```http
POST /api/agents/from-template
```

Creates a live orchestrator and its subagents from a template. The default model preference can be overridden with `brain`; otherwise the user's default model is used, falling back to a local model.

#### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `template_id` | string | Yes | Template ID. |
| `brain` | object | No | Default model preference, `{ "provider": "...", "model": "..." }`. The field name is historical. |
| `name_override` | string | No | Override the orchestrator name. |

#### Example request

```bash
curl -X POST https://api.allternit.com/api/agents/from-template \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "template_id": "tmpl_a1b2...",
    "brain": { "provider": "<provider>", "model": "<specific-model>" },
    "name_override": "My Review Crew"
  }'
```

#### Example response

```json
{
  "pattern": "crew",
  "orchestrator": {
    "id": "agent_orch...",
    "name": "My Review Crew"
  },
  "subagents": [
    { "id": "agent_sub1...", "name": "Security Scanner" },
    { "id": "agent_sub2...", "name": "Style Checker" }
  ]
}
```

## Running agents

### Run an agent

```http
POST /api/agents/:id/runs
```

Sends `input` through the Gizzi runtime using the agent's profile, system prompt and default model preference. The call records a run, persists the outcome, and emits CommRails ledger events.

#### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `input` | string | Yes | User prompt. |
| `plan` | object | No | Opaque plan metadata. |
| `metadata` | object | No | Opaque run metadata. |

#### Example request

```bash
curl -X POST https://api.allternit.com/api/agents/agent_018f3a7c.../runs \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "Review this function for SQL injection risks."}'
```

#### Example response (success)

```json
{
  "run_id": "run_3f8a...",
  "agent_id": "agent_018f3a7c...",
  "session_id": "sess_9c1d...",
  "status": "completed",
  "output": "The function uses parameterized queries, so it is safe from SQL injection.",
  "model": "<specific-model>",
  "provider": "<provider>"
}
```

#### Example response (model error)

```json
{
  "run_id": "run_3f8a...",
  "agent_id": "agent_018f3a7c...",
  "session_id": "sess_9c1d...",
  "status": "error",
  "error": "model not found",
  "model": "<specific-model>",
  "provider": "<provider>"
}
```

### Stream agent events

```http
GET /api/agents/:id/events
```

Server-sent events (SSE) stream of CommRails ledger events scoped to the agent. Replays up to 50 recent matching events on connect, then polls for new events every 2 seconds.

#### Example curl

```bash
curl -H "Authorization: Bearer $TOKEN" \
  -H "Accept: text/event-stream" \
  https://api.allternit.com/api/agents/agent_018f3a7c.../events
```

#### Example event

```text
event: message
data: {"event_type":"agent.run.completed","agent_id":"agent_018f3a7c...","run_id":"run_3f8a...","timestamp":"2026-08-13T14:22:01Z","data":{"duration_ms":1240}}
```

## Workspace initialization

### Initialize agent workspace

```http
POST /api/agents/:id/workspace/initialize
```

Creates the agent's workspace directory and writes a batch of documents into it. Paths must be relative. Parent directories are created as needed.

#### Request body

| Field | Type | Description |
|-------|------|-------------|
| `documents` | array | List of `{ "path": "...", "content": "..." }`. |

#### Example request

```bash
curl -X POST https://api.allternit.com/api/agents/agent_018f3a7c.../workspace/initialize \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "documents": [
      { "path": "README.md", "content": "# Code Reviewer\n\nReviews PRs." },
      { "path": "rules.json", "content": "{\"max_lines\": 100}" }
    ]
  }'
```

#### Example response

```json
{
  "success": true,
  "workspace_path": "~/Library/Application Support/allternit/agent-workspaces/agent_018f3a7c...",
  "written_files": ["README.md", "rules.json"]
}
```

## Error codes

| Status | Meaning |
|--------|---------|
| `200` | Success. |
| `201` | Created. |
| `204` | No content (delete success). |
| `400` | Bad request — validation failed (checklist, missing fields, invalid rating). |
| `401` | Unauthorized — missing or invalid bearer token. |
| `403` | Forbidden — agent not enabled for the requested surface. |
| `404` | Not found — agent, listing, run result, or parent not found. |
| `422` | Unprocessable entity — template or dataset parse error. |
| `502` | Bad gateway — upstream Gizzi runtime error. |
| `500` | Internal server error. |
