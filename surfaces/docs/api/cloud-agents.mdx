Allternit Agents has two specialties. **Cloud Agents** is the hosted session API. **Bot Agents** are the same agent packaged as a teammate (`is_bot`, persistent Computer Cloud desktop).

Canonical reference in the platform repo: `docs/public/api/agents.md` and `docs/public/api/sessions.md`.

## Create a session

```bash
curl -X POST http://localhost:8013/api/v1/sessions \
  -H "Authorization: Bearer $CLERK_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "agent": { "model": "default", "instructions": "Be terse." },
    "computer": { "kind": "none" },
    "input": "Summarize the repo layout."
  }'
```

```ts
import { Allternit } from "@allternit/sdk/cloud-agents";
const allternit = new Allternit({ apiKey, baseURL: "http://localhost:8013" });
const session = await allternit.sessions.create({
  agent: { model: "default", instructions: "Be terse." },
  computer: { kind: "none" },
  input: "Summarize the repo layout.",
});
```

`computer.kind`: `none` | `local` | `sandbox` | `desktop` | `fabric`. Sandbox, desktop, and fabric provision Computer Cloud (Incus/Tart on the VPS). No VM driver → `503` `computer_unavailable`.

Budget includes `estimated_cost_usd` with `charged: false`. Allternit does not bill this.

**Cloud Console → Agents** is the developer session runner. It is not the Hub or Desktop chat composer (that is Chat and Bot Agents).

## Routes

Registered in `cmd/allternit-api/src/cloud_agents_routes.rs` under `/api/v1`:

| Method | Path |
|--------|------|
| `GET`, `POST` | `/sessions` |
| `GET` | `/sessions/:id` |
| `POST` | `/sessions/:id/archive` |
| `GET`, `POST` | `/sessions/:id/events` |
| `GET` | `/sessions/:id/events/stream` |
| `GET` | `/sessions/:id/turns` |
| `GET` | `/sessions/:id/threads` |
| `GET` | `/sessions/:id/outputs` |

The create body also accepts `stream`, `vault_ids`, `budget`, `metadata`, `brain_id`, `memory_store_ids`, `parent_thread_id`, `permission` and a packaged bot id. Status: Implementation IMPLEMENTED, Exposure INTERNAL (data-plane node; not routed on the hosted Cloud API).

## Bot Agents

```ts
const bot = await allternit.bots.create({
  name: "research",
  systemPrompt: "Be terse.",
  botProfile: { tagline: "Looks things up" },
});
await allternit.sessions.create({ botId: bot.id, computer: { kind: "desktop" } });
```
