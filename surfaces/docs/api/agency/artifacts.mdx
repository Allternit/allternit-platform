An **artifact** is an output produced by a run: a patch, a file, a report, a dataset, a log. Artifacts are immutable and content-addressed, and each one is recorded by a receipt. These endpoints open with the rest of the API, after a run can survive restart, resume, verify, replay and receipt-backed completion.

<Note>
This page covers artifacts of Agency API runs. The existing [Artifacts API](/api/artifacts) for the collaboration surface is a separate, live API.
</Note>

## The Artifact object

The Artifact is the public view of the kernel's node output contract.

{{fields:Artifact}}

Notes:

- `hash` is `sha256:` followed by 64 lowercase hex characters. Use it to check the bytes you download.
- `verification_status` says whether a verifier has checked this artifact. `unverified` means no verifier has run on it. `inconclusive` is not a pass.
- `content_url` is short-lived. Fetch the artifact again to get a fresh URL.
- `metadata` is an open object.
- `trust_class` is a [TrustClass](/api/agency/schemas#trustclass): `PUBLIC`, `INTERNAL`, `RESTRICTED`, `SECRET` or `UNTRUSTED`.

## Download and check content

```python
import hashlib, requests

artifact = requests.get(
    f"{BASE}/v1/runs/{run_id}/artifacts/{artifact_id}",
    headers={"Authorization": f"Bearer {KEY}"},
).json()

body = requests.get(artifact["content_url"]).content
assert "sha256:" + hashlib.sha256(body).hexdigest() == artifact["hash"]
```

```typescript
import { createHash } from "node:crypto";

const artifact = await (
  await fetch(`${BASE}/v1/runs/${runId}/artifacts/${artifactId}`, {
    headers: { Authorization: `Bearer ${KEY}` },
  })
).json();

const body = Buffer.from(await (await fetch(artifact.content_url)).arrayBuffer());
const digest = "sha256:" + createHash("sha256").update(body).digest("hex");
if (digest !== artifact.hash) throw new Error("artifact content does not match its hash");
```
