A **receipt** is append-only, content-addressed evidence of an effect, an input, a policy decision or a verification result. Receipts for a run form a hash chain and each one is signed. For the concepts see [Receipts](/architecture/receipts).

Today receipts exist as hashes only. The chain, the signatures and the keys endpoint are not built. Receipt-backed completion is part of the alpha gate (restart, resume, verify, replay, receipt-backed completion).

## The Receipt object

{{fields:Receipt}}

Receipt IDs start with `rcpt_`.

- `content_hash` is SHA-256 over the canonical JSON (RFC 8785, JCS) of every field except `content_hash` and `signature`.
- `prev_hash` is the previous receipt's `content_hash` in the same run. It is `null` only at index 0.
- A correction appends a new receipt with `supersedes` set. Receipts are never edited.
- `payload` is an open object whose shape depends on `type`. Component identities appear in it only with `view=debug`.

### Receipt types

[ReceiptType](/api/agency/schemas#receipttype)

| `type` | Records |
|--------|---------|
| `run` | The run's terminal state. |
| `tool` | A tool invocation and its result. |
| `action` | An external or irreversible action. Carries `idempotency_key`. |
| `mutation` | A change to the workspace. |
| `verification` | A verifier's result. |
| `policy` | A policy decision. |
| `node_output` | An artifact produced by a node. |
| `input` | Human or caller input. |
| `attention` | An attention request or its resolution. |
| `control` | Pause, resume or cancel. |
| `spawn` | The start of an executor. |

### Signature

`signature` ([ReceiptSignature](/api/agency/schemas#receiptsignature)):

{{fields:ReceiptSignature}}

The signed material is the JCS-canonical form of `{schema_id, schema_version, domain, content_hash}`. Including the schema ID, schema version and the domain tag `allternit.receipt.v1` means a signature cannot be reused for another schema, version or protocol.

## Verify independently

The steps:

1. Fetch every receipt for the run, unfiltered, in chain order.
2. For each receipt, drop `content_hash` and `signature`, canonicalize the rest with RFC 8785, hash with SHA-256 and compare with `content_hash`.
3. Check `index` is sequential and `prev_hash` equals the previous `content_hash` (`null` at index 0).
4. For each signature, canonicalize `{schema_id, schema_version, domain, content_hash}` and verify the Ed25519 signature (`value`, base64url) with the JWKS key whose `kid` matches `key_id`. Check `domain` is `allternit.receipt.v1`.

The examples use third-party open-source libraries for RFC 8785 canonicalization and Ed25519: `rfc8785` and `cryptography` in Python, and `canonicalize` plus the built-in `node:crypto` in Node.js. Fetch receipts with the default view, since the hash covers the receipt as served in that view.

<CodeGroup>

```python Python
import base64, hashlib
import requests, rfc8785
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey

DOMAIN = "allternit.receipt.v1"

def b64url_decode(s: str) -> bytes:
    return base64.urlsafe_b64decode(s + "=" * (-len(s) % 4))

def verify_chain(receipts: list[dict], jwks: dict) -> None:
    keys = {
        k["kid"]: Ed25519PublicKey.from_public_bytes(b64url_decode(k["x"]))
        for k in jwks["keys"]
        if k["kty"] == "OKP" and k["crv"] == "Ed25519"
    }
    prev = None
    for i, r in enumerate(receipts):
        body = {k: v for k, v in r.items() if k not in ("content_hash", "signature")}
        digest = "sha256:" + hashlib.sha256(rfc8785.dumps(body)).hexdigest()
        if digest != r["content_hash"]:
            raise ValueError(f"content hash mismatch at index {i}")
        if r["index"] != i or r["prev_hash"] != prev:
            raise ValueError(f"chain link broken at index {i}")

        sig = r.get("signature")
        if sig is None:
            raise ValueError(f"receipt {i} is unsigned")
        if sig["domain"] != DOMAIN:
            raise ValueError(f"unexpected signature domain at index {i}")
        signed = rfc8785.dumps({
            "schema_id": r["schema_id"],
            "schema_version": r["schema_version"],
            "domain": sig["domain"],
            "content_hash": r["content_hash"],
        })
        # raises cryptography.exceptions.InvalidSignature on failure
        keys[sig["key_id"]].verify(b64url_decode(sig["value"]), signed)
        prev = r["content_hash"]

jwks = requests.get("https://api.allternit.com/.well-known/jwks.json").json()
verify_chain(receipts, jwks)  # `receipts` = every page of GET /v1/runs/{run_id}/receipts
```

```typescript TypeScript
import { createHash, createPublicKey, verify } from "node:crypto";
import canonicalize from "canonicalize";

const DOMAIN = "allternit.receipt.v1";

function verifyChain(receipts: any[], jwks: { keys: any[] }): void {
  const keys = new Map(
    jwks.keys
      .filter((k) => k.kty === "OKP" && k.crv === "Ed25519")
      .map((k) => [k.kid, createPublicKey({ key: k, format: "jwk" })]),
  );

  let prev: string | null = null;
  receipts.forEach((r, i) => {
    const { content_hash, signature, ...body } = r;
    const digest = "sha256:" + createHash("sha256").update(canonicalize(body)!).digest("hex");
    if (digest !== content_hash) throw new Error(`content hash mismatch at index ${i}`);
    if (r.index !== i || r.prev_hash !== prev) throw new Error(`chain link broken at index ${i}`);

    if (!signature) throw new Error(`receipt ${i} is unsigned`);
    if (signature.domain !== DOMAIN) throw new Error(`unexpected signature domain at index ${i}`);
    const key = keys.get(signature.key_id);
    if (!key) throw new Error(`unknown key ${signature.key_id}`);
    const signed = canonicalize({
      schema_id: r.schema_id,
      schema_version: r.schema_version,
      domain: signature.domain,
      content_hash,
    })!;
    const ok = verify(null, Buffer.from(signed), key, Buffer.from(signature.value, "base64url"));
    if (!ok) throw new Error(`bad signature at index ${i}`);
    prev = content_hash;
  });
}

const jwks = await (await fetch("https://api.allternit.com/.well-known/jwks.json")).json();
verifyChain(receipts, jwks); // `receipts` = every page of GET /v1/runs/{run_id}/receipts
```
