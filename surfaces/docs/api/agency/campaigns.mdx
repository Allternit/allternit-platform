title: 'Campaigns'
description: 'Persistent objectives that create and drive runs over time: create, list, read, pause, resume and cancel.'
---

<Warning>
Preview — the Agency API is in development and not yet available. This reference describes the v0.3 contract; details may change before alpha.
</Warning>

A **campaign** is a persistent objective that wakes and drives runs over time. A campaign is not a cron job. It owns an objective, a budget, completion criteria and the logic for deciding when another check is useful. Wake triggers only make a wake eligible; the campaign then decides whether to start a run.

<Note>
**Scheduled waking is off.** Campaigns can be created and wake triggers are accepted, but autonomous scheduled waking stays disabled until the API has passed alpha and conformance and an explicit go-live decision is made. Until then every campaign reports `scheduling: "disabled_pending_golive"`, no wake fires, `next_wake` is `null`, and manual runs still work. The alpha itself opens only after a run can survive restart, resume, verify, replay and receipt-backed completion.
</Note>

## The Campaign object

{{fields:Campaign}}

Campaign IDs match `^cmp_[A-Za-z0-9]+$`.

### Status

[CampaignStatus](/api/agency/schemas#campaignstatus). Status is independent of `scheduling`.

| `status` | Meaning |
|----------|---------|
| `active` | Created; first wake pending. |
| `sleeping` | Waiting for `next_wake`. |
| `running` | At least one child run is not terminal. |
| `needs_attention` | A child run or the campaign itself has an open attention request. |
| `paused` | Paused; no future wakes. |
| `completed` | The campaign's completion criteria are met by receipts. |
| `failed` | The campaign failed. |
| `cancelled` | The campaign was cancelled. |

### Budget

[CampaignBudget](/api/agency/schemas#campaignbudget): caps for the whole campaign plus a per-run [Budget](/api/agency/schemas#budget) applied to every child run. At least one of `max_cost_usd` or `max_runs` is required.

{{fields:CampaignBudget}}

### Wake policy

[WakePolicy](/api/agency/schemas#wakepolicy): when the campaign may consider waking. Limits are versioned defaults (`defaults_version`).

{{fields:WakePolicy}}

Each trigger is a [WakeTrigger](/api/agency/schemas#waketrigger), one of five variants selected by `type`:

| `type` | Fields | Wake becomes eligible |
|--------|--------|-----------------------|
| `interval` | `interval_seconds` (min 60), `jitter_seconds` (default 0) | Every interval. |
| `schedule` | `cron`, `timezone` | At times matching the schedule. |
| `event` | `source` (resource URI or connector event, for example `repo://acme/store#push`), `filter` (string map) | When the event occurs. |
| `run_finished` | none | When a child run finishes. |
| `manual` | none | Only when started manually. |

### Attention policy

[AttentionPolicy](/api/agency/schemas#attentionpolicy): how attention requests from this campaign's runs are delivered.

{{fields:AttentionPolicy}}

## Create a campaign

```http
POST /v1/campaigns
```

Only `objective` is required. Workspace, authority, budget, completion criteria and wake policy resolve from the agent's and profile's defaults and are returned on `Campaign.resolved` before any run is created. There are no hidden permissive defaults: if a safe value cannot be resolved the request fails with `ERR_DEFAULTS_UNRESOLVABLE`.

### Parameters

{{params:createCampaign}}

### Request body

[CampaignCreate](/api/agency/schemas#campaigncreate)

{{fields:CampaignCreate}}

`workspace`, `authority` and `completion_criteria` have the same shape as on a run request. See [Create a run](/api/agency/runs#create-a-run).

### Responses

{{responses:createCampaign}}

## Pause a campaign

```http
POST /v1/campaigns/{campaign_id}/pause
```

Asynchronous and idempotent. Stops future wakes. Runs already in flight are unaffected unless `cascade` is `true`.

### Parameters

{{params:pauseCampaign}}

### Request body

Optional. [CampaignControlRequest](/api/agency/schemas#campaigncontrolrequest)

{{fields:CampaignControlRequest}}

### Responses

{{responses:pauseCampaign}}

### Example

```bash
curl -X POST https://api.allternit.com/v1/campaigns/cmp_01JB2M0A3T/pause \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY" \
  -H "Idempotency-Key: 84a1c3e5-2b4d-4f6a-8c0e-1a3c5e7a9b0d" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Release freeze", "cascade": false}'
```

The response is the Campaign.

## Cancel a campaign

```http
POST /v1/campaigns/{campaign_id}/cancel
```

Asynchronous, idempotent and terminal. With `cascade` (default `true`) every non-terminal child run is cancelled with [run cancel semantics](/api/agency/runs#cancel-a-run).

### Parameters

{{params:cancelCampaign}}

### Request body

Optional. [CampaignControlRequest](/api/agency/schemas#campaigncontrolrequest) (`reason`, `cascade`).

### Responses

{{responses:cancelCampaign}}

### Example

```bash
curl -X POST https://api.allternit.com/v1/campaigns/cmp_01JB2M0A3T/cancel \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY" \
  -H "Idempotency-Key: d2f4a6c8-7e9b-4c1d-a3f5-4c6e8a0b2d3f" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Project closed", "cascade": true}'
```

The response is the Campaign. Its status becomes `cancelled` once child runs have settled.
