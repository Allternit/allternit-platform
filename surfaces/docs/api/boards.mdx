## Overview

The Boards API stores workspace-scoped board items such as tasks, tickets, or planning cards. Access is enforced through workspace membership (owner or member). Items support status, priority, labels, deadlines, dependencies, assignment, and comments.

<Note>
This namespace is served by the Allternit API data-plane node (`http://127.0.0.1:8013` on the same machine, or your paired or provisioned node). The hosted Cloud API at `https://api.allternit.com` does not route it; it relays only agent sessions, canvases, office and beta research/sessions. See [Cloud API](/api/cloud-api).
</Note>

## Base URL

```text
http://127.0.0.1:8013/api
```

## Authentication

All requests require a valid bearer token in the `Authorization` header. See [Authentication](/api/authentication) for details.

## Board item object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique item identifier. |
| `workspaceId` | string | Workspace identifier. |
| `title` | string | Item title. |
| `description` | string \| null | Optional description. |
| `status` | string | Current status, default `backlog`. |
| `priority` | integer | Priority value. |
| `labels` | string[] | Label list. |
| `estimatedMinutes` | integer \| null | Optional effort estimate. |
| `deadline` | string \| null | Optional ISO 8601 deadline. |
| `dependencies` | string[] | Dependency item ids. |
| `reporterId` | string \| null | User who created the item. |
| `assigneeId` | string \| null | Assigned user id. |
| `createdAt` | string | ISO 8601 creation timestamp. |
| `updatedAt` | string | ISO 8601 update timestamp. |

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/board-items` | List board items in a workspace. |
| `POST` | `/board-items` | Create a board item. |
| `GET` | `/board-items/:id` | Get a board item. |
| `PUT` | `/board-items/:id` | Update a board item. |
| `DELETE` | `/board-items/:id` | Delete a board item. |
| `POST` | `/board-items/:id/assign` | Assign the item to a user. |
| `GET` | `/board-items/:id/comments` | List comments on an item. |
| `POST` | `/board-items/:id/comments` | Add a comment to an item. |

## List board items

```bash
curl "http://127.0.0.1:8013/api/board-items?workspace_id=ws_01hqx8x7x7x7x7x7x7x7x7x" \
  -H "Authorization: Bearer $TOKEN"
```

### Query parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `workspace_id` | string | Required workspace identifier. |

```json
      "priority": 3,

      "createdAt": "2026-08-13T18:00:00Z",
      "updatedAt": "2026-08-13T18:05:00Z"
    }
  ]
}
```

## Create board item

```bash
curl -X POST http://127.0.0.1:8013/api/board-items \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "workspaceId": "ws_01hqx8x7x7x7x7x7x7x7x7x",
    "title": "Document Factory commands",
    "description": "Write Mintlify pages for the gizzi workspace commands.",
    "status": "backlog",
    "priority": 2,
    "labels": ["docs", "factory"],
    "estimatedMinutes": 120,
    "deadline": "2026-08-20T18:00:00Z",
    "dependencies": []
  }'
```

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `workspaceId` | string | yes | Workspace identifier. |
| `title` | string | yes | Item title. |
| `description` | string | no | Optional description. |
| `status` | string | no | Status, default `backlog`. |
| `priority` | integer | no | Priority, default `0`. |
| `labels` | string[] | no | Label list. |
| `estimatedMinutes` | integer | no | Effort estimate. |
| `deadline` | string | no | ISO 8601 deadline. |
| `dependencies` | string[] | no | Dependency item ids. |

### Response

```json
{
  "item": {
    "id": "bi_02hqx8x7x7x7x7x7x7x7x7x",
    "title": "Document Factory commands",
    "status": "backlog"
  }
}
```

## Update board item

```bash
curl -X PUT http://127.0.0.1:8013/api/board-items/bi_02hqx8x7x7x7x7x7x7x7x7x \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "in_progress",
    "priority": 3
  }'
```

### Response

```json
{
  "success": true
}
```

## Assign board item

```bash
curl -X POST http://127.0.0.1:8013/api/board-items/bi_02hqx8x7x7x7x7x7x7x7x7x/assign \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"assigneeId": "user_2d9e..."}'
```

### Response

```json
{
  "success": true
}
```

## Add comment

```bash
curl -X POST http://127.0.0.1:8013/api/board-items/bi_02hqx8x7x7x7x7x7x7x7x7x/comments \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"body": "Draft is ready for review."}'
```

### Response

```json
{
  "id": "cm_01hqx8x7x7x7x7x7x7x7x7x"
}
```

## Error codes

| Status | Code | Description |
|--------|------|-------------|
| `401` | `Unauthorized` | Missing or invalid bearer token. |
| `403` | `Access denied` | User is not a member of the workspace. |
| `404` | `not_found` | Board item not found. |
| `500` | `internal_error` / `DB error` | Database or server error. |
