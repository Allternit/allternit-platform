## Overview

The Me API returns the current authenticated user's profile, proxies weekly usage metering from the cloud API, and lets self-hosted users create a personal organization when no Clerk-managed organization is available.

## Base URL

```
https://api.allternit.com/api/v1/me
```

All endpoints require a valid Bearer token in the `Authorization` header. See [Authentication](/api/authentication) for details.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/me` | Get the current user profile. |
| GET | `/me/usage` | Get weekly usage metering for the caller. |
| POST | `/me/organization` | Create a personal organization (self-hosted/no-Clerk only). |
| GET | `/me/flags` | Read the caller's account UI flags (Allternit Cloud). |
| PUT | `/me/flags` | Set account UI flags (Allternit Cloud). |

The setup checklist has its own page: [Setup checks API](/api/setup-checks).

## Get current user

```bash
GET /api/v1/me
```

Response:

```json
{
  "user": {
    "id": "user_abc123",
    "clerk_id": "usr_clerk_abc123",
    "email": "dev@example.com",
    "name": "Example User",
    "avatar_url": "https://example.com/avatar.png",
    "role": "user",
    "status": "active",
    "created_at": "2026-01-01T00:00:00Z",
    "organization_id": "org_abc123",
    "organization_role": "owner"
  }
}
```

If the user row is not yet persisted, a synthetic profile is returned from the authentication claims.

## Get my usage

```bash
GET /api/v1/me/usage
```

Proxies the cloud API quota/entitlements service. The cloud API URL is resolved from `ALLTERNIT_CLOUD_API_URL` or company config `cloudApiUrl`.

Response:

```json
{
  "plan": "pro",
  "label": "Pro",
  "status": "active",
  "planTier": "pro",
  "weeklyUsed": 42.5,
  "weeklyLimit": 100,
  "resetsAt": "2026-08-17T00:00:00Z",
  "credits": 150,
  "monthToDateUsageUsd": 12.4,
  "recentTransactions": []
}
```

If no cloud API is configured or the service is unreachable, the endpoint returns `503 Service Unavailable` with a clear error.

## Create personal organization

```bash
POST /api/v1/me/organization
```

Creates a personal organization for the caller and assigns the owner role. This is primarily useful for self-hosted or no-Clerk-key deployments where the middleware does not auto-synthesize an organization. If the caller already has an organization, the endpoint returns the existing one with `created: false`.

Response:

```json
{
  "organization_id": "org_abc123",
  "created": true
}
```

## Account flags

```bash
GET /api/v1/me/flags
PUT /api/v1/me/flags
```

Served by the Allternit Cloud API (`https://api.allternit.com`). Small per-account UI flags stored in the caller's Clerk user `unsafe_metadata`, so they follow the account across Allternit Desktop, ai.allternit.com and the m.allternit.com app. Web and the phone app write the same keys with the Clerk client; Desktop has no Clerk client and uses this endpoint with its Clerk session token.

Auth: a Clerk session JWT, or an API token with the `account` scope.

The only flag today is `botsIntroSeenAt`: when the person finished or skipped the **Meet your bots** card (an ISO-8601 time). Every allowed flag is always present in the response, `null` when unset.

Response (both methods):

```json
{
  "flags": {
    "botsIntroSeenAt": "2026-10-20T12:00:00.000Z"
  }
}
```

`PUT` body: an object of the flags to set. Each value must be an RFC 3339 / ISO-8601 time string of at most 40 characters. Only the flags you send change; other metadata on the account is kept.

```json
{ "botsIntroSeenAt": "2026-10-20T12:00:00.000Z" }
```

| Status | Code | When |
|--------|------|------|
| 400 | `BAD_REQUEST` | Body isn't an object, is empty, names an unknown flag, or a value isn't an ISO-8601 time. |
| 415 / 422 | — | `PUT` without `Content-Type: application/json`, or a body that isn't valid JSON (plain-text error). |
| 401 | `UNAUTHORIZED` | Missing or invalid Clerk session or API token. |
| 403 | `FORBIDDEN` | API token without the `account` scope. |
| 404 | `NOT_FOUND` | The account doesn't exist in Clerk. |
| 503 | `SERVICE_UNAVAILABLE` | `CLERK_SECRET_KEY` isn't configured, or Clerk couldn't be reached. Nothing was changed. |

## Error codes

| Status | Code | Description |
|--------|------|-------------|
| 200 | — | Success. |
| 201 | — | Personal organization created. |
| 401 | `unauthorized` | Missing or invalid authentication. |
| 503 | `usage_metering_unavailable` | No cloud API URL configured. |
| 503 | `usage_metering_unreachable` | Cloud API could not be reached. |
| 503 | `usage_metering_upstream_error` | Cloud API returned a non-2xx status. |
| 503 | `usage_metering_bad_response` | Cloud API response could not be decoded. |
| 500 | `db_error` / `internal_error` | Unexpected server error. |
