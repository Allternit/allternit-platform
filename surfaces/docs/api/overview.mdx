## One public API

Allternit exposes **one public origin**:

```
https://api.allternit.com
```

That origin is the **Cloud API** (`cmd/allternit-cloud-api`). Browsers, SDKs, and CI talk only to it.

The **Allternit API** (`cmd/allternit-api`, port 8013) is the **data-plane runtime**. It holds per-instance SQLite state (sessions, office bindings, local workspaces). It is never a public hostname. The Cloud API authenticates the caller, picks a healthy node, and relays the request.

<Note>
Do not point production clients at `http://localhost:8013` or at any second public gateway. Local 8013 is for desktop and development only.
</Note>

## Agency API (Preview)

The [Agency API](/api/agency/overview) is a new surface of the same Cloud API, on the same origin: `https://api.allternit.com/v1/agency`. You send a goal and get one durable, verified run. It is **PREVIEW**: the v0.3 contract is published for review and the endpoint is not served yet. It is the public surface over the [agent kernel](/architecture/kernel); see [Kernel and Agency API](/architecture#kernel-and-agency-api).

## Which API do I call?

| You want to… | Call | Binary | Storage |
|--------------|------|--------|---------|
| Pair a desktop or VPS, proxy to it, provision hosted/provisioned compute, bill, list models | [Cloud API](/api/cloud-api) | `allternit-cloud-api` | Postgres |
| Run chat completions / embeddings with a virtual key | Cloud API `/v1/*` | `allternit-cloud-api` | Postgres + model router |
| Create an agent session, Office binding, or beta research session | Cloud API `/api/v1/sessions` (Cloud Agents), `/api/v1/office`, `/api/v1/beta/*` | Cloud API **relays** to Allternit API on your node | Node SQLite |
| Create an agent session, Office binding, or beta research session | Cloud API `/api/v1/agent-sessions`, `/api/v1/office`, `/api/v1/beta/*` | Cloud API **relays** to Allternit API on your node | Node SQLite |
| Send a goal and get one durable, verified run (PREVIEW, not served yet) | [Agency API](/api/agency/overview) `/v1/agency` | `allternit-cloud-api` | Postgres |
| Run the runtime yourself (desktop, your VPS, or an Allternit-provisioned box) | [Allternit API](/api/allternit-api) on loopback / tailnet | `allternit-api` | Per-instance SQLite |

## Topology

```
Browser / SDK / CLI
        │  HTTPS + Clerk JWT, virtual key, or device token
        ▼
┌──────────────────────────────────────────┐
│  Cloud API — control plane               │
│  https://api.allternit.com               │
│  pairing · relay · billing · models      │
│  hosted runtimes · provisioned fleet     │
└──────────────────┬───────────────────────┘
                   │ outbound WebSocket relay
                   ▼
┌──────────────────────────────────────────┐
│  Allternit API — data plane              │
│  :8013, not public                       │
│  Mode 1  local desktop                   │
│  Mode 2  user-paired VPS                 │
│  Mode 3  Allternit-provisioned instance  │
└──────────────────┬───────────────────────┘
                   │
                   ▼
            Gizzi runtime (local)
```

## Authentication at a glance

| Credential | Prefix / shape | Used for |
|------------|----------------|----------|
| Clerk session JWT | Clerk `sess` JWT | Browser → Cloud API (pairing approval, relay, P1 namespaces, billing) |
| Virtual key | `ak-` | LLM gateway `/v1/chat/completions` and related |
| Runtime device token | `allternit_runtime_…` | Node → Cloud API (heartbeat, relay connect, rotate) |

See [Authentication](/api/authentication).

## Data-plane relay

Namespaces that store state on the node (agent sessions, Office, beta research) are **Cloud API handlers**. They do not keep a second copy of that state in Postgres.

1. Authenticate the Clerk session.
2. Resolve the caller's default healthy node (desktop, paired box, or provisioned instance). Online means a recent heartbeat.
3. Forward the original request — including the caller's `Authorization` header — over the node's outbound relay WebSocket.
4. Stream the node's response back. Nothing is cached or rewritten.

If the account has no healthy node, the Cloud API returns **HTTP 428** (`pair a device`). Pair a runtime or start a provisioned instance, then retry.
