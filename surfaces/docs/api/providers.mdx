# Providers

The Providers API lists available LLM providers, reports their authentication status, discovers models, and connects subscription or API-key providers through the Gizzi runtime. Provider credentials are stored by Gizzi; the API only reads connection metadata. The same routes are also mounted under `/api` without the `v1` prefix.

<Note>
Existing runtime/provider APIs expose implementation controls intentionally. The Agency API is the abstraction that hides those controls behind capabilities and one durable agent identity.
</Note>

## Base URL

```text
https://api.allternit.com/api/v1
```

For local development:

```text
http://127.0.0.1:8013/api/v1
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/providers` | List providers |
| `GET` | `/api/v1/providers/:id` | Get a provider |
| `GET` | `/api/v1/providers/:id/auth/status` | Get provider auth status |
| `GET` | `/api/v1/providers/:id/quota` | Plan usage windows (5-hour, weekly) for a subscription provider, relayed from the Gizzi runtime. Always `200` with a `status` field (`signed out` / `unsupported` instead of an error). |
| `GET` | `/api/v1/providers/:id/models` | Discover provider models |
| `POST` | `/api/v1/providers/:id/connect` | Start a provider connect flow |
| `GET` | `/api/v1/providers/:id/connect/status` | Check connect status |
| `POST` | `/api/v1/providers/:id/connect/confirm` | Confirm a completed connect flow |
| `GET` | `/api/v1/providers/auth/status` | List auth status for all providers |
| `POST` | `/api/v1/providers/video/generate` | Generate a video via a media provider |
| `GET` | `/api/v1/media/catalog` | Media generation catalog |
| `POST` | `/api/v1/media/video/jobs` | Submit a video generation job |
| `GET` | `/api/v1/media/video/jobs/:job_id` | Get a video job |
| `GET` | `/api/v1/media/video/jobs/:job_id/download` | Download a finished video |
| `POST` | `/api/v1/media/image/generate` | Generate an image |
| `POST` | `/api/v1/media/artifacts` | Upload a media artifact |
| `GET` | `/api/v1/media/artifacts/:artifact_id` | Get a media artifact |
| `GET` | `/api/v1/media/providers` | List media providers |
| `GET` | `/api/v1/media/:mode/providers` | List media providers for a mode |
| `POST` | `/api/v1/media/:mode/generate` | Generate media for a mode |
| `GET` | `/api/v1/provider/ollama/status` | Probe local Ollama status |
| `GET` | `/api/v1/provider/ollama/models` | List local Ollama models |
| `GET` | `/api/v1/provider/huggingface/search` | Search public GGUF model registry |

## List providers

```bash
curl https://api.allternit.com/api/v1/providers \
  -H "Authorization: Bearer $TOKEN"
```

### Response

```json
{
  "providers": [
    {
      "id": "provider-a",
      "name": "Provider A",
      "provider_type": "api",
      "base_url": null,
      "api_key_set": true,
      "models": ["model-a-mini", "model-a-large"],
      "status": "active"
    },
    {
      "id": "local-brain",
      "name": "Local Brain",
      "provider_type": "local",
      "base_url": "http://127.0.0.1:11434",
      "api_key_set": false,
      "models": ["local-model:3b"],
      "status": "active"
    }
  ],
  "all": [...]
}
```

### Provider status values

| Status | Meaning |
|--------|---------|
| `active` | Ready to route requests |
| `unconfigured` | No API key or credential detected |
| `missing_key` | Binary or config present but auth missing |
| `offline` | Local or subprocess provider not reachable |
| `unknown` | Reachability not yet determined |

## Get provider auth status

```bash
curl https://api.allternit.com/api/v1/providers/provider-a/auth/status \
  -H "Authorization: Bearer $TOKEN"
```

### Response

```json
{
  "provider": {
    "provider_id": "provider-a",
    "status": "ok",
    "authenticated": true,
    "auth_required": true,
    "auth_profile_id": "provider-a-auth",
    "chat_profile_ids": ["provider-a-default"],
    "details": {
      "provider_type": "api",
      "base_url": null,
      "api_key_set": true,
      "model_count": 2,
      "capabilities": {
        "tool_call": true,
        "vision": true,
        "limits": { "context": 128000, "output": 16384 },
        "default_model": "model-a-large"
      }
    }
  }
}
```

## Discover provider models

```bash
curl https://api.allternit.com/api/v1/providers/provider-a/models \
  -H "Authorization: Bearer $TOKEN"
```

### Response

```json
{
  "supported": true,
  "models": [
    { "id": "model-a-mini", "name": "model-a-mini" }
  ],
  "default_model_id": "model-a-mini",
  "allow_freeform": true
}
```

For subprocess providers, `supported` may be `false` because the runtime owns model discovery, but `allow_freeform` remains `true`.

## Connect a provider

```bash
curl -X POST https://api.allternit.com/api/v1/providers/cli-provider/connect \
  -H "Authorization: Bearer $TOKEN"
```

### Response states

```json
{
  "status": "already_connected",
  "provider": "cli-provider",
  "label": "CLI Provider"
}
```

Possible statuses: `already_connected`, `connected`, `needs_api_key`, `not_installed`, `started`.

## Check connect status

```bash
curl https://api.allternit.com/api/v1/providers/cli-provider/connect/status \
```

```json
      "likes": 850
    }
  ]

```

## Error codes

| Status | Code | Description |
|--------|------|-------------|
| `401` | `Unauthorized` | Missing or invalid bearer token. |
| `404` | `not_found` / `unknown_provider` | Provider not found. |
| `502` | `gizzi_provider_error` | Gizzi runtime returned an error for media generation. |
| `502` | `huggingface_error` | Public registry returned a non-success status. |
| `502` | `huggingface_unreachable` | Could not reach the public registry. |
| `500` | `internal_error` | Database or server error. |
