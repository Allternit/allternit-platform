## Overview

The Models API exposes the models that the connected Allternit runtime can serve, along with routing policy aliases and a cross-provider pricing snapshot. Model listings are filtered by the virtual key's allowlist, so callers only see models they are permitted to use.

## Base URL

```
https://api.allternit.com/v1
```

For local development:

```
http://127.0.0.1:8013/v1
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/models` | List catalog models |
| `GET` | `/v1/models/*id` | Retrieve a single catalog model |
| `GET` | `/v1/pricing` | List per-model pricing |

## List models

`GET /v1/models` is served by the Fabric model catalog. It requires an active organization (`403 organization_required` otherwise) and lists catalog entries, not policy aliases.

```bash
curl https://api.allternit.com/v1/models \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

### Example response

```json
{
  "object": "list",
  "data": [
    {
      "id": "provider/model-id",
      "object": "model",
      "created": 0,
      "owned_by": "provider",
      "display_name": "Model Display Name",
      "context_window": 128000,
      "quality_tier": "standard",
      "pricing": {
        "input_cents_per_1m": 250,
        "output_cents_per_1m": 1000
      }
    }
  ]
}
```

### Model object fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | `provider/model` id. |
| `object` | string | `model`. |
| `created` | integer | Always `0`. |
| `owned_by` | string | Provider kind. |
| `display_name` | string | Human-readable name. |
| `context_window` | integer | Context tokens. |
| `quality_tier` | string | Catalog quality tier. |
| `pricing` | object | `input_cents_per_1m` and `output_cents_per_1m`. |

## Policy aliases

Policy aliases are not returned by `/v1/models`. Pass one as the `model` of a chat completion to trigger the gateway's benchmark-weighted router, which picks a concrete provider/model pair and derives a cross-provider fallback chain.

| Alias | Optimization target |
|-------|---------------------|
| `auto` | Same as `allternit-balanced`. |
| `allternit-balanced` | Balanced quality and cost across all benchmarks. |
| `allternit-code` | Coding and software-engineering tasks. |
| `allternit-reasoning` | Reasoning, math, and science tasks. |
| `allternit-knowledge` | Knowledge and recall tasks. |
| `allternit-instruct` | Instruction-following and chat quality. |

## Retrieve a model

```bash
curl https://api.allternit.com/v1/models/provider/model-id \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

Returns one model object as above. An unknown id returns `404` with `{ "error": "model_not_found", "message": "..." }`. Aliases are not retrievable here.

## Pricing

`GET /v1/pricing` returns the current per-model rates in dollars per 1 million tokens.

```bash
curl https://api.allternit.com/v1/pricing \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "provider/model-id",
      "object": "model_pricing",
      "input": 2.50,
      "output": 10.00,
      "cache_read": 1.25,
      "cache_write": 0.00,
      "context_over_200k": null
    }
  ]
}
```

### Pricing fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | `provider/model` id. |
| `object` | string | `model_pricing`. |
| `input` | number | Input-token price per 1M tokens. |
| `output` | number | Output-token price per 1M tokens. |
| `cache_read` | number | Cache-read price per 1M tokens. |
| `cache_write` | number | Cache-write price per 1M tokens. |
| `context_over_200k` | object | Higher rates when input plus cache read exceeds 200k tokens. |

## Error codes

| HTTP status | Code | Meaning |
|-------------|------|---------|
| 401 | `allternit.authentication_failed` | Missing or invalid API key. |
| 404 | `model_not_found` | `GET /v1/models/*id`: model not in the catalog. |
| 400 | `allternit.model_not_found` | Chat completion named an unknown model. |
| 429 | `allternit.rate_limited` | Per-key rate limit exceeded. |
| 429 | `allternit.budget_exceeded` | Monthly key or tenant budget exhausted. |
| 500 | `allternit.internal_error` | Internal gateway error. |
