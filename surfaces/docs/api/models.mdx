## Overview

There are two model lists:

- **Hosted Cloud API** (`https://api.allternit.com/v1`): the public models you pay for with Allternit Cloud credits. Prices in this list are what a request is billed.
- **Local runtime gateway** (`http://127.0.0.1:8013/v1`): the gateway inside the Allternit runtime on your own machine. It lists the Fabric model catalog, filtered by the virtual key's allowlist, plus policy aliases and a pricing snapshot.

## Hosted Cloud API

`GET https://api.allternit.com/v1/models` lists every model you can call with `POST /v1/chat/completions`. It needs no API key.

```bash
curl https://api.allternit.com/v1/models
```

### Example response

```json
{
  "object": "list",
  "data": [
    {
      "id": "deepseek-v4.1-flash",
      "object": "model",
      "created": 0,
      "owned_by": "openrouter",
      "provider": "openrouter",
      "upstream_id": "deepseek/deepseek-v4.1-flash",
      "name": "DeepSeek: DeepSeek V4.1 Flash",
      "context_length": 1048576,
      "lane": "standard",
      "prompt_price": 0.00000021,
      "completion_price": 0.00000063
    }
  ]
}
```

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | The model name to send as `model`. |
| `provider` | string | The upstream host that serves it. |
| `upstream_id` | string | The host's own id for the model. |
| `name` | string | Human-readable name. |
| `context_length` | integer | Context window in tokens. |
| `lane` | string | `standard`, or `open` for open-lane models (see below). |
| `prompt_price` | number | USD per input token. This is the billed price. |
| `completion_price` | number | USD per output token. This is the billed price. |

A model can carry more metadata from its host, such as `description`, `architecture` and `supported_parameters`. To get a price per 1M tokens, multiply `prompt_price` or `completion_price` by 1,000,000. The Cloud API has no `/v1/models/{id}` or `/v1/pricing` route: use this list.

## Local runtime gateway

`GET /v1/models` on the runtime gateway is served by the Fabric model catalog. It requires an active organization (`403 organization_required` otherwise) and lists catalog entries, not policy aliases.

```bash
curl http://127.0.0.1:8013/v1/models \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/models` | List catalog models |
| `GET` | `/v1/models/*id` | Retrieve a single catalog model |
| `GET` | `/v1/pricing` | List per-model pricing |

### Example response

```json
{
  "object": "list",
  "data": [
    {
      "id": "provider/model-id",
      "object": "model",
      "created": 0,
      "owned_by": "provider",
      "display_name": "Model Display Name",
      "context_window": 128000,
      "quality_tier": "standard",
      "pricing": {
        "input_cents_per_1m": 250,
        "output_cents_per_1m": 1000
      }
    }
  ]
}
```

### Model object fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | `provider/model` id. |
| `object` | string | `model`. |
| `created` | integer | Always `0`. |
| `owned_by` | string | Provider kind. |
| `display_name` | string | Human-readable name. |
| `context_window` | integer | Context tokens. |
| `quality_tier` | string | Catalog quality tier. |
| `pricing` | object | `input_cents_per_1m` and `output_cents_per_1m`. |

## Policy aliases

Policy aliases (runtime gateway) are not returned by `/v1/models`. Pass one as the `model` of a chat completion to trigger the gateway's benchmark-weighted router, which picks a concrete provider/model pair and derives a cross-provider fallback chain.

| Alias | Optimization target |
|-------|---------------------|
| `auto` | Same as `allternit-balanced`. |
| `allternit-balanced` | Balanced quality and cost across all benchmarks. |
| `allternit-code` | Coding and software-engineering tasks. |
| `allternit-reasoning` | Reasoning, math, and science tasks. |
| `allternit-knowledge` | Knowledge and recall tasks. |
| `allternit-instruct` | Instruction-following and chat quality. |

## Open lane (Cloud API)

On the hosted Cloud API, every model in `GET /v1/models` carries a `lane` field: `standard`, or `open` for open-weight models with far fewer refusals (`deepseek-v4.1-flash-open`, `glm-5.3-flash-open`). Open models need the acceptable use policy and an 18+ confirmation, and every request passes the hard-line filter. See [Open lane and refusal handoff](/api/open-lane).

## Retrieve a model (runtime gateway)

```bash
curl http://127.0.0.1:8013/v1/models/provider/model-id \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

Returns one model object as above. An unknown id returns `404` with `{ "error": "model_not_found", "message": "..." }`. Aliases are not retrievable here.

## Pricing (runtime gateway)

`GET /v1/pricing` on the runtime gateway returns the current per-model rates in dollars per 1 million tokens.

```bash
curl http://127.0.0.1:8013/v1/pricing \
  -H "Authorization: Bearer $ALLTERNIT_API_KEY"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "provider/model-id",
      "object": "model_pricing",
      "input": 2.50,
      "output": 10.00,
      "cache_read": 1.25,
      "cache_write": 0.00,
      "context_over_200k": null
    }
  ]
}
```

### Pricing fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | `provider/model` id. |
| `object` | string | `model_pricing`. |
| `input` | number | Input-token price per 1M tokens. |
| `output` | number | Output-token price per 1M tokens. |
| `cache_read` | number | Cache-read price per 1M tokens. |
| `cache_write` | number | Cache-write price per 1M tokens. |
| `context_over_200k` | object | Higher rates when input plus cache read exceeds 200k tokens. |

## Error codes

| HTTP status | Code | Meaning |
|-------------|------|---------|
| 401 | `allternit.authentication_failed` | Missing or invalid API key. |
| 404 | `model_not_found` | `GET /v1/models/*id`: model not in the catalog. |
| 400 | `allternit.model_not_found` | Chat completion named an unknown model. |
| 429 | `allternit.rate_limited` | Per-key rate limit exceeded. |
| 429 | `allternit.budget_exceeded` | Monthly key or tenant budget exhausted. |
| 500 | `allternit.internal_error` | Internal gateway error. |
