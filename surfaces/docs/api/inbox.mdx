## Overview

The Inbox API stores per-user notification items. Items are created by agents or platform flows and surfaced to the user with a severity and status. Clients can list items, mark them read, or create new items programmatically.

## Base URL

```text
https://api.allternit.com/api/v1
```

For local development:

```text
http://127.0.0.1:8013/api/v1
```

## Authentication

All requests require a valid bearer token in the `Authorization` header. See [Authentication](/api/authentication) for details.

## Inbox item object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique item identifier. |
| `agent_id` | string \| null | Agent that generated the item. |
| `type` | string | Item type label. |
| `title` | string | Short title. |
| `body` | string \| null | Optional body text. |
| `severity` | string | `info`, `warning`, or `critical`. |
| `status` | string | `unread`, `read`, `dismissed`, etc. |
| `action_url` | string \| null | Optional deep link. |
| `metadata` | object \| null | Optional JSON metadata. |
| `created_at` | string | ISO 8601 creation timestamp. |

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/inbox` | List inbox items with unread count. |
| `PATCH` | `/inbox` | Update an item's status. |
| `POST` | `/inbox` | Create a new inbox item. |

## List inbox items

```bash
curl "https://api.allternit.com/api/v1/inbox?status=unread&type=agent_alert&limit=10" \
  -H "Authorization: Bearer $TOKEN"
```

### Query parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `status` | string | Filter by status. |
| `type` | string | Filter by item type. |
| `limit` | integer | Maximum items to return, default `50`. |

### Response

```json
{
  "items": [
    {
      "id": "inb_01hqx8x7x7x7x7x7x7x7x7x",
      "agent_id": "agent_018f3a7c...",
      "type": "agent_alert",
      "title": "Cowork session completed",
      "body": "The overnight cowork run finished with 3 warnings.",
      "severity": "warning",
      "status": "unread",
      "action_url": "/cowork/exec_01hqx8x7x7x7x7x7x7x7x7x",
      "metadata": {"run_id": "exec_01hqx8x7x7x7x7x7x7x7x7x"},
      "created_at": "2026-08-13T18:00:00Z"
    }
  ],
  "unreadCount": 1
}
```

## Update inbox item

```bash
curl -X PATCH https://api.allternit.com/api/v1/inbox \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "item_id": "inb_01hqx8x7x7x7x7x7x7x7x7x",
    "status": "read"
  }'
```

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `item_id` | string | yes | Inbox item identifier. |
| `status` | string | yes | New status value. |

### Response

```json
{
  "success": true
}
```

## Create inbox item

```bash
curl -X POST https://api.allternit.com/api/v1/inbox \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "agent_018f3a7c...",
    "type": "agent_alert",
    "title": "Deployment succeeded",
    "body": "BYOC runtime rolled out version 1.2.0.",
    "severity": "info",
    "action_url": "/byoc/runtimes/runtime_01hqx8x7x7x7x7x7x7x7x7x",
    "metadata": {"version": "1.2.0"}
  }'
```

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | string | yes | Item type. |
| `title` | string | yes | Item title. |
| `agent_id` | string | no | Source agent id. |
| `body` | string | no | Body text. |
| `severity` | string | no | `info`, `warning`, `critical`; default `info`. |
| `action_url` | string | no | Optional deep link. |
| `metadata` | object | no | Optional JSON metadata. |

### Response

```json
{
  "success": true,
  "id": "inb_02hqx8x7x7x7x7x7x7x7x7x"
}
```

## Error codes

| Status | Code | Description |
|--------|------|-------------|
| `401` | `Unauthorized` | Missing or invalid bearer token. |
| `403` | `Access denied` | Item belongs to another user. |
| `500` | `DB error` | Database or server error. |
