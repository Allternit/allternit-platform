---
title: 'Teleport'
description: 'Move a live Code session between your Mac and your cloud computer without losing the conversation.'
---

**Teleport** moves a running Claude or Codex coding session from one computer to another. The whole conversation comes with it, so the session picks up where it stopped. Use it to hand a long task to your always-on cloud computer before you close the laptop, or to bring a session back to your Mac to look at it.

## What moves

- **The conversation.** The session's own file, byte for byte. Allternit checks its checksum on arrival.
- **The model and effort.** The session keeps the model and reasoning effort it was using.
- **The code, through git.** Teleport does not copy your working folder. The cloud computer clones the repo at the commit your Mac was on, and when you bring the session back, Allternit applies the changes made in the cloud as a patch.

Commit and push your work first. Teleport to the cloud stops with a clear message if the working tree has uncommitted changes.

## Teleport from the app

In a Code session, open the session menu (the title at the top, or the three dots on a phone or in a session row) and choose **Teleport to cloud**. The header badge changes from **Local** to **Cloud** once the session is running there. Choose **Bring back to this Mac** to return it.

On the phone and the m.allternit.com app the same action is in the session menu, and sessions running in the cloud show a **Cloud** badge. On iPhone, open the session overview, tap the three dots on a Code session, and choose Teleport to cloud.

Teleport needs a Mac running Allternit Desktop (or a phone paired to one) and a connected cloud computer. On plain web with no Mac behind it, the action is hidden.

## Teleport from the terminal

```bash
gizzi teleport <session> --to cloud
gizzi teleport <session> --to local --base <commit>
```

`<session>` is the gizzi session id or the Claude or Codex session id. Add `--harness codex` for a Codex session, `--target` when you have more than one computer connected, and `--model` when the session has no model recorded. When bringing a session back, `--base` is the commit the session left your Mac on, so the cloud changes can be applied as a patch.

The command prints how to resume natively, for example `claude --resume <id>`.

## Safety rules

- Retrying the same move is safe. The same request gives the same result, and a changed conversation is a new transfer.
- A session that already lives on the destination is refused, so two computers never both own it.
- Bringing a session back never overwrites a Mac copy that changed after it left. It stops and suggests a fork.
- Only Claude and Codex sessions can teleport today.

For the HTTP contract, see the Teleports API page.
