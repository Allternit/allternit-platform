## Overview

The LLM Gateway Admin API provides observability and policy controls for organization owners and admins. It covers usage aggregation, request logs, routing decisions, DLP rules, budgets, and inference hooks. All admin routes require a Clerk JWT and organization owner or admin role.

## Base URL

```
https://api.allternit.com/api/v1/gateway
```

For local development:

```
http://127.0.0.1:8013/api/v1/gateway
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/gateway/usage` | Usage aggregation by day, provider, model, and key |
| `GET` | `/api/v1/gateway/logs` | Request logs with filtering and cursor pagination |
| `GET` | `/api/v1/gateway/routing/decisions` | Routing decisions for policy-alias requests |
| `GET` / `PUT` | `/api/v1/gateway/routing/policies` | List or update routing policies |
| `GET` / `PUT` | `/api/v1/gateway/dlp/rules` | List or update DLP rules |
| `GET` / `PUT` | `/api/v1/gateway/budgets` | List or update budgets |
| `GET` / `PUT` / `POST` / `DELETE` | `/api/v1/gateway/inference-hooks` | Manage inference hooks |
| `POST` / `GET` / `PATCH` / `DELETE` | `/api/v1/gateway/keys` | Manage virtual keys |

Virtual-key management is documented on the [Authentication](/api/authentication) page.

## Authentication

```bash
curl https://api.allternit.com/api/v1/gateway/usage \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

## Usage

### Query parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `from` | string | Start date in `YYYY-MM-DD` format. |
| `to` | string | End date in `YYYY-MM-DD` format. |

### Example request

```bash
curl "https://api.allternit.com/api/v1/gateway/usage?from=2026-08-01&to=2026-08-13" \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

## Logs

### Query parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `limit` | integer | Page size. `1`–`200`. Defaults to `50`. |
| `cursor` | string | Pagination cursor in the form `created_at|id`. |
| `status` | string | Filter by request status. |

### Example request

```bash
curl "https://api.allternit.com/api/v1/gateway/logs?limit=10&status=completed" \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

## Routing policies

### List policies

```bash
curl https://api.allternit.com/api/v1/gateway/routing/policies \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

```json
{
  "policies": [
    {
      "name": "allternit-balanced",
      "weights": {
        "humaneval": 0.20,
        "mmlu": 0.20,
        "gpqa": 0.15,
        "gsm8k": 0.15,
        "arena_elo": 0.15,
        "aider": 0.15
      },
      "source": "preset"
    }
  ]
}
```

### Update a policy

```bash
curl -X PUT https://api.allternit.com/api/v1/gateway/routing/policies \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "custom-code-policy",
    "weights": {
      "humaneval": 0.50,
      "mmlu": 0.10,
      "aider": 0.40
    }
  }'
```

## Budgets

### List budgets

```bash
curl https://api.allternit.com/api/v1/gateway/budgets \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

```json
{
  "budgets": [
    {
      "id": "budget_abc123",
      "scope": "organization",
      "budget_cents": 100000,
      "hard": true,
      "current_month_spend_microdollars": 45230000
    }
  ],
  "tenant_id": "tenant_abc123",
  "current_month_spend_microdollars": 45230000
}
```

### Update a budget

```bash
curl -X PUT https://api.allternit.com/api/v1/gateway/budgets \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "budget_cents": 150000,
    "hard": true
  }'
```

A `hard` budget blocks requests when exceeded. Soft budgets are used for reporting and alerts.

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/gateway/dlp/rules` | List rules and default action |
| `PUT` | `/api/v1/gateway/dlp/rules` | Create or update a rule |

## Error codes

| HTTP status | Code | Meaning |
|-------------|------|---------|
| 400 | `allternit.invalid_request` | Malformed query parameter or request body. |
| 403 | `allternit.insufficient_role` | Caller is not an owner or admin. |
| 404 | `allternit.not_found` | Rule, budget, or log entry not found. |
| 500 | `allternit.internal_error` | Internal gateway error. |

## Workspace vendor provenance

The workspace's vendor connection gateway is separate from the LLM Gateway Admin routes above. A bot thread shows a **via Vendor** chip with verified identity and connection health. Its popover reports agent, mode, lane, guarantee level, and channel when present. A verified account does not make a `ui_bridge` lane reliable or approve its output.

Gemini and Copilot are new carried vendors using `ui_bridge` with best-effort status; neither has been verified against the live services. Account sign-in and the provider-terms warning are under [Settings → Subscriptions](/surfaces/subscriptions). Thread looks and the opt-in composer flag are described in [Vendor packs](/plugins/guides/vendor-packs).
