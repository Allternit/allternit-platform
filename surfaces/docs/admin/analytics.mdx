# Admin Analytics

<Note>
The `/api/v1/admin/analytics/*` endpoints are served by the Allternit runtime (the Desktop app, or a paired or hosted computer), not by `api.allternit.com`. The `/api/v1/analytics/*` rows below are relayed by `api.allternit.com` to the caller's default runtime node. On Allternit Cloud the console keeps Analytics (Usage, Logs, Caching, Cost) visible and hides only Gizzi Code usage.
</Note>


The Admin Analytics API aggregates `llm_usage_events` and related organization activity into time-series and per-dimension reports. Use these endpoints for budgeting, chargeback, capacity planning, and understanding how agents, plugins, skills, and connectors are used across your organization.

All analytics endpoints are organization-scoped and require the caller to be an organization owner or admin.

## Base URL

```text
http://127.0.0.1:8013/api/v1/admin/analytics
```

For a paired or hosted computer, use that runtime's own base URL. For local development with the Desktop app:

```text
http://127.0.0.1:8013/api/v1/admin/analytics
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/v1/analytics/csp-violation` | Stub endpoint for reporting CSP violations |
| `POST` | `/api/v1/analytics/gizzi-code/events` | Ingest Gizzi Code CLI usage events |
| `GET` | `/api/v1/admin/analytics/cost-over-time` | Cost trends over time |
| `GET` | `/api/v1/admin/analytics/token-usage` | Token usage over time |
| `GET` | `/api/v1/admin/analytics/request-volume` | Request volume with status breakdown |
| `GET` | `/api/v1/admin/analytics/per-user-cost` | Cost per user |
| `GET` | `/api/v1/admin/analytics/active-users` | Active user counts |
| `GET` | `/api/v1/admin/analytics/artifact-activity` | Artifact, revision, and section creation |
| `GET` | `/api/v1/admin/analytics/chat-project-usage` | Co-worker project and session activity |
| `GET` | `/api/v1/admin/analytics/connector-usage` | Connector connection counts and statuses |
| `GET` | `/api/v1/admin/analytics/plugin-usage` | Plugin invocation counts |
| `GET` | `/api/v1/admin/analytics/skill-usage` | Skill installs and invocations |
| `GET` | `/api/v1/admin/analytics/gizzi-code/usage` | Aggregate Gizzi Code CLI usage |

## Query parameters

Most `GET` endpoints accept:

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `organization_id` | string | Yes | Organization to query |
| `start` | string | Yes | Start of range (ISO 8601) |
| `end` | string | Yes | End of range (ISO 8601) |
| `granularity` | string | No | `hour`, `day` (default), `week`, or `month` |

`per-user-cost` and `connector-usage` do not support `granularity`.

## Cost over time

```bash
curl -G http://127.0.0.1:8013/api/v1/admin/analytics/cost-over-time \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -d "organization_id=org_01hqx8x7x7x7x7x7x7x7x7x" \
  -d "start=2026-08-01" \
  -d "end=2026-08-08" \
  -d "granularity=day"
```

### Response

```json
{
  "items": [
    {
      "bucket": "2026-08-01",
      "cost_microdollars": 300000,
      "requests": 42
    },
    {
      "bucket": "2026-08-02",
      "cost_microdollars": 200000,
      "requests": 31
    }
  ]
}
```

## Gizzi Code CLI analytics

The Gizzi Code CLI can report usage events to the analytics pipeline.

### Ingest events

```bash
curl -X POST https://api.allternit.com/api/v1/analytics/gizzi-code/events \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "events": [
      {
        "session_id": "sess_01hqx8x7x7x7x7x7x7x7x7x",
        "event_type": "turn",
        "model": "allternit-balanced",
        "provider": "allternit",
        "prompt_tokens": 100,
        "completion_tokens": 50,
        "cost_microdollars": 5000,
        "tool_calls_accepted": 1,
        "tool_calls_rejected": 0,
        "created_at": "2026-08-01T10:00:00Z"
      }
    ]
  }'
```

### Response

```json
{
  "status": "ok"
}
```

```bash
curl -G http://127.0.0.1:8013/api/v1/admin/analytics/gizzi-code/usage \

  -d "organization_id=org_01hqx8x7x7x7x7x7x7x7x7x" \
```

## Error codes

| Status | Code | Description |
|--------|------|-------------|
| `400` | `invalid_range` | `start` must be before `end`. |
| `403` | `organization_required` | Caller is not associated with an organization. |
| `403` | `insufficient_role` | Caller is not an organization owner or admin. |
| `403` | `organization_mismatch` | Requested organization does not match the active organization. |
| `500` | `internal_error` | Database or server error. |
