# Access Tokens

Access tokens are organization-scoped bearer tokens for CLI-style and headless surfaces. Each token has a memorable name, optional scopes, an optional expiration, and an audit trail of last use.

Tokens are stored as SHA-256 hashes. The plain token is returned only on creation and rotation.

## Base URL

```text
/api/v1/admin/access-tokens
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/v1/admin/access-tokens` | Create an access token |
| `GET` | `/api/v1/admin/access-tokens` | List access tokens |
| `GET` | `/api/v1/admin/access-tokens/:id` | Get an access token |
| `POST` | `/api/v1/admin/access-tokens/:id/revoke` | Revoke an access token |
| `POST` | `/api/v1/admin/access-tokens/:id/rotate` | Rotate an access token |

## Scopes

Scopes restrict what the token can do. Common values include:

- `admin` or `owner` — full organization admin access
- `cli:read`
- `cli:write`

## Create an access token

```bash
curl -X POST http://127.0.0.1:8013/api/v1/admin/access-tokens \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Local CLI",
    "scopes": "cli:read,cli:write",
    "expires_at": "2026-12-31T23:59:59Z"
  }'
```

### Request body

```json
{
  "name": "Local CLI",
  "scopes": "cli:read,cli:write",
  "expires_at": "2026-12-31T23:59:59Z"
}
```

### Response

```json
{
  "id": "at_01hqx8x7x7x7x7x7x7x7x7x",
  "org_id": "org_01hqx8x7x7x7x7x7x7x7x7x",
  "name": "Local CLI",
  "token": "at-abc12345-xyz67890-qwerty1234567890",
  "token_prefix": "at-abc12",
  "scopes": ["cli:read", "cli:write"],
  "expires_at": "2026-12-31T23:59:59Z",
  "created_at": "2026-08-13T18:00:00Z"
}
```

<Warning>
  Save the `token` immediately. It cannot be retrieved later.
</Warning>

## Revoke an access token

```bash
curl -X POST http://127.0.0.1:8013/api/v1/admin/access-tokens/at_01hqx8x7x7x7x7x7x7x7x7x/revoke \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

### Response

```json
{
  "status": "revoked",
  "revoked_at": "2026-08-13T18:35:00Z"
}
```

Revoked tokens can no longer authenticate.

## Rotate an access token

```bash
curl -X POST http://127.0.0.1:8013/api/v1/admin/access-tokens/at_01hqx8x7x7x7x7x7x7x7x7x/rotate \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

### Response

```json
{
  "token": "at-new12345-xyz67890-qwerty1234567890",
  "token_prefix": "at-new12",
  "record": {
    "id": "at_01hqx8x7x7x7x7x7x7x7x7x",
    "org_id": "org_01hqx8x7x7x7x7x7x7x7x7x",
    "name": "Local CLI",
    "token_prefix": "at-new12",
    "scopes": ["cli:read", "cli:write"],
    "expires_at": "2026-12-31T23:59:59Z",
    "created_at": "2026-08-13T18:35:00Z",
    "last_used_at": null,
    "revoked_at": null
  }
}
```

Rotation issues a new token, updates the prefix, and clears any previous revocation.

## Authenticate with an access token

```bash
curl -X GET http://127.0.0.1:8013/api/v1/admin/workspaces \
  -H "Authorization: Bearer at-abc12345-xyz67890-qwerty1234567890"
```

The token is authenticated by hashing the bearer value and matching it against stored hashes. On success, `last_used_at` is updated.

## Error codes

| Status | Code | Description |
|--------|------|-------------|
| `400` | `invalid_name` | Name must be 1–128 characters. |
| `401` | `invalid_token` | Token is revoked, expired, or does not exist. |
| `403` | `organization_required` | Caller is not associated with an organization. |
| `403` | `insufficient_role` | Caller is not an organization owner or admin. |
| `404` | `token_not_found` | Access token does not exist. |
