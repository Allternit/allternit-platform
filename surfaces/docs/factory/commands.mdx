<Note>
Shipping with the Allternit Factory build. These commands are the approved design. A command that's specified but not built yet exits `2` with the fact `"<part> <verb> is not built yet"`. It never pretends.
</Note>

You type `gizzi <part> <verb> …`. Gizzi runs the engine (`allternit-factory <part> <verb> … --json`) and renders the result. The **OpenRig** column shows the equivalent OpenRig command, for anyone coming from it.

## Rules for every command

- **`--json`** works on every command, read or write. With `--json`, stdout is exactly one JSON document and nothing else.
- **`--dry-run`** works on every mutation. It prints exactly what would change, and the real run does exactly that.
- **Idempotent.** Running a create twice with the same key doesn't make two things.
- **Errors** with `--json` print `{"error":{"code":"…","fact":"…","action":"…"}}`: what happened, and what to do about it.

### Exit codes

| Code | `error.code` | Meaning |
|---|---|---|
| `0` | — | OK |
| `1` | `refused` | Refused by the Gate (policy, lease, kill switch) |
| `2` | `not_found` | Not found (or not built yet) |
| `3` | `transport` | Transport broken, or the engine is missing |
| `4` | `timeout` | Timed out |
| `5` | `needs_person` | Needs a person (an approval, a gate, a `needs_human` verdict) |
| `64` | `usage` | Usage error (bad flags or arguments) |

If Gizzi can't find the engine, it exits `3` and tells you how to install it. It looks next to the `gizzi` executable, then `$ALLTERNIT_FACTORY_BIN`, then `~/.allternit/bin/allternit-factory`, then `PATH`.

## `gizzi agents`

The crew. See [Agents](/factory/agents).

| Command | OpenRig | What it does |
|---|---|---|
| `gizzi agents up [<team>] [--preset P] [--on <computer>] [--dry-run]` | `rig up` | Boot a team from `team.yaml`: spawn Terminal panes, bind Hosted and Vendor bots |
| `gizzi agents ps` | `rig ps` | Every bot with binding, state, node and proof, reconciled against live panes |
| `gizzi agents down <team\|bot> [--rm-worktree]` | `rig down` | Stop a team's panes, or one bot's pane (`--rm-worktree` also lands the bot's [tree](/factory/trees), or pauses it when it holds unmerged or uncommitted work) |
| `gizzi agents whoami` | `rig whoami` | Which bot and team this session is |
| `gizzi agents recover [<bot>] [--apply] [--lead <id>\|--as-human]` | `rig seat handover`, `rig restore` | Show (or, with `--apply`, do) what to restart after a crash: dead, unfinished sessions you own, relaunched with the harness's own resume when it recorded a session |
| `gizzi agents snapshot` / `restore` | `rig snapshot` / `restore` | Save or restore a whole team |
| `gizzi agents model <bot@team> <model>\|--clear [--restart]` | `rig seat set-model` | Change a Terminal bot's model (next start, or `--restart` now) |
| `gizzi agents handoff <bot@team> [--note]` | `rig seat handover` | Hand a Terminal bot's seat to a fresh session, with a handoff note |
| `gizzi agents harness list\|sync` | (runtimes) | List or rescan the agent CLIs on a machine |
| `gizzi agents pack` / `install <path\|github-url>` | `rig bundle create` / `install` | Package a team, or install one |
| `gizzi agents templates` | (agent specs) | Browse bot templates (served by Gizzi) |
| `gizzi agents wall [<team>]` | `rig tui` terminals view | Open the live wall of panes, or one team's |
| `gizzi agents attach <bot@team>` | drop into a terminal | Open one bot: its pane, its session or its thread |
| `gizzi agents doctor` | `rig doctor`, `rig health` | Check harnesses, panes and transport |

### `gizzi agents tree`

One leased worktree per agent. See [Agent Trees](/factory/trees).

| Command | OpenRig | What it does |
|---|---|---|
| `gizzi agents tree new <branch> [--path] [--owner] [--once] [--source-only] [--plain] [--force-disk] [--offline]` | — | Make or reuse a tree: fresh `origin/main`, free-disk gate, lease, warm-base seed, its own env |
| `gizzi agents tree list [--all] [--size] [--path P]` | — | Every tree: owner, state, behind main, processes, checkpoints, overlaps, machine warnings |
| `gizzi agents tree env [tree]` | — | Print the tree's env: `eval "$(gizzi agents tree env)"` |
| `gizzi agents tree sync [tree]` | — | Forward-only update to `origin/main` (clean trees already in main's past) |
| `gizzi agents tree checkpoint [tree]` / `checkpoints [tree]` | — | Save a checkpoint now, or list them newest first |
| `gizzi agents tree rewind <n> [tree] [--as-owner]` | — | Put the files back to checkpoint `n` (the current state is saved first) |
| `gizzi agents tree pause\|resume [tree] [--as-owner]` | — | Keep a tree for later (pushes branch and checkpoints; never reaped), or make it active again |
| `gizzi agents tree done [tree] [--abandon] [--as-owner]` | — | Land it: merge check, stop its processes, delete build output, branch and checkpoints, remove it, run the discipline check |
| `gizzi agents tree reap [--apply] [--size]` | — | The merged + idle + clean rule over every worktree (a dry run without `--apply`) |
| `gizzi agents tree overlap` | — | Files changed in more than one live tree |
| `gizzi agents tree base status\|refresh [--build]` | — | The warm base trees are cloned from |
| `gizzi agents tree reaper install [--hours N]\|uninstall` | — | Schedule `reap --apply` (launchd or a systemd user timer) |

| `gizzi orchestration send <bot@team> "…" [--queue]` | `rig send` | Send to a bot. Reports the delivery state. Recorded in mail |
| `gizzi orchestration capture <bot@team> [lines]` | `rig capture` | Read a pane's last lines |
| `gizzi orchestration transcript <bot@team> [--tail N]` | `rig transcript` | The recorded transcript |
| `gizzi orchestration drain <bot@team> [--all] [--dry-run]` | — | Deliver the bot's queued messages, oldest first. Each is marked delivered only after its paste is verified |
| `gizzi orchestration threads list\|show\|new\|steer\|resolve` | `rig chatroom` | Bot threads (`standing` / `task`) on your account |
| `gizzi orchestration mail list\|read\|send\|decide` | — | Durable mail and review decisions |
| `gizzi orchestration feed` | `rig stream` | Ledger events as they happen |
| `gizzi orchestration attention list\|ack` | needs-you | What's waiting on a person |
| `gizzi orchestration steer checkpoint\|consult` | — | Steering checkpoints and consults |
| `gizzi orchestration coordinate <project> "…"` | orchestrator seat | Hand a request to the Coordinator |

## `gizzi workflows`

Repeatable plans. See [Workflows](/factory/workflows).

| Command | OpenRig | What it does |
|---|---|---|
| `gizzi workflows run <template> [--param k=v]` | `rig workflow instantiate` + `run` | Make nodes from a Template, then drive |
| `gizzi workflows drive <dag> [--once] [--dry-run]` | `rig workflow watch` | Pick up READY nodes, in the foreground |
| `gizzi workflows template list\|show\|check\|save` | `rig workflow validate` / `show` | Manage and validate Templates; `save --from-run <dag>` saves a run as one |
| `gizzi workflows wake list\|due\|run` | `rig watchdog` | Scheduled checks |
| `gizzi workflows gate add\|resolve\|list` | human gate | Wait-gates |
| `gizzi workflows status <run>` | `rig workflow status` | Render a run's DAG and status |

## `gizzi workspace`

The work and its proof. See [Workspace](/factory/workspace).

| Command | OpenRig | What it does |
|---|---|---|
| `gizzi workspace campaign new\|list\|status\|pause\|finish` | `rig scope mission` | Campaigns |
| `gizzi workspace plan new\|refine` | — | Create or change a plan |
| `gizzi workspace node add --dag --parent --title` | `rig queue create`, `rig scope slice create` | Add a node and its folder |
| `gizzi workspace node list [--dag] [--ready\|--mine]` | `rig queue list --owned`, `rig scope slice ls` | List open nodes (ready, claimed, waiting) |
| `gizzi workspace node claim\|handoff\|close` | `rig queue claim` / `handoff` | Pick up, hand off or close a node |
| `gizzi workspace approve <node>` | `rig queue resolve` | Approve a node at its gate |
| `gizzi workspace proof add\|show` | `rig proof add` / `show` | Add or show evidence |
| `gizzi workspace judge show\|resolve` | `rig proof judge` | Verdicts per contract line |
| `gizzi workspace board [<campaign>]` | the project board | The Board |
| `gizzi workspace tasks board\|tasks\|queue` | — | Your Tasks board, task list and work queue (cowork tasks are nodes in your Tasks DAG) |

## Top level

| Command | What it does |
|---|---|
| `gizzi` | The TUI: one agent plus the factory floor (agents, board, approvals) |
| `gizzi doctor` | Checks Gizzi, the engine, harnesses, transport and the install, including the one-time move of the old orchestrator's state folder to `~/.allternit/factory/` ([details](/factory/migration#on-disk-state)) |
| `gizzi serve` | Unchanged: Gizzi's own harness server. The Factory API is the engine's, at `/api/factory` |
