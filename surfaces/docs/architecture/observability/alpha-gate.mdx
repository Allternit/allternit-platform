The alpha gate is the list of things that must be demonstrably true before the Agency API leaves preview.

## Architecture contract

Intended criteria: a real bug-to-patch-to-failed-test-to-repair-to-verified workflow runs with no monolithic model loop; every decision can be replayed from state and versioned artifacts; a backend can be swapped without graph edits; restart reconstructs a run from state and receipts; an unauthorized write is blocked; a run receipt proves completion; provenance and cost telemetry exist on every transition; and the system shows measured lift over the same backbone run naked.

## Current implementation

The gate is a design target. It has not been run and the Agency API is not live.
