System lift is the claim the architecture has to earn: the same backbone, run inside the kernel, does measurably better than the same backbone run naked.

## Architecture contract

A lift measurement runs an identical task set with and without the kernel's graphs, verification and recovery, and reports the difference in verified completion, cost and latency. It needs recorded runs and a fixed evaluation set. A small model showing lift over itself is the intended first milestone.

## Current implementation

Not on main. No lift result is published, and this page makes no performance claim.
