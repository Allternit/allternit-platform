# Release Notes

## 2026-10-24 — Continue a CLI session from your phone

The same change applies on ai.allternit.com's phone layout and in the m.allternit.com app. Desktop already had it.

- **Phone:** press and hold **New chat** (or **New thread** in Code) and tap **Continue CLI session** to pick up a Claude Code, Codex, Grok or other CLI session from your computer. It opens as a chat on the phone. Before, the picker was only on the desktop layout. See [Native Sessions](/cli/native-sessions).

## 2026-10-23 — Project panels from files

The same change applies on Desktop, on ai.allternit.com (including the phone layout) and in the m.allternit.com app, wherever Code talks to Gizzi Code on your computer.

- **Code mode:** a project can keep panels as JSON files in `.allternit/panels/`. Each one is an ops sheet with live feeds or one of your MCP Apps, and opens from **Panes → Panels** beside the chat or as a strip above the message box. A panel's rules for the agent (instructions and guards that ask before a command) apply only after you approve them, and an edited file asks again. See [Project panels](/guides/project-panels).

## 2026-10-23 — Graph and Calendar on every Automation Tasks tab

The same change applies on Desktop, on ai.allternit.com (including the phone layout) and in the m.allternit.com app.

- **Automation Tasks:** **Goals**, **Loops** and **Agent Heartbeats** now have the **List / Graph / Calendar** switch that Routines has, and **All** shows every kind on one graph and one calendar. Goals appear on their target date, loops and heartbeats at their run times, and the graph connects each task to its bot and the goal it serves. See [Goals, loops and heartbeats](/guides/bot-routines#goals-loops-and-heartbeats).

## 2026-10-23 — Phone Link stops jumping to the Home Screen

- **Phone Link (iPhone):** Desktop no longer restarts the iPhone helper after one slow answer. A restart sends the iPhone to its Home Screen, so a bot working on the phone lost its place. Desktop now restarts the helper only after it misses two checks in a row. See [Phone Link](/guides/phone-link).

## 2026-10-23 — One default computer on every device

The same change applies on Desktop, on ai.allternit.com (including the phone layout) and in the m.allternit.com app.

- **Default computer:** pick a computer once and your phone, the web app and your bots all use it. Before, each device kept the last computer it used, so your phone could stay on a laptop after you picked your cloud computer. Tap **Make default** in **Settings → Account → Runtimes**. If the default stops answering, the app uses another computer until it's back, then returns to it. See [Choose your default computer](/guides/computers-and-apps#choose-your-default-computer).

## 2026-10-23 — Gizzi Code knows your repo

- **Repo map:** every Code turn now starts with a ranked map of your repo: files, what they export, and how many files import each. Files you just changed rank higher. It updates as files change. See [Code intelligence](/cli/code-intelligence).
- **Rename across files:** the agent renames through your language server, so every caller changes together, with one permission prompt and normal undo.
- **Edit by name:** a new `symbol_edit` tool replaces a whole function or class by name.
- **Review with a verdict:** `/review` asks a fresh reviewer to check your changes and answers PASS, FAIL (with file and line) or PARTIAL. `/review pass` fixes and re-reviews until it passes, and `gizzi run --review` exits 0, 3 or 4 for CI. Goal rounds now run your checks and a review between rounds. See [Code intelligence](/cli/code-intelligence#review-with-a-verdict).
- **Models for each job:** set a model for explorers, coders, the reviewer, goal escalation and summaries in `models.jobs`. See [Configuration](/cli/configuration#models-for-each-job).
- **In the app (Code mode):** a **Review** button with a verdict card under the latest reply, a **Models for each job** sheet from the model pill, each Code session's model, files edited and cost in the sidebar, a warning when two sessions edit the same file, and a live **Code map** pane in Desktop that opens on the file the agent is working on: what it uses, what uses it and what a change could break, with **Whole repo** for every file at once. See [Code intelligence](/cli/code-intelligence).
- **Run line:** failed tool calls now show in the run line under the latest reply, and the line stays visible in Code and on touch screens.

## 2026-10-23 — Claude Code runs on cloud computers

- **Cloud computers:** Claude Code now answers on your Allternit cloud computer. Before, every turn failed with "--dangerously-skip-permissions cannot be used with root/sudo privileges", because the cloud computer runs its desktop as root. The fix applies only on cloud computers, not on your own machine.

## 2026-10-23 — Cloud computers show your real email

- **Cloud computers:** Settings → Account on your Allternit cloud computer now shows your account's email address. Before, a cloud computer showed a placeholder such as `user_…@users.allternit.local`, so it looked like a different account.
- **Default computer:** when your cloud computer pairs again (for example after you sign out on it), it stays your default computer. Before, the default stayed on the old pairing, so your phone could go to a laptop instead.

## 2026-10-23 — Cloud computers pair past the machine limit

- **Cloud computers:** your Allternit cloud computer now pairs even when your own computers already use every machine slot on your plan. Before, Plus, Super and Ultra allowed one machine, so a cloud computer could fail to pair with "Active machine limit reached" if your Mac was already paired. See [Hosted runtime](/byoc/hosted-runtime).

## 2026-10-23 — Group chats as cards

The same change applies on Desktop, on ai.allternit.com (including the phone layout) and in the m.allternit.com app.

- **Group chats** open on the same cards as chats and a bot's threads, in a grid or a deck. Each card shows the room's members, its latest messages with who said them, **Needs you** when a bot asked you something, and how many messages are new. **List** keeps the earlier rows. See [All chats at a glance](/guides/session-overview).

## 2026-10-22 — All chats at a glance

The same changes apply on Desktop, on ai.allternit.com (including the phone layout) and in the m.allternit.com app.

- **Overview:** every open chat, Cowork task, code thread or agent run as live cards, in a grid or a deck. Each card shows the latest reply and whether the session is working or needs you. Filter by project from the line under the title. The **×** archives a session; on phones you can swipe a card up. See [All chats at a glance](/guides/session-overview).
- **Where:** **Open all recents** on Desktop now opens on the cards, with **List** for the previous page. On phones, tap the count button in the chat or Code header, or **See all** beside Recents.
- **Bots:** a bot's **Threads** tab shows its threads as the same cards, with **Take it** and **Not now** on suggestions. The **Tasks** tab is now dropdowns: thread, then steps, then the subagents each step handed work to. See [The deck above the composer](/guides/bot-threads#the-deck-above-the-composer).
- **Archived chats** leave Recents on phones and show under the Archived filter on Desktop, like Cowork and Code sessions.

## 2026-10-21 — API keys in Cloud Console

- **Desktop and ai.allternit.com:** Cloud Console has an **API Keys** tab. You can make, copy and revoke your Allternit API keys there. Before, only the phone ACI screen had this list. See [Make an Allternit API key in the app](/api/authentication#make-an-allternit-api-key-in-the-app).

## 2026-10-21 — Your bots come alive

The same changes apply on Desktop, on ai.allternit.com (including the phone layout) and in the m.allternit.com app.

- **Bot stage:** when you pick a bot, it stands on a dark stage above the greeting, with a glow in its color. Its own avatar breathes, glances around and leans toward your pointer. Click it to start voice. A bot's empty chat shows the same stage. See [Your bot's stage](/guides/bot-avatars#your-bots-stage).
- **Voice:** the bot's avatar swells with your voice while it listens and with its own voice while it speaks. Cast characters move their mouths. The voice bar shows the bot's avatar instead of the Allternit mark. See [Talk to your bots](/guides/voice).
- **Calls:** a bot's phone calls show its own avatar on the call screen and the live call card.
- **Needs you:** a bot that is waiting on your answer now nudges side to side. Before, it showed its speaking art.
- **Fix:** a look you pick for the A:// main bot now shows on the launch screen too.

## 2026-10-21 — New controls across the workspace

The same changes apply on Desktop, on ai.allternit.com (including the phone layout) and in the m.allternit.com app.

- **Saving:** save buttons keep their size while they work, then show **Saved**.
- **Destructive actions:** deleting a bot, unpairing a computer and revoking a key now use press-and-hold. Disconnect and revoke buttons ask for confirmation in place, without a pop-up. Disconnecting a connector offers **Undo**.
- **Copy buttons:** copy buttons on code blocks, terminal output, share links, invite links and webhook URLs confirm in place.
- **Form fields:** pickers for models, timezones, tools and connector actions can be searched. Number fields have steppers, and times use a time picker. Settings toggles and tabs slide between options.
- **Panels:**
  - Side drawers and phone sheets can be dragged closed.
  - Toasts stack, and you can swipe them away.
  - Phone lists show **Delete** when you swipe a row.
  - Wizards show their steps.
  - Long lists have pages.
  - File trees open a file with one click.
- **Usage:** plan and voice limits show as usage meters. Tool-call inputs and outputs open as a JSON tree you can fold.
- **Keyboard shortcuts:** you can now change the workspace shortcuts in **Settings → About → Keyboard shortcuts**. See [Desktop](/surfaces/desktop#workspace-shortcuts).
- **Accessibility fix:** screen readers no longer announce text fields as "Input" or "Text Area".

## 2026-10-20 — App steps and source chips in replies

- Steps that reach your connected apps now show the app's logo and name ("Searched **Slack** for messages since yesterday") and, when they finish, the first three things they found: messages, emails, pull requests, issues or notes, with "+N more". While the assistant works, the newest step's finds stay open. When the reply is done, the steps fold into a summary such as "Ran 2 searches, read 3 sources", followed by the logos of the apps used. See [Agent steps in replies](/guides/agent-steps).
- Links in an answer that point into one of your apps (Slack, GitHub, Linear, Gmail, Notion, Google Drive and others) show as small source chips with the app's logo.

## 2026-10-20 — Meet your bots, editable routines calendar

- **Meet your bots** replaces setup's Main bot step and opens once on your first visit to Bot Mode. Watch the Bots network, add bots from the templates by dragging them onto your team or tapping them, pick your main bot (A:// by default, Gizzi, the Gizzi YouTube cast or a vendor bot you already use), see and change your team's routines, and give them a first job. Nothing is created until **Start the job**, and the last page reports each part honestly with **Retry what didn't finish**. **Replay intro** in the Bots rail **⋯** menu shows it again. See [Meet your bots](/guides/meet-your-bots).
- **Routines → Calendar** is now editable on every routines screen (a bot's Routines tab, Automation Tasks, Cowork → Routines and a bot chat's Routines panel) and opens on **Day**: click an empty time to add a routine, click one to change who runs it, what it does and when, and drag it to move it. Routines that run every few hours draw as one band. See [Bot routines](/guides/bot-routines#edit-routines-on-the-calendar).
- Built-in templates now each have a default character, and the bot setup picker shows every character whole, with Gizzi's eyes following your pointer and a tap to make it jump.
- The **List / Graph / Calendar** switch from a bot's Routines tab is now also on **Automation Tasks** (All and Routines tabs, including the phone screen), **Cowork → Routines** and a bot chat's **Routines** panel. These screens show every bot's routines on the graph and calendar, and the switch remembers one choice across all of them. See [Bot routines](/guides/bot-routines#list-graph-and-calendar).

## 2026-10-19 — Routine graph and calendar, usage by brain and bot, Bot Mode Marketplace

- A bot's **Routines** tab now switches between **List**, **Graph** and **Calendar**. The graph draws each routine from its trigger to the bot to its last result, with failures in red. The calendar shows upcoming runs by day, week or month, with an Upcoming runs list; **All bots** shows the whole team's schedule with each bot's avatar. Selecting a routine opens its details, a Next 7 days strip and run history with durations. See [Bot routines](/guides/bot-routines#list-graph-and-calendar).
- **Settings → Usage** now splits cost and tokens per brain, draws a daily chart, and can narrow everything to one bot. The breakdown gains **Brain**, **Bot** and **Day**. The usage summary API takes `group_by=bot,day` and `tz_offset_minutes`. See [Usage dashboard](/guides/usage-dashboard) and [Usage API](/api/usage).
- **Bots rail ⋯ → Templates** is now **Marketplace**, with **Agents** (templates), **Apps** (connectors) and **Skills** (one-click install) tabs. See [Marketplace](/guides/bot-templates#marketplace).
- Fix: red error states that used an undefined colour token now show in red, and a connector directory that fails to load offers **Try again** instead of loading forever.

## 2026-10-18 — Delegate tasks to a project's bots

- Every project now has **Delegate**: a to-do list you hand to the project's bots. Add tasks with an optional time estimate, then drag one onto a bot or use **Assign to…**. Each task becomes a project thread for that bot. A bot works its tasks one at a time, and its lane shows what it runs now and what waits. Turn on **Auto** to give tasks to whoever is free first. Each bot shows its average cost per finished task, and "Busy until" is built from your estimates. Both are labelled as estimates. On the phone, Delegate is one column with **Assign to…**. See [Delegate tasks to a project's bots](/guides/project-delegate).

## 2026-10-18 — Neutral dark mode

- Dark mode (and System, when your device is dark) is now neutral graphite instead of warm brown: grey backgrounds, panels and borders, with the same tan accent on buttons and selected items. Desktop, ai.allternit.com, the phone app and Office all use it. Light mode is unchanged.

## 2026-10-16 — Bots on your Home Screen

- Save any bot to your phone's Home Screen as its own icon with the bot's avatar and name. Tapping it opens that bot's chat, full screen. Choose **Add to Home Screen** from the bot's **⋯** menu. On a computer you get a QR code to scan; on a phone you get the steps for your browser. Works on iPhone and Android, no app store. See [Bots on your Home Screen](/guides/bot-home-screen).

## 2026-10-10 — Main bot setup and drag to make main

- Every account now has a main bot. The first bot you create becomes it. Without one, the main bot tile (and Bot Mode, once per session) opens **Set up your main bot**: a short explanation of what the main bot does and what it never does without approval, then **Set up A://** in one click, or pick one of your bots. See [Your main bot](/surfaces/bots#your-main-bot).
- On desktop, drag a bot in the Bots rail onto the main bot tile to make it your main bot, or onto the promoted row to promote it.

## 2026-10-10 — Bot Mode: main bot, bot screen, thread switcher

- The Bots rail is lighter. Your **main bot** sits at the top as a large photo tile. Up to three **promoted** bots sit in a row under it, then Projects, then Bots, with Group chats pinned at the bottom above your account row. See [Bots](/surfaces/bots#the-bots-rail).
- Each bot row shows the last line from its newest thread. The thread dropdown under each bot is gone; a bot's threads live on its bot screen.
- Make any bot your main bot, or promote it, from its **⋯** menu.
- Clicking a bot opens its **bot screen**: a bigger header with its photo and how to reach it, then its **main chat** beside its **threads**. The main chat is always there and knows the status of the bot's threads without taking in their context. Threads idle for 7 days fold into **Stale**. See [Bots](/surfaces/bots#bot-screen).
- Bot **Settings** (formerly Config) starts with **Phone and reach**: the bot's number, texting and voice calls, its phone, email and channels, and who it can contact on its own.
- In a thread, click the thread title to **switch threads**: the main chat, the bot's other threads, and the same project's threads from other bots, with **+ New thread** and **+ Incognito**. See [Switching threads](/guides/bot-threads#switching-threads).
- The bots home shows your bots as a horizontal row (main bot first). Terminal CLI runs (Kimi, Codex, Claude Code) no longer appear there; they stay in Code mode.
- Project pages add **Needs you · N** in the header and a row of the project's bots to start one on a new thread.

## 2026-10-08 — Polished interactive cards

- Cards in replies have a new design: inputs and results in labelled groups, sliders with a filled track, number fields with $ / % and − / + buttons, segmented choices, and up to two actions at the bottom. Numbers animate when you change an input. Light and dark, desktop and phone. See [Interactive answers](/guides/interactive-answers#design).
- Cards now draw in Chat, Cowork, Code and bot threads instead of showing as a code block, and no longer show up under Outputs.
- While a card is being written, one steady placeholder holds its place with the card's title, then the finished card appears in one step. Numbers no longer flash in digit by digit.
- Cards have a controls panel for the numbers you change and lead with the answer in large type.
- Starting a new chat shows your message and **Starting chat…** right away, instead of an empty screen while the chat is set up.

## 2026-10-08 — Interactive answers turned on, with live data

- Assistants now know they can answer with an [interactive card](/guides/interactive-answers) (sliders, metrics, tables, charts, choices) in Chat, Cowork, Code, bot threads, the HUD and Design mode. Plain text stays the default.
- Cards can show live data from your connected apps and refresh it. A card that changes something asks first with an **Allow** bar showing the exact tool and arguments; nothing runs until you approve.
- What you set on a card is remembered when you come back to the chat (on that device).
- Settings → Response style → **Layout and visuals**: choose **Auto** or **Text only**.
- Bot threads and the HUD now render cards instead of showing their code. In Slack, Telegram, email and other channels a card is sent as readable text.
- Design mode's preview shows the reply's card re-skinned with your DESIGN.md. UI Forge is now a working playground for cards.
- Removed: the old `[v:…]` preview syntax (no model was ever told to write it, and the text after a stray `[v:` in a reply disappeared), BlueprintCanvas, and the `render_walkthrough` tool, which reported a render that never happened.

## 2026-10-08 — Attach any file or folder

- Attach any file type in the composer: video, audio, ZIP, and files with any extension, including dotfiles. On Desktop and desktop browsers, attach whole folders from **Add a folder** or by dragging them in. See [Attachments](/guides/attachments).
- Files show the moment you pick them, with **Reading…** while they are read, so a slow PDF or folder is never silent. Videos show a frame and their length.
- Video, audio and other files reach the agent as a link to your Allternit Cloud storage. Sent messages show file chips instead of the extracted text.
- The composer's grey outline is gone. The soft grey band only appears behind a reply strip or attachment cards.

## 2026-10-07 — Composer polish, replies, images and interactive answers

- The chat text box, question cards, working pill and card grids have a new, quieter look across Desktop, ai.allternit.com and the m.allternit.com app. See [Composer, replies and questions](/guides/chat-composer).
- **Reply** to a whole reply, or to text you select in one. The quote travels with your message.
- Agent questions use numbered choices: press **1**–**9** on Desktop. **Skip question** skips only that question. The agent now receives the text of your choice; before, it got an internal id like `0-Framer`.
- Images you attach now reach the model as images. Before, they showed in the text box but weren't sent. Desktop shows attachments as cards with real details (pages, lines, rows and columns); phones show previews. See [Attachments](/guides/attachments).
- While a file is being written, a placeholder shaped like it holds its place.
- Replies can include [interactive answers](/guides/interactive-answers): cards with sliders, metrics and tables that update on your device.
- API: `POST /api/agent-chat` accepts `attachments` like the Desktop `/api/v1/ai/chat` bridge. See [Agent Chat API](/api/agent-chat).

## 2026-10-07 — Bots on your cloud computer

- `gizzi agents up <team> --on "Cloud computer"` runs a team's bots on your Allternit cloud computer, the same way as on a paired Mac or VPS. The cloud computer pairs itself; there is nothing to set up. See [Factory agents](/factory/agents).
- Only the Factory engine's peer port goes on your private mesh, never the cloud computer's screen. The pairing is removed when the cloud computer is deleted. See [Cloud computers as paired computers](/api/cloud-api#cloud-computers-as-paired-computers).

## 2026-10-06 — Memory Drive

- Everything your agents remember is now kept in your **Memory Drive**: a private folder of one-line notes with the conversation each came from and the date, and a full history of changes. Chat, bots, the phone app and Gizzi share it. See [Memory Drive](/guides/memory-drive).
- Settings → Memory → Memory Drive shows the files, history and diffs, lets you edit, and creates read-only or write tokens so other agents (Claude Code, Codex) can clone it.
- A nightly **Dream** merges duplicates, fixes contradictions a conversation proves wrong, adds lessons and removes long-unused memories, as one change with a report and an undo. It runs at night in your time zone.
- Move memories you already had with **Import existing memory** (your Needs you inbox reminds you), or bring them from **ChatGPT or Claude** by pasting or uploading their memory list.
- **Delete forever** removes chosen memories from the drive and its whole history.
- Teams, projects, bots and swarms get their own drives, with a questions board for people and agents. Gizzi: [`gizzi memory`](/cli/memory).

## 2026-10-06 — Notifications from the event backbone

- One push sink turns event backbone events into notifications: approvals, threads that need you, messages, ended calls, sign-in needed and usage alerts are on by default; finished runs and other informational events are off. Each type has its own switch. See [Notifications](/guides/notifications) and [Notification preferences](/api/notifications).
- Relayed channel messages from a runtime that forwards its events now notify once, with the sender and text, through the sink instead of the direct push.
- Cloud budget alerts now emit `usage.threshold` once per crossing, so push and MCP Events subscribers get them.
- The `allternit-bot` CLI keys list now shows each key's MCP Events subscriptions, and the owner can stop one. See [allternit-bot CLI](/guides/allternit-bot-cli).

## 2026-10-02 — Thread and project pane parity

- Bot threads now use one-row tops with avatar navigation and vendor provenance popovers. Ripped-page context dividers, plan cards, and wavy gap/day rules explain thread history. The pane switches Thread, Browser, and Computer; notifications and bot settings fold into ⋯ when docked. See [Threads](/guides/bot-threads).
- Projects and Bot Mode share one bot project list with pin/archive, server context files, per-device folders, coordinator instructions, and Threads / Library / Routines / Browser panes. Projects-tab workspaces include grouped threads, graphs, receipts, decision cards, wrap-up reports, and Library. See [Projects](/guides/project-coordination).
- Carried vendors and all seven channel providers have thread looks. Allternit remains the default composer; vendor composer skinning is opt-in through an in-memory flag. Packed threads omit the dot-grid backdrop. See [Vendor packs](/plugins/guides/vendor-packs).
- Gemini and Copilot connection entries use best-effort `ui_bridge`. They are new and not yet verified against the live services. Sign in under Settings → Subscriptions and read the terms warning. See [Subscriptions](/surfaces/subscriptions).
- Web phone and PWA layouts keep avatar, provenance, project controls, and pane menus reachable. Panes open full screen with Back; view menus and actions stay above pane content.
