## allternit-api

Verified in `cmd/allternit-api/src/main.rs`:

| Variable | Purpose |
|---|---|
| `ALLTERNIT_API_PORT` | Listen port. Default `18013` (dev); pin `8013` in production. Binds `0.0.0.0`. |
| `ALLTERNIT_DATA_DIR` | Data directory (per-instance SQLite) |
| `ALLTERNIT_ENCRYPTION_KEY` | Key for encrypted local secrets |
| `ALLTERNIT_LOG_FORMAT` | Log format selector |
| `ALLTERNIT_PASSKEY_RP_ID`, `ALLTERNIT_PASSKEY_RP_ORIGIN` | Passkey relying-party settings |
| `ALLTERNIT_MESH_PROVIDER`, `ALLTERNIT_MESH_SERVER_URL`, `ALLTERNIT_MESH_AUTH_KEY`, `ALLTERNIT_MESH_TAGS` | Mesh enrollment |
| `ALLTERNIT_FABRIC_TRANSPORT_LEASE_SECS`, `ALLTERNIT_FABRIC_TRANSPORT_SWEEP_SECS` | CommRails fabric transport timing |

This is the set read directly in `main.rs`; other modules read further variables.

## agent-daemon

| Variable | Default |
|---|---|
| `ALLTERNIT_CLOUD_API_URL` | `https://api.allternit.com` |
| `ALLTERNIT_RUNTIME_NAME` | `<hostname> VPS` |
| `ALLTERNIT_GATEWAY_URL` | `http://127.0.0.1:8013` |
| `ALLTERNIT_RUNTIME_IDENTITY_PATH` | daemon default |
| `ALLTERNIT_PAIRING_MODE` | unset (`hosted_auto` for provisioned instances) |

See [Installation](/byoc/installation).

## How this relates to the Agency Kernel

BYOC is where the Allternit API data plane and Gizzi runtime run on hardware you control. The [Agency Kernel](/architecture) contracts are served through the Cloud API. Nothing on this page changes them.
