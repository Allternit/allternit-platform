## Overview

`allternit-vm-executor` (`services/vm-executor`) is a Rust crate that owns a `DriverRegistry`, tracks active VMs, and exposes a lifecycle API on top of `allternit-driver-interface`. Consumers link it as a library.

## VM statuses

`Creating`, `Running`, `Paused`, `Stopped`, `Failed` (`VmStatus`).

## API (`VmExecutor`)

| Method | Purpose |
|---|---|
| `new(default_driver)`, `with_registry(registry, default_driver)` | Construct |
| `register_driver(driver)` | Add an `ExecutionDriver` |
| `create_vm(spec)`, `start_vm(id)`, `stop_vm(id)`, `pause_vm(id)`, `resume_vm(id)` | Lifecycle |
| `exec(id, cmd)` | Run a command |
| `inspect_vm(id)`, `list_vms()` | Introspection (`VmInfo`, `VmSummary`) |
| `health_check()` | `ExecutorHealth` |

## Errors

`ExecutorError` includes `NoDriver` among its variants; see `services/vm-executor/src/lib.rs` for the full list.
