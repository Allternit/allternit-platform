## Network posture

- `allternit-api` binds `0.0.0.0:$ALLTERNIT_API_PORT`. Block that port at the host firewall; only the local `agent-daemon` needs it.
- The node needs only outbound HTTPS/WSS to `api.allternit.com`. The relay (`/api/v1/runtime-relay/connect/:runtimeId`) carries browser and SDK traffic to the node, so no reverse proxy, TLS certificate or inbound port is required.
- If nothing is paired and online, relayed routes return HTTP 428.

## Health checks

```bash
curl http://127.0.0.1:8013/health
curl http://127.0.0.1:8013/health/live
curl http://127.0.0.1:8013/health/ready
```

## Backups

State lives under `ALLTERNIT_DATA_DIR` (per-instance SQLite). Stop the process, copy the directory, start it again. A device identity file (`ALLTERNIT_RUNTIME_IDENTITY_PATH`) belongs to the paired daemon; losing it means re-pairing.

## Revoking a node

A paired device can be revoked through the Cloud API (`/api/v1/runtime-devices/:id`, `/api/v1/runtime-devices/:id/revoke-self`). See [Cloud API](/api/cloud-api#runtime-pairing).

## Scaling

One paired node is one runtime. Provisioned and hosted instances are managed through the Cloud API (`/api/v1/provisioned-instances`, `/api/v1/hosted-runtimes`). There is no built-in horizontal scaling of a single node.

## How this relates to the Agency Kernel

BYOC is where the Allternit API data plane and Gizzi runtime run on hardware you control. The [Agency Kernel](/architecture) contracts are served through the Cloud API. Nothing on this page changes them.
