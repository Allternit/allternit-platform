# Accessibility Nutrition Labels — Allternit for iPhone

Real-iPhone test checklist for the App Store accessibility declaration (plan step 14). Results are recorded by hand on a real iPhone, not the simulator. Every cell starts empty. Fill each with PASS or FAIL, and note the date, the device and the iOS version at the foot.

Rule: declare a feature only if every task passes. Save the declaration as a draft with only the features that passed.

## What each feature test means

| Feature | Test |
|---|---|
| VoiceOver | Every control has a label, the reading order makes sense, nothing traps focus, and the purchase sheet can be reached and used |
| Voice Control | Every control has a name you can say out loud |
| Larger Text | At the largest accessibility text size, nothing clips or overlaps |
| Dark Interface | The task works and reads clearly in dark mode |
| Differentiate Without Color | Status is never shown by color alone |
| Sufficient Contrast | Text and controls stay readable, also with Increase Contrast on |
| Reduced Motion | No forced animation, including while a reply streams |
