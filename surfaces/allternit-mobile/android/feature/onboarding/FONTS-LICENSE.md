# Bundled fonts

`src/main/res/font/roboto_{regular,semibold,bold}.ttf` are Roboto by Google (Christian Robertson),
static instances downloaded from Google Fonts, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). The sign-in screen uses them so it matches the web sign-in,
which Chrome on Android draws in Roboto.
