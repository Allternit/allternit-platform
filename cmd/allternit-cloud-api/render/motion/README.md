# Motion cloud render

Renders a Motion artifact to an H.264 MP4 on the cloud-api host. The route
that starts and tracks jobs is `src/routes/artifact_render.rs`
(`/api/v2/artifacts/:id/render`); the rules (limits, queue, plans, paths) are in
`src/artifacts/motion_render.rs`.

```
node dist/render.mjs --in composition.json --out out.mp4 [--ffmpeg /usr/bin/ffmpeg]
```

stdout carries `progress <0..1>` lines; errors go to stderr; exit code 0 means
the MP4 was written (yuv420p, faststart, the composition's fps and size,
no audio).

## One renderer

`dist/render.mjs` is the app's own `src/lib/artifacts/motion/render.ts` and
`schema.ts` (from allternit-ai), bundled with `src/runner.mjs`. The runner
draws each frame with `renderFrame(ctx, comp, i / fps)` into an
`@napi-rs/canvas` canvas (prebuilt linux-x64 binary, no system libraries) and
pipes raw RGBA frames to ffmpeg. There is no second implementation of the
drawing code.

**The bundle is vendored (checked in)** and regenerated by a script, not built
in CI, because the renderer source lives in another repository:

```
cd cmd/allternit-cloud-api/render/motion && npm ci      # once: installs esbuild
cd ../../../..
node scripts/build-motion-render.mjs --ai ../allternit-ai   # writes dist/
node scripts/build-motion-render.mjs --ai ../allternit-ai --check   # exits 1 when stale
```

`dist/SOURCE.json` records the allternit-ai commit and the SHA-256 of
`render.ts` and `schema.ts` the bundle was built from. Regenerate and commit
whenever either file changes in allternit-ai (or `src/runner.mjs` changes).

## What differs from the in-tab export

- **Logos:** only `data:image/...` logos are drawn. `https` logo URLs are never
  fetched from the server; the wordmark is drawn instead.
- **Fonts:** a Linux host has none of the preview's system fonts, so the
  bundle ships Inter (sans), Source Serif 4 (stands in for the serif stack's
  Georgia) and JetBrains Mono (stands in for Menlo / ui-monospace) in `fonts/`,
  all SIL Open Font License 1.1 (`fonts/LICENSES.txt`).

## Deploy

`deploy-contabo.sh` packs `dist/`, `fonts/`, `package.json` and
`package-lock.json` (never `node_modules`), copies them to the host and runs
`npm ci --omit=dev --ignore-scripts` into
`/opt/allternit-cloud-api/render/motion` before the binary swap. The service
finds the folder at that path; override with `ALLTERNIT_MOTION_RENDER_DIR`.
Other host settings: `ALLTERNIT_NODE_BIN` (default `/usr/bin/node`),
`ALLTERNIT_FFMPEG_BIN` (default `/usr/bin/ffmpeg`),
`ALLTERNIT_MOTION_RENDER_TMP` (default `<tmp>/allternit-motion-render`).
When any piece is missing, `POST .../render` answers 503 `render_unavailable`.
