Ask the user to sign a PDF. The tool uploads it, files a signature request and returns at once with an id and a link. The user signs on Desktop or their phone in their own time; never wait on it.

Only the user can sign. You can't sign, approve or decline, and never see the signature.

Create: `title`, `document_path` (PDF, up to 20 MB), optional `summary`, `details` (up to 8 label/value rows) and `send_to` (email for the signed copy). Returns `{id, status: "pending", sign_url}`. Give the user the link and carry on.

Check: pass only `id`. Returns the status (pending, signed, declined, cancelled, expired) and, when signed, the signer and time. Check only when the user says they signed or you need the signed file.

Needs ALLTERNIT_API_TOKEN (a signed-in account). If missing, tell the user; don't try another route.
