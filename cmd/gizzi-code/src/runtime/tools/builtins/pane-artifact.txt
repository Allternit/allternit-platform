Work on the artifact open beside the chat in this session's editor pane — a PDF, an Allternit Docs document, Sheets workbook, Slides deck, a page, a video, a Design canvas, a design system, or a Build session's site — through that editor's own tools. Changes land in what the user has open, where they see them, and are saved with it.

Files the user attaches in chat (PDF, Word, Markdown, HTML, video) open in their editor automatically; the message says so in a line like "[Opened in the editor pane: form.pdf → artifact <id> (pdf)…]". Work on them with this tool.

Actions:
- open: open an artifact in the pane (artifact_id = its id) and get what describe returns. Use it for an attached file or when another artifact is showing. You never need to ask the user to open anything.
- describe: how the editor's tools work, every tool with its input schema, and the current content. Call this (or open) once before the first change.
- read: the current content (what the editor feeds its own assistant).
- call: run one editor tool (tool = its name from describe, input = an object matching its schema). Some tools return a picture of the result (e.g. a Build site's rendered preview); look at it and fix what's wrong.

Use this whenever the user asks about or wants changes to an attached or open file: edit the file itself, don't paste a rewritten version into the chat. If the app doesn't answer, say what you were going to change and carry on in the chat; don't ask the user to open the file.
