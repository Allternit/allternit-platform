Run one TypeScript script that calls several MCP tools, and get back only what it returns.

Use it instead of separate MCP calls when a task needs 3+ calls, a loop over results, or one tool's data passed to another. Intermediate results stay in the script.

The script:
- Is the body of an async function. Call `await <server>.<tool>(args)` per the declarations below and `return` what you need (JSON, cut at 8 KB).
- A call rejects when the tool errors or the person declines; use try/catch to continue without it.
- Each call asks permission like a normal MCP tool call.
- Limits: 50 calls, 60 s run time (approval waits don't count), 32 MB memory.
- Only plain JavaScript built-ins: no fetch, setTimeout, process, require, import or file system.
