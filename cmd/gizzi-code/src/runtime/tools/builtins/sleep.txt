Wait for a short time inside this turn, then carry on.

Use it for short waits: a deploy to finish, a build to run, a page to update. Give the number of seconds (1 to 900) and say why you are waiting; the reason is shown to the user.

The wait ends early if the user sends a new message, and it ends if the turn is cancelled. The result says how long you actually slept and what woke you: timer, user_input or cancelled. After a user_input wake, read the new message and answer it before going back to the wait.

For anything longer than 15 minutes, use automation instead of sleeping.
