Create a git worktree with its own branch and move this session into it, so the work stays apart from the main checkout.

Enter one only when the person asks for a worktree, or when the project's instructions say to use one. Do not create one just to try something.

- Give a short name (letters, digits, dots, dashes, underscores), or leave it out to get one. A name that already has a worktree reuses it.
- base is the branch or commit to start from; the current HEAD when left out.
- The session works inside the tree until you call worktree_exit. Enter one tree at a time; exit before entering another.

The result gives the path, the branch and the base. Tell the person where the work now happens.
