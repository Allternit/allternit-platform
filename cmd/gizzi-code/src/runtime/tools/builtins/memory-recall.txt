Search the user's Memory Drive (personal plus any mounted drives) by words.

Use it before you assume a preference, convention or past correction, and before you ask the user something they may already have told you. Use it to find an entry's id and version before changing or deleting it with memory_write.

Each hit is one memory line with its drive, topic file, id, version, source and date. Pass the version as if_version when you change that entry. To see a whole topic, use memory_list.
